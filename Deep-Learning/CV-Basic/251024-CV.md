# 컴퓨터 비전

## 01 컴퓨터 비전의 정의

### 1.1 Computer Vision이란?

**Vision의 정의**

- Vision: 시각적인 정보들의 집합 (ex. 사진, 비디오, …)
- 즉, 시각으로 보이는 것을 숫자로 데이터화 하여 저장한 모든 것들을 포함하는 개념
- Images are fundamentally, tensors
- 이미지 → 텐서라는 수학적인 형태로 구성된 숫자 ⇒ 컴퓨터가 여러가지 연산을 할 수 있음

**Vision to Computer Vision**

- Computer Vision: Artificial Intelligence (AI)의 한 종류로, vision 데이터들에서 의미 있는 정보를 추출하고 이를 이해한 것을 바탕으로 여러가지 작업을 수행하는 것

시각과 관련? → CG?

**Computer Vision vs. Computer Graphics**

- Computer Graphics: 컴퓨터 모델을 활용하여 이미지를 렌더링하는 과정

→ 입력과 출력 상반, 점점 오버랩됨

### 1.2 Types of Computer Vision

- level : 이미지에 대해서 얼마나 픽셀 간의 관계를 고려하면서 정보를 처리하는 가
- Low-level로 갈수록 pixel단위로 이미지를 처리하고, High-level로 갈수록 이미지 전반을 하나의 entity로 묶어서 처리하게 됨
- Low-level : 전체 이미지를 pixel-wise로 처리
    - Photo manipulation
    - feature extraction
- Mid-level
    - image → image
    - image → world
    - image → time
- High-level : : 전체 이미지에서 여러 개의 pixel을 entity로 묶어서 처리
    - classification
    - object detection
    - segmentation

→ 엄격한 분리 기준은 없음

## 02 컴퓨터 비전 훑어보기

### 2.1 Low-level

**Image Processing**

- Resize : 바로 주변에 있는 픽셀들만 고려하여 연산, 전체를 고려하지 않음
- Color Jitter : 색상 변경, RGB 독립적으로 바꾸기 때문에 관계를 고려하지 않음

**Feature Extraction**

- Edge detection : 급격한 픽셀값을 보여주는 이미지의 위치(edge)가 주변의 픽셀 값으로만 결정이 됨
- Segmentation by Color (e.g. watershed) : 각각의 픽셀들의 크기를 참고하여 여러가지 영역으로 분할, 이미지 전반적인 정보를 가지고 있지 않음, 로컬만 참조

### 2.2 Mid-level

**Images → Image**

- Panorama Stitching  : 여러 이미지를 붙여서 하나의 파노라마 이미지를 만듦, 단순하게 이어 붙이면 안되고 변환 연산이 필요함. 이미지에서 대응되는 위치를 찾아야 함.

**Images → World**

- Multi-view Stereo : 여러 각도에서의 2D 이미지로 3D 구조, 질감까지 생성
- Depth Estimation : 2D 사진으로 3D 상의 깊이를 예측
- LIDAR : 라이더 센서로 얻은 데이터로 자율주행, 3D 사물 재구성

### 2.3 High-level

**Semantics**

- Image Classification : 이미지 전체를 이용하여 이미지 분류, 넓은 범위에서 이해
- Object Detection : 이미지 검출하고 어떤 건지 분류
- Segmentation : 2D에서 여러가지 객체들을 픽셀 단위로 분류

## 03 컴퓨터 비전 활용 사례

### 3.1 Pose Estimation

- Action Recognition : human 자동 감식 카메라 구동

- Re-identification : 특정 한 사람 계속 추적, human action recognition과 같이 사용하기도 함

### 3.2 Optical Character Recognition

- 이미지에서 글자를 인식 및 검출
- 이미지 문서 텍스트를 정형화, 자동화, 효율적 → 비용 절감
- 여러 분야 활용 가능, 문서처리 자동화, 서비스 질 향상

### 3.3 Medical Image Analysis

의료 분야, 높은 정밀도, 미세한 차이가 중요, 전문가만 할 수 있던것, 높은 신뢰도를 가지는 1차적 정보를 제공한다면 큰 도움

### 3.4 Generative Models

- Generative Adversarial Network(GAN) : 이미지 생성 모델

- Virtual Try-On (VITON) : 이커머스 분야, 사고싶은 옷을 실제 구매하지 않고도 착샷을 알려주는 소비자의 니즈 충족

- Text to Image Generative Model : 문장을 이미지로 만들어 줌 → 실제로 존재하지 않은 것도 만들어 줌, 디자인 초안 만드는게 쉬워짐, 전문 디자이너 수요 감소

- Image to Video  : 이미지로 동영상 만듦
- Text+Image to Video : 이미지와 설명을 적으면 비디오로 만들어 줌
- Modify Videos with Texts : 비디오도 변경해 줌 → 영상 편집 기술

### 3.5 Neural Radiance Fields

- NeRF : 랜더링 + 컴퓨터 비전 → 3D 사물 랜더링 방식이 아주 쉬워짐, 여러 각도에서의 3D 랜더링 결과를 빠르고 정확하게 만들게 됨

### 3.4 Images with other modalities

- Images ↔ Text (e.g. Image Captioning)

- Images ↔ Brain Signals : 뇌의 신호를 가지고 이미지를 생성, 컴퓨터 비전으로 사람의 생각을 읽고 이미지로 표현 → 마비환자들과의 의사소통 가능
- Image & Video ↔ Text, Audio, Depth, Heat Map, IMU
