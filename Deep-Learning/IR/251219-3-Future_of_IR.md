# IR 발전 방향 전망

## 1. 문제 재정의

### 1.1 기술적 전환점

#### 패러다임 변화

**배경**:
```
우리가 직면한 문제에 대한 관점을 전환시키는
기술적 전환점이 주기적으로 발생
```

**LLM의 등장**:
```
Large Language Models(LLM)의 등장은 그러한 전환점 중 하나

결과:
→ Information Retrieval(IR) 분야의 문제를 새롭게 정의
```

---

### 1.2 문제에 대한 고찰

#### Traditional IR의 정의

**기존 정의**:
```
큰 규모의 비정형 텍스트 문서 집합으로부터
원하는 조건의 질의를 통해
적합한 문서를 추출하는 과정
```

---

#### 새로운 IR의 역할

**패러다임 변화**:
```
IR은 대화형 Agent의 Submodule로 변화

역할:
- 최종 답변을 생성하는데 사용되는 레퍼런스 추출 역할

최종 목표:
- 의사결정에 필요한 정보의 수집/분석 결과 확보
```

**변화 요약**:
```
Traditional IR:
문서 검색 → 문서 나열

Modern IR (with LLM):
정보 수집 → 분석 → 의사결정 지원
```

---

### 1.3 Requirements (요구사항)

#### 대화형 Agent의 요구사항

**1. 분석/판단**
```
기존:
- 단순한 정보의 나열

요구:
- 분석된 결과를 통해
- 의사결정에 직접 도움이 되는 형태의 정보 제공
```

**2. 멀티모달 (Multimodal)**
```
범위:
- 텍스트뿐만 아니라
- 음성 (Audio)
- 비전 (Vision) 정보도 다룰 수 있어야 함
```

**3. 개인화 (Personalization)**
```
고려사항:
- 사용자의 행동
- 장단기 대화 히스토리를 반영
- 최적화된 정보 제공
```

**4. 정보 처리 자동화 (Automation)**
```
요구사항:
- 실시간 분석 및 색인
- 대용량 처리를 위한 비용 최적화
```

---

### 1.4 아키텍처

#### 모듈 구성

**데이터 처리 모듈 & 추론 모듈**

**LLM의 역할**:
```
1. 문서 분석
2. 질의 의도 파악
3. 결과 분석
4. 답변 생성
```

**IR의 역할**:
```
1. 데이터 전처리/색인
2. 데이터 추출
```

---

#### 아키텍처 다이어그램
```
사용자 질의
  ↓
LLM (질의 의도 파악)
  ↓
IR (데이터 추출)
  ↓
LLM (문서 분석)
  ↓
LLM (결과 분석)
  ↓
LLM (답변 생성)
  ↓
사용자에게 제공
```

## 2. 전망

### 2.1 시도 중인 기술들

#### 데이터 품질의 중요성

**핵심 원칙**:
```
Garbage In, Garbage Out
→ 데이터 품질이 중요
```

---

#### 지금까지의 집중 영역

**과거의 초점**:
```
1. 색인 가능한 형태:
   - 주로 잘 정리된 텍스트
   - 이미지에 대한 벡터 데이터

2. 최적화 방향:
   - 여러 조건별 최적화된 임베딩 생성 모델
   - Vector DB의 고도화에 집중

3. 부족한 부분:
   ❌ 색인되는 데이터의 품질 자체를 높이려는 시도는 부족
```

---

#### LLM으로 인한 변화

**새로운 가능성**:
```
LLM으로 다룰 수 있는:
- 데이터의 종류 확대
- 데이터 분석 수준 향상
- 비용 절감
```

**구체적 개선**:
1. **문서를 더 체계적으로 분석/가공하여 색인**
2. **오디오와 이미지/비디오 정보까지 색인**
3. **저비용으로 대규모 데이터를 전처리**

---

#### IR의 빈구멍 메우기 - 텍스트 전처리

**Layout Analysis**

**목적**:
- 문서의 복잡하고 다양한 구조를 이해
- 이를 반영한 색인

**처리 대상**:
```
- 표 (Tables)
- 그래프 (Charts)
- 이미지 (Images)
- 복잡한 레이아웃
```

**기술**:
```
- Document Layout Analysis
- OCR + Structure Understanding
- LLM-based Document Parsing
```

---

#### IR의 빈구멍 메우기 - 멀티모달 (음성)

**Speech to Text**

**주요 솔루션**:
1. **OpenAI Whisper**
   - 오픈소스
   - 다국어 지원
   - 높은 정확도

2. **Google Speech to Text**
   - 클라우드 기반
   - 실시간 처리

3. **네이버 클로바노트**
   - 한국어 특화
   - 회의록 자동 작성

---

**Text Analysis**

**LLM 기반 처리**:
1. **Semantic Chunking**
```
   - 의미 단위로 문서 분할
   - 맥락 보존
```

2. **Text Summarization**
```
   - 핵심 내용 요약
   - 계층적 요약
```

---

#### 추론 모듈 (LLM) 최적화

**1. 도메인 특화 LLM**
```
목적: 도메인 성능 최적화

분야:
- 의료 (Medical)
- 법률 (Legal)
- 특허 (Patent)
- 금융 (Finance)
```

**2. Small Size LLM**
```
목적:
- Inference 비용 최적화
- On-device 적용

예시:
- Phi-3
- Gemma
- LLaMA 2 (7B)
```

**3. 더 강력한 성능의 LLM**
```
기능:
- 정보에 대한 확신도(Confidence)를 판단하고 제공하는 능력
- 멀티모달 입력 처리
```

### 2.3 장기 전망

#### AGI를 향한 발전

**핵심 능력**:

**1. 메타 인지 (Metacognition)**
```
- 아는 것과 모르는 것을 판단하는 능력
- 스스로 학습하는 능력
```

**2. 지속적 학습**
```
Learning Loop을 통한 지속적인 학습
```

---

#### 메타 인지의 중요성

**Learning Loop 구조**:
```
Goal Setting/Update
  ↓
Planning (Chain of Thought)
  ↓
Collect Data & Learning
  ↓
Explore & Evaluation
  ↓
Goal Setting/Update (순환)
```

---

#### 상세 프로세스

**1. Goal Setting/Update (목표 설정/업데이트)**
```
- 현재 상황 파악
- 목표 정의
- 우선순위 결정
```

**2. Planning (계획)**
```
- Chain of Thought 활용
- 단계별 계획 수립
- 필요한 리소스 파악
```

**3. Collect Data & Learning (데이터 수집 및 학습)**
```
- 필요한 정보 수집
- 새로운 지식 학습
- 경험 축적
```

**4. Explore & Evaluation (탐색 및 평가)**
```
- 실행 결과 평가
- 성공/실패 분석
- 개선점 도출
```

**5. 순환 (Loop)**
```
평가 결과를 바탕으로 목표 재설정
→ 지속적인 개선
```

## 전체 요약

### IR의 패러다임 변화
```
Traditional IR:
문서 검색 → 문서 나열

Modern IR (LLM 시대):
정보 수집 → 분석 → 의사결정 지원

Future IR (AGI 시대):
자율적 학습 → 메타 인지 → 지속적 개선
```

---

### 요구사항 변화

| 항목 | Traditional | Modern | Future |
|------|------------|--------|--------|
| **출력** | 문서 리스트 | 분석된 답변 | 의사결정 지원 |
| **입력** | 텍스트 | 멀티모달 | 멀티모달 + 맥락 |
| **개인화** | 없음 | 히스토리 기반 | 완전 개인화 |
| **처리** | 수동 | 반자동 | 완전 자동 |

---

### 기술 발전 로드맵

**단기 (1-2년)**:
```
1. RAG 보편화
2. 비용 최적화
3. 멀티모달 확대
4. 도메인 특화 LLM
```

**중기 (3-5년)**:
```
1. 완전한 멀티모달
2. 개인화 고도화
3. 실시간 학습
4. 비용 대폭 감소
```

**장기 (5년+)**:
```
1. AGI 수준 접근
2. 메타 인지 능력
3. 자율적 학습
4. 의사결정 자동화
```

## 주요 개념 정리

### 메타 인지 (Metacognition)
```
정의: 자신의 인지 과정을 인지하는 능력
의미: 아는 것과 모르는 것을 판단
중요성: AGI의 핵심 요소
```

### Learning Loop
```
정의: 지속적인 학습 순환 구조
구성: Goal → Plan → Learn → Evaluate → Goal
목적: 자율적 개선
```

```
정의: 문서 구조 이해 및 분석
대상: 표, 그래프, 이미지, 복잡한 레이아웃

```

### Task-oriented Dialog
```
정의: 특정 작업 수행을 위한 대화
예시: 예약, 주문, 문의 처리
트렌드: 자동화 확대
```

### Domain-specific LLM
```
정의: 특정 도메인에 특화된 LLM
예시: 의료, 법률, 금융
장점: 높은 정확도, 전문 용어 이해
```
