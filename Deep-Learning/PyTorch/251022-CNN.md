# Convoltuion

- Convolution 연산은 이미지 처리에서 중요하고 자주 사용되는 연산 개념
- Convolution은 두 함수를 합성하는 수학적인 연산으로 한국말로 `합성곱`
- 이미지 처리에선 이미지의 픽셀과 필터를 서로 합성(원소끼리 곱)하는 방식으로 계산
- Convolution 연산을 거친 결과값(feature map) 다음과 같은 공식으로 크기를 계산
    
    O=(I+2P−K / S)+1
    
    - O : output size를 의미합니다.
    - I : Input size를 의미합니다.
    - P : 패딩 사이즈를 의미합니다.
    - K : 필터 사이즈를 의미합니다.
    - S : stride 사이즈를 의미합니다.
- PyTroch에선 `torch.nn.Conv2d`로 convolution 연산을 지원
- `torch.nn.Conv2d`의 파라미터
    - `in_channels` : input 값의 채널을 의미
        - ex) input shape : (BATCH_SIZE, 3, 256, 256) => in_channels = 3
    - `out_channels` : convolution 연산을 통해 생성된 아웃풋의 채널을 의미
        - ex) output shape : (BATCH_SIZE, 64, 256, 256) => out_channels = 64
    - `kernel_size` : 필터의 크기를 의미 (필터 사이즈 = kernel_size x kernel_size)
    - `stride` : 필터의 이동 간격을 의미
    - `padding` : 입력 데이터 주변에 추가되는 값(padding)의 크기
    

## Pooling Layer

- Pooling Layer는 convolution 레이어의 출력으로부터 정보를 요약하고, 계산 비용을 줄이며, 불필요한 정보를 제거하여 모델을 더욱 효율적으로 만드는 역할
- Pooling을 하는 방식은 크게 두가지로 Max Pooling 과 Average Pooling이 있음
    - Max Pooling
        - 각 영역에서 가장 큰 값을 선택하여 크기를 줄이는 방식
        - 특징 맵의 중요한 특징을 강조하고 불필요한 정보를 줄이는데 도움
        - PyTorch 에선 `torch.nn.MaxPool2d`로 구현 가능
    - Average Pooling
        - 각 영역의 평균 값을 선택하여 크기를 줄이는 방식
        - Max Pooling에 비해 많은 정보를 유지하지만, 주요 특징을 강조하는 데는 덜 효과적일 수 있음
        - PyTorch 에선 `torch.nn.AvgPool2d`로 구현 가능

## VGG

- VGGNet은 2014년 ImageNet 인식 대회에서 2위를 한 모델로 옥스퍼드 VGG 연구팀이 개발한 모델
- VGGNet은 작은 필터 사이즈로 모델을 깊게 쌓는 방법을 개발한 모델
- VGGNet의 모든 convolution 연산의 필터 사이즈는 3x3 사이즈
- Convolution layer를 쌓는 간단한 구조로 모델 구조를 변형하기 쉬워 추후 연구에 많은 활용되었음
- VGG 모델은 11개의 layer, 13개의 layer, 16개의 layer, 19개의 layer를 쌓는 시도를 하였음

## GoogLeNet

- Inception이라고 불리우는 GoogLeNet은 VGGNet이 2등을 하였던 ImageNet 인식 대회에서 1등을 한 모델
- GoogLeNet의 핵심은 inception module

### Inception module

- Inception 모듈은 convolution layer를 병렬적으로 사용하여 **다양한 필터의 크기에서 효율적으로 feature를 뽑아내는 것**이 목적
- 1x1 convolution layer를 통해 차원을 줄여주어 효율적인 계산
    - 1x1 convolution의 장점
        - 채널 수를 조절하여 계산량을 감소
        - 활성화 함수와 같이 사용되면서 비선형성을 강조
- 복잡한 아키텍쳐지만 1X1을 사용해서 모델 파라미터는 더 적음
- activation function도 추가적으로 넣을 수 있기 때문에 비선형성을 더 띄어서 성능이 올라감

## ResNet

- ResNet은 convolution layer를 많이 쌓았을 때, train의 성능과 test의 성능 모두 하락하는 degradation 문제가 발생하는 것을 해결하기 위해 제안한 논문
- convolution layer를 통과하지 않은 값과 convolution layer를 통과한 값을 더해주는 residual learning (skip connection)방식으로 convolution layer의 성능 손실 방지

### Bottleneck building block

- Bottleneck layer는 1x1 convolution 연산을 이용하여 채널의 수와 연산량을 감소시키고, skip connection을 수행
