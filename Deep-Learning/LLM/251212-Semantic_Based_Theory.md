# 의미기반 언어 지식 표현 체계 이론

## 1. 분포 가설 (Distributional Hypothesis)

### 핵심 개념
- **"단어가 나타나는 주변 맥락이 유사하면, 그 단어들의 뜻도 서로 비슷하다"**
- 단어의 의미는 그 단어가 사용되는 맥락에 의해 결정됨
- 예: Tesgüino와 wine이 등장하는 주변 문맥이 비슷하므로, 두 단어는 유사함

### One-Hot Vector
- 단어의 해당하는 인덱스에 1을, 나머지에 0을 할당한 범주형 벡터 (Discrete vector)
- **단점**:
  - 벡터 차원이 매우 커져 계산 효율이 낮음
  - 단어 간 유사도를 반영하지 못함
  - 분포 가설에 기반한 의미론적 정보를 반영하지 못함

## 2. 단어 임베딩 (Word Embeddings)

### 정의
- **단어를 고정된 길이의 밀집 벡터(Dense Vector)로 표현하는 기법**
- 분포 가설에 기반

### 특징
- 비슷한 의미를 가진 단어들이 벡터 공간에서 서로 가까이 위치
- 벡터 연산 가능: `king - man + woman ≈ queen`
- **Vocabulary**: 각 단어를 고유한 인덱스에 매핑하고, 임베딩 매트릭스에서 해당 단어의 밀집 벡터를 조회하는 룩업 테이블

### 단어 임베딩의 종류

#### 1) Count-based Methods
- 단어의 출현 **빈도**나 문맥 내 공존 빈도를 기반으로 벡터 생성
- 예: Count Vector, TF-IDF

#### 2) Prediction-based Methods
- **신경망을 이용**해 주변 단어로부터 타겟 단어를 예측하며 학습된 벡터 사용
- 예: Word2Vec, FastText, Neural Probabilistic Language Models

#### 3) Other Methods
- 예: GloVe (Global Vectors for Word Representation)

---

## 3. Word2Vec

### 개요
- **주변 단어 기반으로 신경망으로 예측**하는 문맥 예측(Prediction-based) 방법
- 분포 가설을 바탕으로 학습
- 매개변수가 단어 벡터인 모델로, 특정 목표에 대해 반복적으로 최적화

### 학습 방법

#### 1) CBOW (Continuous Bag of Words)
- **주변 단어들의 맥락을 통해 중심 단어를 예측**
- 주변 단어들의 문맥 벡터를 합치거나 평균내어 중심 단어 예측 확률을 최대화
```
[주변 단어1, 주변 단어2, 주변 단어3, 주변 단어4] → [중심 단어]
```

#### 2) Skip-gram
- **중심 단어로부터 주변 단어들을 예측**
- 중심 단어의 분산 표현을 사용하여 주변에 등장할 가능성이 있는 단어들의 확률을 최대화
```
[중심 단어] → [주변 단어1, 주변 단어2, 주변 단어3, 주변 단어4]
```

## 4. GloVe (Global Vectors for Word Representation)

### 개요
- **공존 행렬(Co-occurrence Matrix)** 기반의 단어 벡터 학습 방법
- 벡터 간의 dot-product가 단어 쌍의 공존 확률의 로그 값과 같아지도록 학습
- **Word2Vec과의 차이**: Word2Vec은 local(지역적) 문맥 정보 사용, GloVe는 global(전역적) - 코퍼스 전체의 통계 정보 사용

### 공존 확률 (Co-occurrence Probability)
- 단어 i와 단어 j가 함께 등장할 확률
- 단어 i와 j가 **문맥 단어 k의 문맥에서 얼마나 잘 등장하는지 추정**

### 손실 함수
- **V**: Vocabulary의 크기
- **X_ij**: 전체 코퍼스에서 단어 i와 단어 j가 함께 등장하는 횟수의 공존 행렬
- **f(X_ij)**: 가중치 함수
  - 공존 횟수에 따라 가중치 부여
  - 희귀한 단어 쌍에 대한 영향 감소
  - 자주 등장하는 단어 쌍에 대한 영향 증가

## 5. FastText

### 개요
- **문맥 예측(Prediction-based) 기반 + 서브워드 정보 포함**
- 단어를 **n-그램 서브워드로 분해**하여 내부 구조를 반영
- Word2Vec을 확장하여 희귀 단어나 오타에 대한 내성 강화
- GloVe보다 세밀한 표현 가능

### Word2Vec의 문제점과 개선

#### Word2Vec의 문제점
1. **OOV (Out of Vocabulary) 문제**: 학습 중 만나지 않은 새로운 단어나 합성어에 대해 임베딩 생성 불가
2. **형태학적 유연성 부족**: 동일한 어근을 공유하는 단어들 간의 매개변수 공유 없음
   - 예: eat, eats, eaten, eater, eating을 모두 다르게 벡터화 → 비효율적

#### FastText의 개선 방법

**1. Subword 단어 분해**
- 중심 단어의 임베딩은 n-그램(3-6 grams) 벡터의 합으로 계산
- 문맥 단어의 벡터는 n-그램을 추가하지 않고 사용
- Hashing 기법을 활용하여 분해된 n-gram의 메모리 사용량 제한
- OOV 및 형태학적 유연성 확보

**2. Negative Sampling**
- 실제 문맥 단어 주변에 negative sample을 무작위로 선택하여 임베딩 최적화
- 의미적으로 다르면 멀게, 비슷하면 가깝게 학습

**학습 과정**:
1. 중심 단어 임베딩은 문자 n-gram + 전체 단어 벡터의 합으로 계산
2. 문맥에 등장하는 단어들은 n-gram으로 분리하지 않고 단어 벡터 사용
3. 유니그램 빈도의 제곱근 비율로 Negative Sample 무작위 수집 (문맥단어 1개당 5개)
4. 중심 단어와 문맥 단어 간 내적 → 시그모이드 → SGD로 최적화

## 6. Doc2Vec

### 개요
- **문맥 예측(Prediction-based) 기반으로 문서 전체의 벡터를 학습 및 표현**
- 단어/서브워드 벡터가 아닌 **문서 벡터 단위의 모델**
- Word2Vec의 확장

### 특징
- 단어뿐만 아니라 문장, 문단, 전체 문서를 고유한 벡터로 변환
- 문서의 순서와 구조를 포함한 정보 학습
- 문서 간 유사성 측정 및 문서 분류 작업에 활용

### 학습 방법
- 문장에 해당하는 document id(#doc5)도 의미공간에 위치
- document id와 각 문서에 등장한 단어들이 서로 가까워지도록 벡터 최적화

## 7. CoVe (Contextualized Word Vectors)

### 개요
- **시퀀스 모델링(Sequence Modeling) 기반의 단어 벡터 학습**
- 사전 훈련된 기계 번역 모델에서 단어의 문맥적 임베딩 추출
- **문맥에 따라 변화하는 동적인 단어 벡터 제공**

### 기존 방법과의 차이
- Word2Vec: 같은 단어는 어디에 있든 같은 벡터
- CoVe: 단어가 각기 다른 문맥에서 등장할 때 그에 따라 달라지는 의미 포착
- 문맥에 민감한 단어 벡터 생성

### 학습 과정
1. **기계번역 모델 학습**: Bi-directional LSTM 구조에 Machine Translation 학습
2. **다른 NLP Task에 적용**: 
   - 기계 번역 모델의 인코더 context vector와 GloVe 모델 활용
   - 문맥적 정보를 함축한 벡터 추출
   - 다른 NLP task에 적용

## 정리 및 비교

| 모델 | 특징 | 장점 | 단점 |
|------|------|------|------|
| **Word2Vec** | 주변 단어 예측 기반 | 의미적 유사도 학습 | OOV 문제, 형태학적 정보 미반영 |
| **GloVe** | 전역 공존 행렬 기반 | 전체 코퍼스 통계 활용 | 계산 비용 높음 |
| **FastText** | 서브워드 정보 활용 | OOV 해결, 형태학적 유연성 | 메모리 사용량 증가 |
| **Doc2Vec** | 문서 레벨 임베딩 | 문서 간 유사도 측정 가능 | 학습 시간 증가 |
| **CoVe** | 문맥 의존적 벡터 | 동적인 의미 표현 | 계산 복잡도 높음 |

---

## 참고사항
- 모든 방법은 **분포 가설**을 기반으로 함
- Count-based → Prediction-based → Contextualized 순으로 발전
- 최근에는 BERT, GPT 등 Transformer 기반 모델이 주로 사용됨
