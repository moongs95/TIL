# 1-2. 데이터 수집 ② 크롤링 (Web Crawling)

## 01. 크롤링 개요

### 1.1 크롤링이란?

**크롤링(Crawling) / 웹 크롤링(Web Crawling)**  
인터넷 상의 웹페이지를 자동화된 방식으로 탐색하며 정보를 수집하는 과정

- 거미가 거미줄을 타고 이동하는 모습에 빗대어 **스파이더링(Spidering)** 이라고도 불림
- 크롤링을 수행하는 프로그램을 **웹 크롤러(Web Crawler)** 라고 함

> 데이터 구축 목적의 크롤링은 엄밀히 말하면  
> **스크래핑(Scraping)**에 가깝지만,  
> 본 노트에서는 **‘크롤링’으로 통일**하여 사용

---

### 1.2 크롤링 방법 (프로세스)

크롤링은 단순 수집이 아니라  
**웹 구조 분석 → 수집 → 정제 → 저장**의 반복 과정이다.

#### 크롤링 전체 흐름

1. **웹사이트 구조 파악**
   - URL 패턴
   - 페이지 계층 구조
   - 페이지 간 관계  
   → ❗ 분석이 가장 중요

2. **크롤링 도구 선택**
   - BeautifulSoup
   - Scrapy
   - Selenium 등

3. **URL 수집**
   - 크롤링 대상 URL 리스트 구성
   - 계층형(hierarchy) 리스트 구성 → 반복문 활용

4. **HTTP 요청 및 다운로드**
   - GET 요청 전송
   - HTML 소스코드 수신

5. **데이터 추출**
   - HTML 파싱
   - CSS Selector / XPath 활용

6. **데이터 가공**
   - 문자열 정제
   - 타입 변환
   - 구조화

7. **데이터 저장**
   - CSV / JSON
   - Database

8. **4 ~ 7 과정 반복**

---

### 크롤링 시 주의사항

#### 크롤링 전 확인 사항
- 저작권 및 이용 약관 확인
- API 제공 여부 확인

**예시**
- **YouTube**  
  → YouTube Data API 사용 권장 (크롤링보다 효율적 & 안전)

#### 크롤링 코드 작성 시 주의사항
- **IP 차단 방지**
  - 과도한 요청은 공격(DDoS)으로 간주될 수 있음
  - `time.sleep()` 등으로 요청 간격 조절
  - `robots.txt` 확인 필수

### 1.3 크롤링 활용 사례

#### 도메인별 크롤링 활용도

- 텍스트 > 시계열 > 이미지/영상

---

#### 이미지 / 영상 데이터

크롤링이 가장 까다로운 데이터 유형

**이유**
- **저작권**: 영리적 사용 제한
- **보안**: HTML에서 직접 접근 불가한 경우 다수
- **용량**: 샘플당 크기가 큼

**제한적 사용 가능 사례**
- 상품 이미지
- 저작권 보호기간이 만료된 명화
- 정부 공공저작물  
  - 저작권법 제24조의2 (공공저작물 자유 이용)

➡️ 대부분 **명시적 허가가 있는 경우에만 사용**

---

#### 시계열 데이터 (주식 데이터)

주식 데이터는 크롤링 방식이 매우 효과적

- 데이터가 **매일 누적**
- 최신 데이터의 지속적 수집 필요

**연구에서 중요하게 맞추는 요소**
- 수집 주기  
  - 일별 시가 / 종가 / 고가 / 저가 / 거래량
- 학습/테스트 분할 시점  
  - 예: 2022-12-31 이전 학습
- 전처리 방식  
  - 이동평균 (5, 20, 60, 120일)

➡️ 기존 연구의 **수집·전처리 방식을 재현**하는 것이 핵심

---

#### 텍스트 데이터

가장 일반적인 크롤링 대상

- 특정 태스크에 맞는 대량 텍스트 수집
- (LLM 사전학습용 대규모 크롤링은 별도 영역)

**활용 예시**
- 위키
  - 사이트: 위키피디아, 위키낱말사전
  - 태스크: 지식 그래프 생성 (Knowledge Graph)

- 리뷰 데이터
  - 사이트: 아마존, 네이버쇼핑, IMDb
  - 태스크: 추천 시스템 (Recommendation)

## 02. 크롤링에 필요한 사전 지식

### 2.1 HTML 기초

**HTML (Hyper Text Markup Language)**  
웹페이지 구조를 표현하는 대표적인 마크업 언어

```html
<tag class="class1 class2" attribute1="arg1">
  content
</tag>
```
#### HTML 구성 요소

- **Tag**: 구조 표현  
- **Class**: CSS 선택자  
- **Attribute**: 기능 및 속성  
- **Content**: 실제 내용  

➡️ **HTML 구조 분석 → 필요한 데이터 위치 파악**

---

#### HTML 구조 확인 방법

#### 브라우저 개발자 도구 사용

- **Windows**: `Ctrl + Shift + I`
- **Mac**: `Cmd + Option + I`
- 또는 `F12`

#### 절차

1. 요소 선택 버튼 클릭  
2. 원하는 요소 클릭  
3. 해당 HTML 코드 확인
