# OCR 기초

# 01. OCR 기초

## 1.1 OCR 개념 정의

### OCR이란
- **광학 문자 인식 (Optical Character Recognition)**
- 텍스트 이미지를 기계가 읽을 수 있는 **텍스트 포맷**으로 변환하는 과정  
- **이미지 데이터 → 텍스트 데이터**

---

### OCR 프로세스

#### 1) 검출 (Text Detection)
- 이미지에서 **텍스트 영역(Word Box)** 을 찾는 단계
- 이미지 내 텍스트를 감지하고 해당 영역을 추출

**주의사항**
- 여러 줄이 하나의 박스로 검출될 경우 → **Multi-line**
  - 인식 단계에서 **성능 저하 가능**
- 텍스트가 밀집된 문서의 경우
  - 글자 간 거리가 좁음
  - 문단 단위로 예측되어 **하나의 박스**로 검출될 가능성 증가
  - 결과적으로 **인식 성능 저하**

→ 밀집 텍스트, 문서 유형에 따른 **검출 최적화 필요**

---

#### 2) 인식 (Text Recognition)
- 검출된 텍스트 영역에서 **문자열을 반환**하는 단계
- 다양한 텍스트 형태를 처리해야 함

**텍스트 변형 유형**
- Horizontal / 수평
- Rotated / 기울어진
- Curved / 곡선 형태
- Arbitrary / 불규칙한 형태

---

### Layout Analysis
- 단순 문자 인식을 넘어 **문서 구조 이해**가 필요
- 문단, 제목, 표, 도식 등 **레이아웃 정보 파악**
- 표·도식 등 특수한 형태의 이미지를 **구조화된 데이터**로 변환

---

## 1.2 Text in Image

### Document Image

#### Document OCR 특징
- 높은 텍스트 밀도
- 표와 같은 **특이한 레이아웃**
- 스캔 과정에서 발생하는 **아날로그 데이터 열화**

---

### Scene Text Image

#### Scene Text OCR 특징
- 불규칙적인 배경
- 다양한 색상과 변형 (Word Art 등)
- 다양한 글씨체 사용

---

# 02. OCR 필요성

## 2.1 업무 프로세스 자동화

### 문서 처리 자동화 예시
- 청구서류 접수 확인
- 청구 내용 심사 및 안내 자동화

---

### 문서 작업 자동화가 어려운 이유
- **문서 파일이 아닌 문서 이미지**로 주고받는 경우가 많음
  - 내용 위조 방지
  - 직인, 날인 등 복제 방지 목적
- **매우 높은 정확도 요구**
  - 예: `2,000` 과 `20,000` 은 업무적으로 큰 차이

---

### 문서 자동화의 장점
- **인재 양성 비용 감소**
  - 신규 인력 교육 부담 감소
- **시간적 제약 탈피**
  - 24시간, 연중무휴 서비스 가능
- **인건비 절감**

---

## 2.2 비정형 데이터 자산화

### 비정형 데이터란 (Unstructured Data)
- 미리 정의된 데이터 구조 없이 정리되지 않은 정보
- 예시:
  - 동영상 파일
  - 오디오 파일
  - 사진
  - 보고서(문서)
  - 이메일 본문 등

---

### 비정형 데이터 자산화의 어려움
- 변칙성과 모호함으로 인해 **알고리즘 처리 어려움**
- 지속적으로 생성되는 데이터 중 **가장 큰 비중**
- 축적된 데이터 양이 방대하여 **수작업 자산화 한계**
- 하지만, 방대한 데이터가 가지는 **잠재적 가치는 매우 큼**

→ **인공지능 모델을 활용한 자산화 필요**

---

### 비정형 데이터 자산화 예시
- 창고에 보관된 문서들을
  - 검색 가능
  - 활용 가능한 형태로 가공
  - 데이터 자산으로 전환
