# 딥러닝 개요

- AI 발전 과정 5단계에서 3,4,5가 딥러닝 부분
- AI : 감지, 추론, 행동, 적응이 가능한 프로그램
- ML : 데이터 기반으로 개발
- DL : 모델의 구조가 뉴럴넷 기반

## 딥러닝의 구성요소

- 딥러닝을 구성하는 필수적인 요소 : 모델, 데이터, 학습 방법
- 성능 = 모델(구조) + 데이터 + 학습 방법(손실함수, 최적화/기타 알고리즘)

```text
- 모델을 학습하기 위해 필요한 데이터 (Data)
  … MNIST, Fashion MNIST 등
- 주어진 데이터를 원하는 결과로 변환하는 모델 (Model)
  … 다층 퍼셉트론(MLP), 컨볼루션 신경망(CNN), 순환 신경망(RNN) 등
- 모델의 결과에 대한 오차를 수치화하는 손실 함수 (Loss Function)
  … 평균절대오차(MAE), 평균제곱오차(MSE), 교차 엔트로피(CE) 등
- 손실 함수의 값이 최소가 되도록 모델의 파라미터를 조정하는 최적화 알고리즘 (Optimization Algorithm)
  … 경사 하강법(GD), 확률적 경사 하강법(SGD), 모멘텀(Momentum) 등
- 성능 향상을 위한 기타 알고리즘
  … Dropout, Regularization, Normalization 등
```

### 데이터

- 해결하고자 하는 문제(task)에 따라 필요로 하는 데이터의 형태나 구성이 달라짐

### 모델

- 입력을 원하는 결과로 바꾸어주는 일련의 연산 과정을 구조화한 것
- 딥러닝의 학습 대상
- 입력(숫자) -> 모델(연산들의 틀) -> 원하는 결과(숫자)
- 연산들의 틀을 그래프의 구조로 표현

### 손실함수

- 실제 혹은 목표로 하는 값(y)과 모델의 추정한 값(yhat) 사이의 차이, 즉 오차를 수치하하는 함수
- 파라미터 값들 중 어느 것이 정답과의 오차가 작은 것인지 정량적으로 표현 필요 ex. 평균제곱오차(MSE)

### 최적화 알고리즘

- 손실 함수가 최소값을 가지도록 모델의 파라미터를 최적화하는 알고리즘 ex. 언제 평균제곱오차가 제일 작아지는지

```text
- Parameter (파라미터, 매개변수)

: 어떠한 시스템이나 함수의 성질을 나타내는 변수
: 연산을 위해서 정해줘야 하는 값
시스템, 틀(모델) : y=ax+b, 파라미터 : a, b

→ 파라미터를 정해주는 과정이 학습

⇒ 딥러닝에서 ‘최적화’란 대개 최적의 해를 바로 찾는 것이 아닌, 근사최적해를 점진적으로 찾는 것을 의미한다.
```

- 모든 a, b값의 조합에 대해서 다 비용을 계산하는 것은 거의 불가능하기 때문에, 최소한 조합에 대한 계산으로 비용이 제일 적은 (a, b)를 찾는 것이 목표!

### 딥러닝 파이프라인

- **모델**이 **데이터**를 통해 추정한 값(yhat)이 정답/목표(y)와 최대한 가까워지도록(=**손실함수**의 값이 최소가 되도록) 파라미터(θ)를 **최적화 알고리즘**을 적용하여 최적의 모델 파라미터(θ')를 찾는 과정
- task에 맞는 데이터, 모델 틀을 먼저 정해둠
- 파라미터 정해 주는 것이 학습 → 파라미터 값에 따라 모델이 좋은지, 안좋은지 정량적으로 표현(손실함수) → 손실함수 값으로 파라미터를 어떻게 바꿀지 결정 ⇒ 반복
