# OpenAI 한판정리

## 1. OpenAI 소개

### OpenAI란?

**정의**:
- **AI research 및 deployment company (AI 연구 및 배포 회사)**

**목표**:
- **인공지능이 모든 인류에게 혜택을 줄 수 있도록 하는 것**
- **AGI (Artificial General Intelligence)** 개발
  - 즉, **인간보다 똑똑한 AI 시스템**에 대한 비전을 강조

---

## 2. OpenAI 역사

### 설립 (2015년)

**배경**:
- **일론 머스크와 샘 알트먼**이 설립
- **Closed-AI의 대표주자인 구글에 대항하기 위함**
- **비영리**로 시작한 사업

---

### 마이크로소프트 투자

**투자 시기**:
- 2019년
- 2021년
- 2023년

**계약 내용**:
- 마이크로소프트의 **연이은 대규모 투자**를 받음
- **GPT-4를 비롯하여 지적재산권 라이센스**
- **기타 제품 상용화 독점계약**을 맺음

---

### 2023년 말 이슈

**사건**:
- 공동창업자 샘 알트먼 이사회 해고 이슈
- 투자자들을 비롯, 업계 관계자들의 신뢰를 잃음

**결말**:
- 협상으로 인한 기존 알트먼 등의 복귀가 확정
- 새로운 이사회가 꾸려지면서 사건이 일단락

## 3. OpenAI 사업

### 사업 구조

**핵심: 언어모델**
- 자사 응용 소프트웨어의 기반이 되는 **파운데이션 모델**
- **유료 API를 통해 서드파티 기업에도 서비스를 제공**
- **플러그인 지원**을 통하여 자사 GPT만의 생태계를 만들어 나가고 있음
- **OpenAI의 알파이자 오메가인 분야**

---

### 보유 모델/기술

**1. GPT 시리즈**
```
- 대형 언어모델 (Large Language Model)
- GPT-3.5, GPT-4 등
```

**2. Whisper**
```
- ASR (Automatic Speech Recognition) Model
- 자동 음성 인식 모델
```

**3. DALL-E**
```
- Text-to-Image Generation Model
- 텍스트를 이미지로 생성하는 모델
```

---

### 대표 응용 소프트웨어

**ChatGPT**:
- GPT-3.5, GPT-4 기반의 **대화형 인공지능 서비스**

---

## 4. OpenAI API

### 개요

**정의**:
- **OpenAI의 최첨단 AI Models에 기반한 인터페이스를 제공**

---

### Features (주요 기능)

**제공 기능**:
- **Chat** (채팅)
- **Embeddings** (임베딩)
- **Analysis** (분석)
- **Fine-tuning** (미세조정)
- **Prompt Engineering** (프롬프트 엔지니어링)
- **Text to Image** (텍스트를 이미지로)
- etc...

---

### GPT Type Interface

**주요 인터페이스**:
1. **Text Generation** (텍스트 생성)
2. **Embedding** (임베딩)
3. **Fine-tuning** (미세조정)

---

## 5. Text Generation (텍스트 생성)

### Chat Completions API

**형태**:
- Chat Completions API의 형태로 활용

**제공 기능**:
- **이미지 입력**
- **스트리밍 기능**
- **Log probabilities 반환**
- **Functions 기능 제공**

---

### Text Generation with Image/Video (GPT-4)

**기능**:
- **Image/Video 입력 지원**
- GPT-4에서 멀티모달 기능 제공

---

## 6. Prompt Engineering (프롬프트 엔지니어링)

### 개념

**정의**:
- 수행하고자 하는 작업에 대한 **Instruction/examples** 등에 대한 정보를 API의 입력과 함께 전달

**목적**:
- 모델이 원하는 결과를 생성하도록 유도

---

## 7. Function Call with Chat Completion

### 개념

**정의**:
- **Function에 대한 specification을 Chat Completion API에 제공**하여 GPT 모델의 기능을 확장하는 방법

**작동 방식**:
- GPT 모델이 제공된 **function parameters의 요소 중에서 적절한 시기에 함수를 활용**하도록 함

**효과**:
- 외부 API 호출
- 데이터베이스 조회
- 특정 작업 수행 등

---

## 8. Embeddings (임베딩)

### 활용 분야

OpenAI API의 Embeddings를 다음 작업에 활용:

**1. Search (검색)**
```
텍스트 간 유사도 기반 검색
```

**2. Clustering (클러스터링)**
```
유사한 텍스트들을 그룹화
```

**3. Recommendations (추천)**
```
유사도 기반 추천 시스템
```

**4. Anomaly detection (이상치 탐지)**
```
정상 패턴과 다른 텍스트 탐지
```

**5. Diversity measurement (다양성 측정)**
```
텍스트 간 다양성 정도 측정
```

**6. Classification (분류)**
```
텍스트 분류 작업
```

---

## 9. Fine-tuning (미세조정)

### When to use fine-tuning (언제 사용할까?)

**시도 순서**:
1. **Prompt Engineering** 시도
2. **Prompt Chaining** 시도
3. **Function calling** 시도
4. 다양한 작업을 수행하여 결과를 향상시키는 노력

**Fine-tuning 고려 시점**:
- 그럼에도 **원하는 결과가 나오지 않는 경우에 튜닝 고려**

---

### Create a fine-tuned GPT model (미세조정 모델 생성)

**과정**:
1. **학습을 위한 데이터 준비**
2. **학습을 위한 job 생성**
3. **Job 관리**

---

### Use a fine-tuned model (미세조정 모델 사용)

**방법**:
- Chat Completion API에서 **"model" 매개변수 변경**하여 활용

---

## 10. GPT Builder (GPT 빌더)

### 개요

**정의**:
- **ChatGPT를 활용하여 커스텀 GPT를 구성할 수 있도록 하는 기능**

---

### GPT Builder: Configuration (설정)

**Configure에서 설정 가능한 항목**:
1. **대표 이미지**
2. **이름**
3. **설명**
4. **지시 사항 설정**

---

### GPT Builder: Conversation starters (대화 스타터)

**기능**:
- **메시지 입력창 상단에 표시되는 대화 스타터 기능 설정**

**목적**:
- 사용자가 쉽게 대화를 시작할 수 있도록 유도

---

### GPT Builder: Knowledge (지식)

**기능**:
- **업로드한 자료를 참조하여 답변을 제공**할 수 있도록 하는 기능

**활용**:
- PDF, 텍스트 파일 등을 업로드
- Custom GPT가 해당 자료를 참고하여 답변 생성

---

### GPT Builder: Built-in-capabilities (내장 기능)

**Custom GPT가 자체적으로 활용할 수 있는 기능**:

**1. Web Browsing (웹 브라우징)**
```
- Custom GPT가 실시간 인터넷 검색을 활용
- 최신 정보를 답변에 활용
```

**2. Image Generation (이미지 생성)**
```
- DALL-E 모델을 활용하여 이미지를 생성하는 옵션
```

**3. Code Interpreter (코드 인터프리터)**
```
- 요청 사항을 내장된 Python program을 통해 수행한 뒤 답변 제공
- 데이터 분석, 계산, 차트 생성 등
```

---

### GPT Builder: Actions (액션)

#### 개념

**정의**:
- **Built-in capabilities (검색, DALL-E, Code Interpreter)를 사용하는 것 외에도**
- **하나 이상의 외부 APIs를 GPT에서 사용할 수 있도록 하여 사용자 작업을 정의**

---

#### 활용 예시

**Actions를 통해 GPT는**:
1. **API를 통해 외부 데이터를 통합**
2. **GPT를 데이터베이스에 연결**
3. **이메일에 연결**
4. **쇼핑 도우미로 만들기**
5. 등의 상호 작용이 가능

---

#### Actions 정의 방법

**방법**:
- **외부 API에 대한 정보 및 스키마를 YAML or JSON 형식으로 입력**하여 Actions를 정의

**효과**:
- Custom GPT가 정의된 API 구조만을 인식
- **API의 특정 기능에만 액세스하도록 설정**

### Function Call vs Actions 비교

| 구분 | Function Call | Actions |
|------|---------------|---------|
| **사용 위치** | API 레벨 | GPT Builder 레벨 |
| **목적** | 프로그래밍적 확장 | 사용자 친화적 확장 |
| **정의 방법** | API 파라미터 | YAML/JSON 스키마 |
| **대상** | 개발자 | 일반 사용자 |

**3. 쇼핑 도우미**
```
YAML 정의 → 쇼핑몰 API 연결

## 실전 활용 가이드

### API 사용 단계별 가이드

**Level 1: 기본 사용**
```
1. Chat Completions API로 텍스트 생성
2. Prompt Engineering으로 결과 개선
```

**Level 2: 고급 사용**
```
1. Embeddings로 검색/분류 시스템 구축
2. Function Call로 외부 API 연동
3. 이미지/비디오 입력 활용
```

**Level 3: 전문가 사용**
```
1. Fine-tuning으로 커스텀 모델 생성
2. 복잡한 Prompt Chaining 구성
3. 대규모 시스템 통합
```

---

### GPT Builder 활용 단계

**Step 1: 기본 설정**
```
1. Configuration에서 이름, 설명, 지시사항 설정
2. Conversation Starters 추가
```

**Step 2: 지식 추가**
```
1. Knowledge에 참고 자료 업로드
2. 특정 도메인 지식 제공
```

**Step 3: 기능 확장**
```
1. Built-in Capabilities 활성화
2. Actions로 외부 API 연동
```

## 주요 개념 정리

### AGI (Artificial General Intelligence)
```
정의: 인간 수준 또는 그 이상의 일반 지능
목표: 모든 인지 작업을 인간처럼 수행
OpenAI의 최종 목표
```

### Function Call
```
정의: GPT가 특정 시점에 함수를 호출할 수 있도록 하는 기능
목적: GPT의 기능을 외부 시스템과 연동하여 확장
활용: API 호출, 데이터베이스 조회, 계산 수행 등
```

### Embeddings
```
정의: 텍스트를 고차원 벡터로 변환
목적: 텍스트 간 유사도 계산, 검색, 분류 등
차원: 일반적으로 1536차원 (text-embedding-3-small)
```

### Fine-tuning
```
정의: 사전학습된 모델을 특정 작업에 맞게 추가 학습
목적: 특정 도메인이나 스타일에 특화된 모델 생성
시점: Prompt Engineering으로 해결 안 될 때
```

```

3. 캐싱 활용
4. 배치 처리
```

**성능 최적화**:
```
