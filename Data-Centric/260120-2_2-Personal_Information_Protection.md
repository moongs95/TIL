# 2-2. 데이터 수집 시 주의 사항 ② 개인정보 보호

## 01. 개인정보 보호 개요

### 1.1 개인정보

**개인정보**란 다음 조건을 모두 만족하는 정보이다.

1. 살아 있는 개인에 관한 정보  
2. 개인과 관련된 정보로서  
3. 특정 개인을 알아볼 수 있는 정보  
4. 해당 정보만으로는 식별이 불가능하더라도  
5. 다른 정보와 쉽게 결합하여 개인을 식별할 수 있는 정보

#### 개인정보가 아닌 경우
- 사망한 자, 법인, 단체, 사물에 관한 정보
- 집단 통계값과 같이 개인 식별이 불가능한 정보
- 특정 개인을 알아보기 어려운 정보  
  - 이때 ‘알아보기 어려움’의 기준은 **해당 정보를 처리하는 모든 사람**

**결합 가능성 판단**
- 결합 대상 정보의 입수 가능성과 결합 가능성이 높아야 개인정보에 해당
- 예시  
  - 차량번호: 자동차등록원부와 결합 가능 → 개인정보  
  - 결합에 과도한 시간·비용이 필요한 경우 → 개인정보 아님

---

### 개인정보의 종류

개인정보는 관련 법령에 따라 다양한 유형으로 구분되어 보호됨

- **고유식별정보**  
  개인을 고유하게 식별하는 정보  
  - 주민등록번호, 여권번호, 운전면허번호, 외국인등록번호  
  - 개인정보 보호법 제24조

- **민감정보**  
  개인의 사상·신념·정치·건강·성생활 등 민감한 정보  
  - 개인정보 보호법 제23조  
  - 건강정보, 생체정보, 결제정보 등 포함

- **개인위치정보**  
  개인의 위치에 관한 정보  
  - 위치정보법

- **개인영상정보**  
  개인의 초상, 행동 등이 포함된 영상 정보  
  - 개인정보 보호법 제2조

---

### 1.2 개인정보 보호 지침

#### AI 관련 개인정보 보호 6대 원칙  
(개인정보보호위원회)

- **적법성**: 개인정보 처리는 적법하고 명확한 근거를 가져야 함
- **안전성**: 개인정보를 안전하게 처리·관리해야 함
- **투명성**: 개인정보 처리 내역을 알기 쉽게 공개해야 함
- **참여성**: 정보주체의 권리를 보장하고 소통 체계를 갖출 것
- **책임성**: 개인정보 처리 책임을 명확히 할 것
- **공정성**: 차별·편향 발생을 최소화할 것

#### AI 개인정보 보호 자율점검표
- 점검 항목: 16개
- 확인 사항: 54개
- 구성
  - 단계별 점검 요소: 9가지
  - 상시 점검 요소: 7가지

### 1.3 개인정보의 수집

#### 개인정보처리방침 vs 개인정보 수집·이용 동의서

**동의서 ≠ 처리방침**

- **개인정보처리방침**
  - 개인정보 수집·이용·보호 절차와 기준을 규정한 문서
  - 실제 이용을 위해서는 정보주체의 명시적 동의 필요

- **개인정보 수집·이용 동의서**
  - 개인정보처리방침에 따라 개인정보를 수집·이용하기 위한 동의 문서
  - 수집 항목, 목적, 보유·이용 기간, 제3자 제공 여부 명시 필요

## 02. 개인정보 비식별화

### 2.1 개인정보 비식별화란

**개인정보 비식별화(De-Identification)**  
개인 식별이 가능한 요소를 제거하여  
특정 개인을 알아볼 수 없도록 하는 조치

#### 비식별화 정보 유형
- **가명정보**
  - 직접 식별자는 제거
  - 간접 식별자(가명)는 유지

- **비식별화 정보**
  - 직·간접 식별자를 모두 제거한 정보

- **익명정보**
  - 재식별이 완전히 불가능한 정보
  - 데이터 활용성이 크게 떨어지므로 지양

---

### 개인정보 비식별화 프로세스

1. 사전 검토  
2. 비식별 조치  
3. 적정성 평가  
4. 사후 관리  
- 부적정 시 다시 비식별 조치 단계로 회귀

---

### 2.2 개인정보 비식별화 방법

#### 일반적 기법
- 가명처리
- 총계처리
- 데이터 삭제
- 데이터 범주화
- 데이터 마스킹

#### 프라이버시 보호 모델
- **k-익명성**
- **l-다양성**
- **t-근접성**

---

### 2.3 개인정보 비식별화 사례

#### 도메인별 비식별화 방법

- **수치형 데이터**
  - 라운딩, 범주화, 총계처리

- **이미지·영상 데이터**
  - 얼굴·번호판 블러 처리
  - 크롭(자르기)

- **텍스트 데이터**
  - 이름·민감정보 키워드 마스킹
  - 위치 정보 라벨링

- **음성 데이터**
  - 음성 구간 크롭

#### 예시
- 입원 날짜 → 연도 단위로 변환
- 연령 → 평균 연령으로 총계 처리
- 얼굴·번호판 → 블러 처리
- 텍스트 마스킹 후 라벨링 → 가상 데이터 생성 가능
