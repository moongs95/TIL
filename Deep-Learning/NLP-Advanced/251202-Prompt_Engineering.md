# 🚀 Prompt Engineering 정리

## 01. Prompt Engineering

> 모델에 입력되는 Prompt에 따라 결과가 달라지므로  
> **좋은 Prompt를 설계하는 것이 성능 향상의 핵심!**

---

### 1.1 Prompt Engineering 의 정의

| 용어 | 의미 |
|---|---|
| Prompt | 모델에게 수행할 작업을 알려주는 지시사항 |
| Engineering | 의도를 수행하도록 효과적으로 설계하는 과정 |
| Prompt Engineering | **추가 학습 없이** Prompt 설계만으로 모델이 의도를 잘 수행하도록 하는 기술 |

- GPT-3로 시작된 Zero-Shot + Instruction 시대의 핵심 기술

---

### 1.2 Prompt에 따른 결과 차이

- 잘못된/모호한 Prompt → 엉뚱하거나 틀린 응답
- **Prompt가 곧 품질이다!**

---

### 1.3 좋은 Prompt 작성을 위한 주요 가이드

---

## 🎯 전략 1: 명확하고 구체적인 Prompt 작성

> Prompt가 길어져도 문제 없음!  
> → 맥락을 충분히 제공하는 것이 중요

#### 전략 1.1) 구분자 사용
- 예: `"""`, ````, `<tag></tag>`, `---` 등
- 문서 요약 시:  
  → `"--- 로 구분된 문서를 한 문장으로 요약해라"`

#### 전략 1.2) 구조화된 출력 요청
- HTML / JSON / 표 형태로 출력 요구
- 실무에서 가장 많이 사용되는 방식

#### 전략 1.3) 조건 충족 여부 확인
- 반드시 Output Validation 포함
- 예: `조건이 충족되지 않으면 "조건 불충족"이라고 출력`

#### 전략 1.4) Few-Shot Prompting
- 예시를 직접 포함하여 학습 효과 유도
- "보기처럼 따라하라" 방식

---

## 🧠 전략 2: 모델에게 생각할 시간 제공

> 복잡한 문제는 단계별 사고 유도

#### 전략 2.1) 작업 단계를 명시
- **Step-by-step reasoning** 지시
- 예:  

```text
문제를 풀 때 3단계로 사고해라:

1. 문제 분석

2. 핵심 정보 도출

3. 최종 답안 작성
```


#### 전략 2.2) 성급한 결론 금지
- “먼저 생각을 설명한 뒤 답을 제시해라(Chain of Thought)”
- (내부 reasoning이 노출되기 싫으면 다음 기법 사용👇)

---

## 🔥 최신 Prompt Engineering 핵심 기술 추가

> 아래는 **최근 LLM 시대 필수 Prompt 전략**

---

### 3.1 CoT (Chain of Thought) / 숨겨진 추론 활성화

- 명령 예시:  
“천천히 단계적으로 사고해라”
- 추론 품질 향상
- 민감 데이터 공개 방지 → 아래 기법 사용👇

---

### 3.2 *심플한 최종 답만*: **Answer-only**
- 내부 추론은 숨기고 결과만 출력
- 예: 단계별로 생각하되 최종 답만 출력해라.


---

### 3.3 ReAct Prompting (Reason + Act)
- **추론 + 행동(검색/도구 사용)**을 통합
- 검색 기반 시스템에 매우 유용

---

### 3.4 Self-Critique / Self-Refine

- 모델에게 **자체적으로 검증 + 수정**시키기
- 예:
1) 초안 생성
2) 오류 피드백
3) 수정 반영

---

### 3.5 Instruction Hierarchy (역할 + 맥락 + 규칙)

최고 성능을 위한 구조화 Prompt 템플릿:

```text
[역할지시] 당신은 전문 번역가다.
[목표] 아래 문장을 정확하게 한-영 번역하라.
[요구 형식] JSON 형식으로 출력.
[제한 조건] 의미 왜곡 없이 / 은유는 그대로 유지
[입력] "나는 구름 위를 달렸다"
```


---

### 3.6 Negative Prompting
- 하면 안 되는 것 명확히 지시
- 예:
  - "설명 길게 하지 마"
  - "사실과 다른 내용을 만들어내지 마(Hallucination 방지)"

---
