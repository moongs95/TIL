# 2-3. 데이터 수집 시 주의 사항 ③ 윤리 (Ethics)

## 01. 인공지능 윤리

### 1.1 인공지능 윤리

**인공지능의 사회적 영향력**  
인공지능의 급격한 발전은 사회 전반에  
긍정적·부정적으로 모두 큰 영향을 미치고 있음

---

### 인공지능의 윤리적 이슈들

- 안전성 및 신뢰성
- 프라이버시
- 기술 오남용
- 책임성
- 인간 고유성 혼란
- AI 포비아(AI Phobia)

➡️ 향후 AI·로봇 관련 윤리 이슈를 예측하기 위해  
빅데이터 분석과 미래연구 기법을 활용하여 도출됨

- 2017년 연구에서 제시된 문제 중  
  여전히 해결되지 않은 이슈 다수 존재
- 실제 AI 서비스 배포 이후  
  **알고리즘 차별**, **선정성 문제** 등 추가 이슈 발생
  - 대부분 의도하지 않았으나 발생한 문제

---

### 인공지능 윤리 기준

과학기술정보통신부·정보통신정책연구원 발표  
**인공지능(AI) 윤리기준**

#### 3대 기본 원칙
- 인간 존엄성 원칙
- 사회의 공공선 원칙
- 기술의 합목적성 원칙

#### 10대 핵심 요건
- 투명성
- 안전성
- 책임성
- 데이터 관리
- 연대성
- 인권 보장
- 프라이버시 보호
- 다양성 존중
- 침해 금지
- 공공성

---

### 1.2 데이터 윤리

**데이터 윤리의 필요성**

- 인간은 자신이 속한 문화권과 경험의 영향을 받음
- 인공지능 역시 **학습 데이터의 영향을 그대로 반영**함

➡️ 인공지능 윤리는 데이터 윤리와 분리할 수 없음

#### 데이터와 직접적으로 연관된 핵심 요건 (5가지)
- **인권 보장**: 저작권·인권을 고려한 데이터
- **프라이버시 보호**: 개인정보 침해 방지
- **다양성 존중**: 편향되지 않은 데이터
- **침해 금지**: 유해하지 않은 데이터
- **데이터 관리**: 양질의 데이터 확보

---

## 02. 데이터 편향성

### 2.1 데이터 편향성 개요

**데이터 편향성(Data Bias)**  
데이터 분포가 특정 방향으로 치우쳐진 상태 또는 그 정도

- 편향된 데이터를 학습한 모델은  
  **의도치 않게 편향된 결과**를 도출할 수 있음
- 딥러닝 모델 학습은 베이지안 추론에 기반함
- 이를 서비스에 적용할 경우  
  **불공정한 차별**로 이어질 수 있음

**예시**
- 과거의 편향된 판례 데이터를 학습한 모델이  
  특정 인종에게 불리한 판단을 지속적으로 내리는 경우

---

### 2.2 데이터 편향성 사례

- 인종 차별 사례
- 성별 차별 사례
- 지역 차별 사례
- 기타 사회적 차별 사례

---

### 2.3 데이터 편향성 줄이기

**편향 완화 방법**

- **데이터 다양성 확보 및 균형 조정**
  - 다양한 소스에서 데이터 수집
  - 불균형한 라벨 분포 조정

- **편향 감지 및 수정 모델 활용**
  - 편향을 탐지·보정하는 알고리즘 적용

- **투명성과 책임성 강화**
  - 의사결정 과정 설명 가능성 확보
  - 서비스 운영 책임 명확화

---

## 03. 노이즈 필터링

### 3.1 노이즈 필터링 개요

**인간이 생성하는 노이즈 데이터**

- 모든 데이터를 그대로 학습할 경우  
  부적절한 데이터까지 함께 학습될 수 있음
- 따라서 **노이즈 필터링이 필수**
- 필터링을 위한 **대응 솔루션 데이터 확보** 또한 중요

---

### 사회적으로 문제가 될 수 있는 요소

아래와 같은 유해 요소를 탐지하는 문제를 통칭하여  
**Toxicity Detection / Explicit Content Detection**이라 함

- 텍스트의 경우  
  - **Hate Speech Detection**
- 선정성 탐지  
  - **Nudity Detection**

#### 주요 유해 요소
- **폭력적 내용**
  - 비속어·욕설
  - 폭력 행위, 음주·흡연 묘사

- **차별 발언**
  - 외모, 정치 성향, 나이, 성별, 종교 비하

- **선정적 내용**
  - 과도한 노출
  - 성인용품, 성적 엔터테인먼트

---

### 3.2 노이즈 필터링 방법

#### 비속어·유해 발언 필터링
- 직접 파이프라인 구현
- 또는 외부 API 활용

#### 관련 공개 데이터셋
- Toxic Comment Classification Challenge
- Hate Speech and Offensive Language
- Wikipedia Talk Labels: Toxicity
- SemEval-2021 Task 5: Toxic Spans Detection
- Korean HateSpeech Dataset
- Korean UnSmile Dataset
- K-MHaS (Korean Multi-label Hate Speech)
- 기타 다수

#### 선정적·폭력적 콘텐츠 필터링
- 직접 모델 및 파이프라인 구현
- 또는 API 기반 필터링 적용
