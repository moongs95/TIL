# 환경 관리툴

- 소프트웨어 개발에서 특정 프로젝트의 종속성과 설정을 관리하는데 사용되는 도구
- 프로젝트별로 격리된 개발 환경을 설정하고 유지하는 데 중점을 두며, 이를 통해 다양한 프로젝트 간의 종속성 충돌을 방지하고 일관된 개발 환경을 보장

## 종류

- Conda
- Virtualenv
- Pipenv
- Container 기술

### Conda

- 정의 : 오픈소스 패키지 관리 시스템 및 환경관리 시스템, Python 및 R과 같은 프로그래밍 언어를 위한 소프트웨어 패키지, 종속성 및 환경을 관리하는데 사용
- 특징 : 언어 독립적, 크로스 플랫폼, 환경 관리, 다양한 패키지
- 활용 : 패키지 설치, 환경 관리, 버전 관리
- 장점 : 패키지 호환성, 재현성, 효율성

### Virtualenv

- 정의 : Python의 가상환경을 생성하는 도구, 각 환경은 독립적으로 관리되며, 서로 다른 프로젝트에 대해 서로 다른 python 및 패키지 세트를 사용할수 있음
- 특징 : 환경 격리, 간편한 사용, 패키지 관리

### Pipenv

- 정의 : Pip와 virtualenv의 기능을 결합한 Python 개발을 위한 도구, Pipfile과 Pipfile.lock을 사용하여 프로젝트 종속성을 관리
- 특징 : 종속석 관리, 가상환경 통합, 보안 강화
