# 다층 퍼셉트론

- 모델(Model) = 뉴럴넷(neural network, NN) -> 다층 퍼셉트론(MLP)

## 뉴럴넷(Neural Network)개요

- 딥러닝이 등장하기 전 사람과 기계의 인지 과정이 어떻게 달랐는지를 생각
- 사람 혹은 동물의 뉴런을 모방하는 인공뉴런의 출현

### 사람과 기계

- 사람이 손글씨 숫자를 인식하는 과정

```text
 v1 : Motion -> v2 : Stereo -> v4 : Recognition -> MT(v5) : Attention
```

- 기계가 손글씨 숫자를 인식하는 과정 : 전통방식

```text
(1) 샘플들을 보면서 패턴을 파악(주요 특징을 빱아냄, Handcraft Feature)
(2) 주요 특징을 프로그래밍 언어로 표현
(3) 의사 결정 룰을 정함
-> 특징을 뽑는 걸 사람이 설계
```

- 기계가 손글씨 숫자를 인식하는 과정 : 뉴럴넷 방식 => 자동으로 특징들과 의사 결정 룰을 찾아냄

### 뉴런과 인공 뉴런

- 사람의 뉴런을 유사하게 한 인공 뉴런
- 입력 -> 가중치 -> transfer function -> activation function(퍼셉트론, 시르모이드 뉴런) -> 출력

## 퍼셉트론(Perceptron)

### 퍼셉트론의 구조

- 1957년 코넬 항공 연구소의 프랑크 로젠블라트에 의해 고안된 가장 간단한 형태의 Feed-Forward 네트워크
- 입력 신호 : 다음 뉴런과 연결되어 있음 cf. 연결이 안되려면 가중치를 0
- 정해놓은 임계치보다 크면 1, 아니면 0으로 출력 -> 출력값이 on/off로 구성된 것이 퍼셉트론
- 다수의 신호를 입력받아 하나의 신호를 출력
- 퍼셉트론 예시 : 이진수 입력, 이진수 출력, 스텝함수
- 단일 퍼셉트론만 가지고도 많은 것을 할 수 있음
- 가중치와 임계치를 변화시키며 다양한 의사 결정 모델을 만들 수 있음(이진수로 표현)
- 파라미터(w)가 바뀜에 따라 의사결정이 달라짐

### 퍼셉트론의 원리

- 하나의 퍼셉트론이 기하적으로 어떤 의미를 갖는지 이해
- h = (x1·w1) + (x2·w2)
- h > b -> 1

#### 퍼셉트론과 선형 분리

- 퍼셉트론을 일반화하면 선형식을 통한 분리로 이해할 수 있음 -> 선형 분리 가능성
- 공간을 선으로 분리할 수 있음(출력을 예상)
- AND, OR, NAND 등의 로직을 구현할 수 있게 됨

```text
NAND gate(전기 회로 근간 연산)는 “universal for computation(어떠한 연산)”으로 알려져 있고, 이는 어떤 모델이든 NAND gate의 조합으로 표현 가능 ⇒ universal_approximation_theorem
퍼셉트론이 NAND gate를 묘사할 수 있으면 여러 퍼셉트론으로 구성된 NN은 어떠한 연산(모델)이든 가능함. → 선형분리로 묘사할 수 있음
→ 하나의 퍼셉트론으로 낸드게이트를 표현

BUT...
XOR 논리 게이트는 하나의 퍼셉트론으로는 구현이 불가능함을 1969년 Minsky가 “Perceptron”을 통해 증명하였다. 그러나 여러 층의 퍼셉트론을 활용하면 분리가 가능하며, 이를 다층 퍼셉트론의 비선형 분리 가능성이라고 한다. 즉 퍼셉트론들의 조합으로 어떠한 연산이든, 어떠한 입출력 관계든지 표현이 가능하다! ⇒ non_linear_separability(여러 선을 사용한다는 뜻은 비선형이라는 뜻)
→ 여러개의 퍼셉트론으로 XOR게이트를 표현
```

## 다층 퍼셉트론(Multi-Layer Perceptron)

### 모델 개요

- 퍼셉트론을 사용하지 않더라도 Multiple Layer Networks가 아닌 MLP로 불리기도 함
- 또한, Fully-Connected Layers(FCs)의 동의어로 사용

### 활성화 함수(Activation Function)

- 입력 신호의 총합을 출력신호로 변환하는 함수
- 활성화 함수를 사용하는 이유 : 활성화 함수가 없는 다층 퍼셉트론 모형 = 단순한 선형식, 비선형식으로 구분하는게 더 좋을 때가 있음
- 활성화 함수의 종류 : Step, Sigmoid, tanh, ReLU, Leaky ReLU, Maxout, ELU

#### 시그모이드 함수 (Sigmoid Neuron / Sigmoid Function)

- 연산과정 전체를 미분 가능하게 만드는게 큰 목적 => 역전파 기법과 관련
- 이진수에서 0~1 사이 값으로 출력이 변경

### MLP의 구조

```text
- 노드(node)/뉴런(neuron) : Transition (z) + Activation Function
- 레이어/층(layer)-  입력층(input layer)-  은닉층(hidden layer)-  출력층(output layer)
- 엣지(edge), 커넥션(connection) : 가중치(weight)를 의미
```

- MLP에서 레이어 수는 보통 (은닉층수+1)개를 의미
