# 비지도학습 방법론

## 비지도학습이란?

### 비지도학습의 정의

- 학습용 Ytrain을 활용하지 않고 입력 데이터 x로만 모델을 학습하는 방법론
- 입력 데이터 사이의 유사성, 관계활용, 행렬 분해 등 별도 방법으로 구조 분석
- 입력값에 내재된 정보로 가상의 라벨 생성하거나 자기 자신을 라벨로 활용
- Manifold Hypothesis : 일반적인 고차원 데이터들은 가능한 모든 데이터의 공간에 완전히 고르게 분포하는 것이 아니라 매우 적은 차원의 매니폴드(곡선과 유사한 개념)를 이루고 있을 것

### 비지도학습의 예시

- 차원축소 : PCA 고차원 데이터의 정보를 최대한 보존하면서 훨씬 적은 차원으로 표현
- 시각화 : t-SNE 구조를 변경하지 않음
- 노이즈 제거 : 차원축소를 하면 정보가 유실된다는 사실을 역으로 활용
- 군집화 : k-Means, DBSCAN 데이터 간의 유사성, 관계를 통해 여러 개의 자연스러운 군집으로 나누는 문제
- 이상값 탐지 : 일반적인 인풋값과 전혀 다른 이상값을 찾아내는 문제
- 단어 임베딩 : 자연어 처리에서 사용하는 방법론, 영어나 한국어 같은 자연어 단어들을 의미적인 연산이 가능한 임베딩 공간에 매핑
- 생성모델 : 저차원 임베딩 공간에서 원래의 이미지 공간으로 가는 함수를 학습해 기존에 없던 새로운 feature를 가진 샘플을 만들어냄

## 고차원 데이터의 이해

### 고차원 데이터란?

- 데이터 내 feature가 많아 차원이 높은 데이터
- 현실은 고차원
- 스마트폰 사진, 동영상 데이터, 음성 데이터

### 고차원에서 생기는 문제점들

- 컴퓨터 자원의 사용량
- 차원에 따른 데이터의 Sparsity 문제
- 직관적으로 이해하기 힘듦
