# 🌟 자연어처리(NLP)

---

# 1. 개요: 왜 자연어 처리인가?

AI는 이미 일상의 거의 모든 서비스 속에 깊게 스며들었다.

### ● 일상 속 AI 예시
- 추천 시스템 (유튜브, 넷플릭스)
- OCR (문서 인식)
- 영상 요약 / 자율주행
- IBM Watson / AlphaGo
- AI × Journalism / Art / Healthcare
- ChatGPT, Copilot 등

### ● AI를 구성하는 4대 핵심 영역
- **머신러닝(두뇌)**: 데이터를 바탕으로 학습
- **자연어 처리(귀)**: 인간 언어 이해/생성
- **로보틱스(육체)**: 물리적 행동
- **컴퓨터 비전(눈)**: 영상·이미지 이해

---

# 2. 자연언어처리란 무엇인가?

## 2.1 자연언어(Natural Language)
- 인간이 일상에서 자연스럽게 사용하는 언어  
  (한국어, 영어 등)
- 인공언어(파이썬, C 등)의 반대 개념

## 2.2 자연언어처리(NLP)
- 컴퓨터가 인간 언어를 이해(분석)하고 생성하도록 만드는 기술
- 형태소 분석 → 구문 분석 → 의미 이해 → 텍스트 생성까지 포함

## 2.3 NLP의 두 축: NLU & NLG

### ● NLU (이해: Natural Language Understanding)
- 텍스트 분류
- 품사 태깅
- 감정 분석
- 개체명 인식 (NER)
- 질의응답(MRC)
- 의미 분석(Semantic Parsing)

### ● NLG (생성: Natural Language Generation)
- 문장 생성
- 번역
- 요약
- 언어 모델링

### ● 두 영역의 교집합
- 챗봇
- 기계 번역
- 요약
- 질의응답 시스템

# 3. 자연언어처리가 어려운 이유

언어는 규칙적이지 않고 예외가 많으며  
무한한 변형이 존재하기 때문에 컴퓨터에게 매우 어려운 분야다.

---

## 3.1 전통적 관점의 어려움

1. **다른 단어 → 유사한 의미**
   - 예: “먹다”, “섭취하다”, “드셔요”

2. **다른 표현 → 같은 의미**
   - 예: “밥 먹었어?”, “식사하셨어요?”

3. **다른 문법 → 같은 의미**
   - 예: “나는 밥을 먹었다” / “밥 먹음”

4. **같은 단어 → 문맥 따라 다른 의미**
   - “은행(금융)” vs “은행나무”

---

## 3.2 형태소 분석의 난점

- **중의성**: “배” (과일 / 신체 / 운송수단)
- **고유명사 처리**
- **사전에 없는 신조어 처리**

---

## 3.3 문맥 기반 모호성

- 주변 문맥에 따른 의미 변화가 크다.
- 단어 하나만으로 의미를 해석하기 매우 어려움.

---

## 3.4 표현의 중의성(ambiguity)

- 언어는 **최소한의 표현으로 최대 의미**를 전달
- 문장 생략이 많아 해석 어려움
  - “나 갔어.” → 장소 생략
  - “그거 해줘.” → 대상 생략

---

## 3.5 규칙의 예외성

- 숙어, 관용구는 규칙으로 일반화 불가
- 예: “발등에 불 떨어지다”

---

# 4. 왜 한국어 NLP는 더 어려운가?

한국어는 언어적 특성 때문에 NLP 난이도가 더 높다.

## 4.1 교착어(Agglutinative Language)

- 하나의 단어가 다양한 형태로 변형됨  
  예: 먹다 → 먹었고 / 먹을게 / 먹으니까 / 먹겠지만 …
- 조합이 무한에 가까워 형태소 분석이 매우 복잡

---

## 4.2 어순 자유도

- 한국어는 어순이 의미에 큰 영향을 주지 않음
- “나는 밥을 먹었다”  
  “밥을 나는 먹었다”  
  → 둘 다 자연스러운 문장

→ 컴퓨터가 문법적 구조를 파악하기 어려움

---

## 4.3 주어 생략

- 한국어는 주어를 자주 생략한다.
- “밥 먹었어?” → 누가? 언제? 생략
- 자연어 처리는 숨겨진 의미 추론이 필요해 난도 상승

---

## 4.4 띄어쓰기 문제

- 한국어는 띄어쓰기 규칙이 완전하지 않음
- 잘못된 띄어쓰기 빈번
- 띄어쓰기 없어도 의미 전달 가능한 구조
- NLP에서 토큰화가 매우 어려움

---

## 4.5 평서문·의문문 형태 동일

- “밥 먹었어”  
- “밥 먹었어?”  
→ 문장부호가 없으면 구분 불가

# 5. 일상 속의 NLP 활용

자연어처리는 이미 다양한 서비스에 사용된다.

## 5.1 주요 응용 분야

- 문법 교정 (GEC)
- 음성 인식
- 기계번역 / 실시간 번역
- 정보 추출 / 검색
- 질의응답 시스템 (QA)
- 문서 요약
- 챗봇
- 생성형 AI (에세이, 기사, 창작)

---

## 5.2 산업군에서의 NLP 활용

- 자동완성(AutoComplete)
- 검색 엔진
- 문서 요약
- 문서 질의응답
- 기업용 Chat-Bot
- AI Assistant (Copilot 등)
- ChatGPT 기반 Plugin 생태계

---

# 6. 핵심 요약

## ✔ 자연어 처리란?
사람의 언어를 컴퓨터가 **이해하고 생성**하도록 만드는 기술.

## ✔ 어려운 이유?
- 모호성, 중의성, 규칙의 예외성
- 문맥 의존성
- 특히 한국어는 조어 규칙·어순·띄어쓰기 때문에 난도가 매우 높음

## ✔ 어디에 쓰임?
- 검색, 번역, 음성인식, 챗봇, 요약 등
- 산업 전반에서 필수 기술로 자리잡음
