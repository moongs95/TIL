# 추천시스템 & 시계열 데이터

## 추천시스템이란?

- 데이터를 활용, 기하급수적으로 많은 옵션들 중에서 사람들이 원하는 것이 무엇인지 예측하고 범위를 좁혀주고 찾아주는 머신러닝의 한 분류
- 추천시스템은 기업이 돈을 벌도록 해주는 수익 모델과 직접적으로 연관된 경우가 많아 수많은 분야에서 매우 오래전부터 연구
- 다양한 형태의 데이터 활용, 문제정의 통해 접근, 딥러닝 이전에도 연구, 많은 정형데이터 활용기법

### 구성요소

- 사용자
- 아이템 또는 콘텐츠
- 활동기록
- 피드백
- 유저프로필

## 다양한 형태의 추천시스템

### 추천시스템 활용의 예시

- 스트리밍 서비스
- 소셜 네트워크 서비스
- 교육 서비스
- 헬스 케어 서비스
- 금융 서비스
- 광고 플랫폼 추천시스템

### 결과값 예측

- 분류 모델링 : 구매 여부
- 회귀 모델링 : 선호도
- 비지도 학습 : 유사성 판단, 순위 예측

## 기초 추천시스템 모델링 방법론

### 추천시스템 기초 방법론

- 인기도 기반 추천시스템
- 연관규칙
- 콘텐츠 기반 추천

### 협업 필터링

- 사용자들 또는 아이템 사이의 유사성을 기반으로 작동하는 추천시스템 방식
- 코사인 유사도 : 두 벡터 사이의 내적 값을 길이의 곱으로 나누어 계산
- 기억 기반 협업 필터링 : 사용자-아이템 행렬을 기반으로 사용자들 사이, 아이템 사이의 유사성 판단
- 잠재요인 분석 : 임베딩과 같은 개념으로 유저들의 아이템에 대한 선호도, 특정 피쳐에 대한 선호를 나타내는 잠재요인을 찾아내도록 학습

### 협업 필터링 방식의 한계점

- 콜드 스타트 문제
- 개인정보 문제
- 시간에 따른 선호도 변화 문제

## 시계열 데이터의 처리

- 시계열 데이터 : 동일한 간격으로 연속된 시각에 취한 순차적 데이터
- 순차적 데이터 : 순서를 가지는 데이터

### 시계열 데이터의 구성성분

- 불규칙 성분 : 노이즈
- 규칙 성분(체계적 성분) : 패턴이나 경향성에 의해 설명, 예측 가능한 변동 성분
- 추세 : 점차 증가, 점차 감소, 방향성, 인구 수, 전세계 평균기온
- 계절성 : 정기적 변화, 성수기 비수기, 평일 주말, 낮과 밤
- 순환성 : 주기적으로 변화하지만 일정하지 않은 주기

### 시계열 데이터의 특성

- 기술적 분석
- 예측적 분석
- 독립 항등 분포
- 자기 상관
- 마르코프 속성
- 시계열의 정상성

## 시계열 데이터의 모델링 방법론

### 시계열 데이터의 분석 과정

1. 정상성 검정으로 데이터 정상성 여부 먼저 판단
2. 정상적 데이터로 전처리(분해)한 뒤 모델 구성
3. 평균이 일정, 분산 및 공분산에 연속적인 상관성이 없도록 변환

### 시계열 데이터의 성분 분해

- 시계열 데이터는 여러가지 구성 성분의 합 또는 곱으로 이루어짐.
- 각 성분으로 분해하여 예측, 계절성 따른 변화 조정하는데 활용
- 계절성, 추세와 불규칙 성분으로 분해하는 계절성 분해

### 이동평균과 자기회귀 모델

- 이동 평균 모델 : p기간 안의 시계열 데이터를 평균하여 시간 t의 추세 주기를 측정 -> 장기 추세에 유리
- 자기 회귀 모델 : 시계열의 특성 스텝(t)를 예측하기 위해 일정 스텝 수(p)만큼의 과거 데이터(t-p부터 t-1까지)들을 입력값으로 선형회귀모델 학습
