# 1-3. 데이터 수집 ③ 오픈 소스 (Open Source Data)

## 01. 오픈 소스 데이터

### 1.1 오픈 소스 데이터 개요

**오픈 소스(Open Source)**

- **오픈 소스 소프트웨어**  
  누구나 특별한 제한 없이 코드를 보고 사용할 수 있는  
  오픈 소스 라이선스를 만족하는 소프트웨어

- **오픈 소스 데이터**  
  오픈 소스 소프트웨어와 유사하게  
  누구나 특별한 제한 없이 접근 및 이용이 가능한 데이터 / 데이터셋

---

### 오픈 소스 데이터의 필요성

#### 데이터를 활용하는 입장

- 데이터 수집 방법 중 **가장 쉽고 빠른 방식**
  - 다운로드만으로 즉시 사용 가능
  - 사용 제약이 비교적 적음
  - 이미 방대한 데이터셋이 공개되어 있음  
    - 예: Kaggle (25만 개 이상, 2023.09 기준)

- **연구 및 모델 성능 비교에 적합**
  - 다수의 연구에서 오픈 소스 데이터를  
    **벤치마크(benchmark)** 로 사용
  - 동일 데이터 기준으로 성능 비교 가능

#### 데이터를 구축하는 입장

- 기존 오픈 데이터셋을
  - 그대로 활용하거나
  - 수집·라벨링 방식을 참고하여 재구성 가능
- 라벨링 가이드, 규칙, 레퍼런스를 얻기 쉬움
- 목적에 맞는 데이터셋을 **더 효율적으로 구축 가능**

---

## 02. 오픈 소스 데이터 플랫폼 (국내)

### 2.1 개요

**국내 오픈 소스 데이터 현황**

국내에서는 빅데이터 산업 수요 증가에 따라  
공공기관 중심으로 데이터 개방이 확대됨

#### 통계 데이터 개방
- (2007) 국가통계포털 **KOSIS** 오픈
- (2016) 행정자료이용센터 오픈  
  → (2020) 통계데이터센터로 명칭 변경

#### 공공 데이터 개방
- (2011) 국가공유자원포털 오픈  
  → (2013) 공공데이터포털로 명칭 변경
- (2012~)  
  - 서울 열린데이터광장  
  - 식품안전나라 등  
  다양한 공공데이터 플랫폼 등장

#### AI 인프라 구축
- (2018) **AI 허브(AI Hub)** 오픈
- (2019~) 매년 인공지능 데이터 구축 사업 진행

---

### 2.2 대표적인 플랫폼

**국내 주요 오픈 데이터 플랫폼**

- **공공데이터포털**  
  공공기관이 생성·관리하는 데이터를  
  통합 제공하는 플랫폼

- **서울 열린데이터광장**  
  환경, 교통, 인구 등  
  서울시 시정 전반 데이터 제공

- **AI 허브 (AI Hub)**  
  인공지능 데이터 구축 사업으로 생성된  
  오픈 데이터 제공 플랫폼  
  - AI 데이터
  - AI SW API
  - 컴퓨팅 자원 지원

- **기타**
  - 각 부처 및 지자체별 데이터 포털

---

## 03. 오픈 소스 데이터 플랫폼 (해외)

### 3.1 대표적인 플랫폼

**해외 주요 오픈 데이터 플랫폼**

- **Kaggle**
  - 데이터 과학 / 머신러닝 대회 플랫폼
  - 다양한 오픈 데이터셋 제공
  - 사용자 작성 노트북(Notebook) 열람 가능

- **Hugging Face**
  - NLP / 멀티모달 중심 데이터셋
  - 모델, 데이터, 토큰라이저 통합 제공

- **Papers With Code**
  - 논문 + 코드 + 데이터셋 연계 제공
  - 최신 연구 동향 및 벤치마크 확인 가능

- **UCI Machine Learning Repository**
  - 전통 머신러닝 데이터셋 저장소
  - 예: Iris, Wine, Adult 등

- **국가별 공공데이터 포털**
  - 미국, EU, 일본 등 각국 정부 주도의 데이터 개방 플랫폼
