# 모델 평가와 개선

## 모델 평가의 기초

### 모델 평가의 중요성과 복잡성

- ML 모델 학습시키면 어떻게든 손실함수 0으로 가지만 결과로 나온 모델이 완벽히 원하던 기능을 하는 경우는 거의 없음
- 데이터 셋은 사람의 판단을 모아놓은 것으로 구성과정에서 의도하지 않았더라도 사람이 가진 편견이나 선입견 등이 반영

### 모델 평가의 구성요소

- 정성평가 : 모델에 들어가는 입력값과 그에 따른 모델의 출력값을 사람이 직접 확인해보면서 모델의 성능이 어떤지 판단
- 정량평가 : 모델의 성능이 얼마나 좋은지 수치로 나타내는 평가지표
- 정량, 정성 모두 적절히 활용해야 함.
- Train-Test 데이터 셋 분할 : 일반화 성능 측정
- 검증용 데이터 셋
- 모델의 복잡도 : 모델이 더 복잡하고 어려운 데이터까지 학습할 수 있는 용량, 파라미터 수가 많을 수록 복잡도 커짐
- 과적합 : 모델이 학습데이터의 패턴에만 과하게 학습, 새로운 데이터에서 성능 떨어짐
- Regularization : 과적합 방지

## 모델의 일반화 성능과 데이터셋의 분할

### 데이터셋의 적절한 분할 방법

- 2분할 : 학습용/검증용
- 3분할 : 학습용/검증용/평가용
- 검증용 데이터셋의 성능평가 결과는 모델의 구조를 결정하는 하이퍼파라미터 최적화와 학습완료된 모델의 선별에 사용
- k-fold 교차 검증
- 내삽 : 학습 데이터셋 범위 내에서 새로운 데이터 예측 또는 분류
- 외삽 : 학습 데이터셋 범위 넘어서는 새로운 데이터 예측 또는 분류
- 일반화 성능 : 외삽 성능, 내삽 성능을 포함, 모델이 처음 접하는 데이터에서 얼마나 좋은 성능을 내는지
- 시계열 데이터의 검증 : 가장 최근 데이터 검증용, 그보다 이전 데이터 학습용, 현시점 이후 미래 데이터 평가용
- 데이터셋의 계층적 분할 : 특정 클래스 샘플이 매우 적을 경우 클래스별로 나누어 각각 랜덤분할 후 다시 합치는 계층적 분할 방법 사용

## 기초정량평가 방법론

### 다양한 문제의 정량평가 지표

- 최소화 지표, 최대화 지표
- 혼동 행렬
- 분류 문제 : 정밀도, 재현율, F1-Score, ROC, AUC
- 회귀 문제 : MAE, MSE, RMSE
- 그 외 : 편집거리, MOS(음성), 모델 기반의 정량평가(이미지), 인퍼런스 시간, 처리율, 메모리 사용량(컴퓨팅 자원)

### 정량평가의 체계적인 활용

- 문제마다 상황마다 다르게 정량평가 지표를 선택
- 각 평가지표 특성 이해하는 것이 중요
- MAE는 오차가 0인지 아닌지, MSE는 이상치에 민감
- 여러 정량평가 지표를 함께 활용
- 지표들끼리 충돌하는 경우엔 최적화지표, 충족 지표

## 체계적인 정성평가 방법론

### 정성평가의 중요성

- 측정되지 않는 정성평가
- 정량평가만으로는 모델이 가진 여러 심각한 문제가 드러나지 않음
- 평가용 데이터셋의 대표성
- 모델의 이해할 수 없는 오답패턴
- 평가지표 자체의 빈틈
- 데이터셋과 모델의 정성평가가 있음

### 정성평가의 단점과 지속가능한 정성평가를 위한 팁

- 정성평가는 확장성이 떨어지고 주관성을 배제하기 힘듦
- 정성평가 과정에 대한 대략적인 분석이 필요
- 샘플 관찰 계획 세우기
- 점진적 정성평가 프로세스
- 발견된 이슈의 기록 및 분류

## 모델 에러의 분석

### 머신러닝 모델의 최적화

- 과적합 : 모델 복잡도를 줄이거나 학습 데이터를 늘림 -> 큰 편향 때문에 발생
- 과소적합 : 모델 복잡도를 늘리거나 학습 데이터를 줄임 -> 큰 분산 때문에 발생

### 최적화 문제의 진단과 해결

- 편향 : 예측값과 목표값 사이 발생하는 에러의 평균적 크기
- 분산 : 모델의 예측값이 서로 퍼져있는 정도
- 편향과 분산은 trade-off 관계
- L1, L2 Regularization : 모델 복잡도가 높은걸 직접적으로 제한을 걸어 복잡도를 낮춤. -> L1 또는 L2 norm을 손실함수에 더함(라쏘, 릿지)
- 학습 데이터 증강(Augmentation)
- Early Stopping
