# 지수함수와 로그함수

## 지수와 로그

- 지수(Exponentiation) : power function과 모습은 같지만 변수가 지수
- 로그(log) : base a에 x가 나오게 하는 y값을 찾음, a에 몇제곱(y)을 해야 x가 나오는지

## 자연상수와 지수/로그함수

- 일반적인 공학분야에서는 지수와 로그의 base를 자연상수 e로 다루는 경우가 압도적으로 많음(ln)
- 컴퓨터 공학에서는 이진수를 다루는 경우가 많기 때문에 base를 2로 다루는 경우가 많음
- 상용로그는 base가 10

## 지수함수

- base가 상수, 지수가 변수
- f(x)=a^x : domain은 실수 전체, 출력은 항상 양수(0, 무한대), 증가함수(빠름)
- f(x)=a^(-x) : domain은 실수 전체, 출력은 항상 양수, 감소함수(빠름)
- 점근선 : y=0

## 로그함수

- 지수함수의 역함수(x -> y, y -> x)
- f(x)=log_2x : domain이 (0, 무한대), range가 실수(지수함수와 domain, range가 반대), 증가함수
- f(x)=log_(1/2)x : domain이 (0, 무한대), range가 실수(지수함수와 domain, range가 반대), 감소함수
- 점근선 : x=0

## 증가함수의 비교

- 지수함수 > 멱함수 > xlogx > x > logx
- 천천히 증가할 수록 좋은 알고리즘
