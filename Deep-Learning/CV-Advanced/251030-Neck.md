# Neck

## Neck Recap
- FPN: 다양한 크기의 객체를 더 잘 탐지하기 위해 여러 layer의 feature map을 함께 활용하는 모델 (lateral connection)

## Detector 구조
1. Backbone : Input image를 입력받아 feature map을 생성하는 feature extractor
2. Neck : 다양한 scale의 feature map을 통합 (FPN 및 이후 발전 모델)
3. Head : feature map을 바탕으로 최종적인 객체 탐지 수행 (RPN, RoI projection 등의 모듈 활용)
