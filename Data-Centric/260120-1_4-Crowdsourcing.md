# 1-4. 데이터 수집 ④ 크라우드 소싱 (Crowdsourcing)

## 01. 크라우드소싱 개요

### 1.1 크라우드소싱이란?

**크라우드소싱(Crowdsourcing)**  
기업 활동의 일부 과정에 **일반 대중을 참여**시키는 방식

➡️ 인공지능 데이터 구축 과정에서  
**데이터 수집 또는 라벨링 작업을 일반 대중에게 위임**하는 형태로 활용됨

- **크라우드 워커(Crowd Worker)**  
  기업의 업무 용역을 대행 수행하고  
  그에 상응하는 대가를 받는 일반인 작업자  
  - 재택근무 형태 가능
  - 자유롭게 할당된 과제를 수행하는 경우가 많음

---

### 크라우드소싱 프로세스

작업 의뢰  
→ 미션 업로드  
(작업자용 앱에 교육자료 + 데이터 생산 미션 업로드)  
→ 미션 전달  
(품질 기준 전달)  
→ 미션 수행  
(작업 모니터링)  
→ 전수 검사  
(숙련 작업자를 선별하여 100% 검사)  
→ 데이터 전달  
(전수 검사를 통과한 고품질 데이터)  
→ 보상 지급  
(통과한 작업자에게만 지급)

---

### 크라우드소싱 프로세스 예시 – 크라우드웍스

1. **요구사항 정의**  
   - 데이터 컨설턴트가 고객사 요건 분석
   - 프로젝트 조건 정의

2. **워크플로우 설계**  
   - 고객사 요구사항에 맞춘 데이터 제작 흐름 설계

3. **데이터 라벨링**  
   - AI 보조 라벨링 활용
   - 복잡한 작업은 ML 기반 어시스턴트로 효율 향상

4. **데이터 검수**  
   - 충분한 작업 이력과 성능이 검증된 라벨러가 검수 수행

---

### 1.2 크라우드소싱 사례

**크라우드소싱을 통한 데이터 수집 예시**

- **이미지 데이터**
  - 특정 개체가 담긴 사진 촬영

- **음성 데이터**
  - 특정 문장 녹음

- **텍스트 데이터**
  - 특정 상황에 대한 감정 표현 수집

➡️ 명확한 **요구사항 정의**가 품질을 좌우함

## 02. 크라우드소싱 업체

### 2.1 국내 크라우드소싱 업체

**국내 주요 업체**
- 딥네츄럴 (DeepNatural)
- 셀렉트스타 (SELECTSTAR)
- 크라우드웍스 (Crowdworks)
- 텍스트넷 (TEXTNET)
- 기타 다수 업체

➡️ **비용 · 편의성 · 목적**에 따라 업체 선택
