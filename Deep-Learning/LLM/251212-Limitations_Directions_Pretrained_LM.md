# 사전학습 기반 언어모델의 한계점 및 방향성

## 1. 사전학습 기반 언어모델의 한계

### 주요 한계점 개요
1. 일반화 능력의 한계
2. 사람의 선호도 기반 답변 불가
3. 지식의 오래됨과 업데이트 문제
4. 계산 비용 및 환경 문제
5. 데이터 편향 및 윤리적 문제
6. **할루시네이션 (Hallucination)**

---

### 1) 일반화 능력의 한계

#### 라벨링된 데이터의 부족
- **기존 사전학습 모델: 사전학습 → 미세조정의 2단계 과정**
- 라벨링 데이터가 많이 필요하며, 부족할 경우 기대 성능을 얻을 수 없음
- 라벨링된 데이터를 만드는 과정은 많은 노동력 필요

#### 미세조정 후 모델의 일반화 능력 상실
- **사전학습된 모델을 미세조정할 경우, 일반화 능력이 상실됨**
- **사전학습 단계에서 가지고 있던 지식 대부분이 미세조정 과정에서 사라짐**

**예시**:
```
사전학습 BERT vs 의료 진료 분석으로 미세조정된 BERT

테스트 문장:
1. "서울에서 부산까지 KTX로 얼마나 걸리나요?"
2. "떡볶이는 매운맛과 달콤한맛 두 가지가 있어요."

결과:
- 사전학습 BERT: 두 문장을 어느정도 이해함
- 미세조정된 BERT: 위의 두 문장을 의료 용어로 혼동함
```

---

### 2) 사람의 선호도 기반 답변 불가

#### 문제점
- **사람의 선호도에 대한 정보를 가지고 있지 않아 사용자가 원하는 답변을 주기 어려움**
- 사람의 선호는 매 상황마다 다를 수 있음
- 모델이 생성한 결과의 좋고 나쁨은 사전학습 모델링 기법으로 극복 불가

**예시**:
```
사용자: "커피와 차 중 어느 것을 살까요?"
모델: [긴 설명 제공]
사용자: "간단하게 설명해줘"

문제: 기존 미세조정된 언어모델은 "간단하게 설명해줘"라는 
      두 번째 요청을 단독으로 처리할 수 없음
```

---

### 3) 지식의 오래됨과 업데이트 문제

#### 핵심 문제
- **기존 사전학습 모델은 사전학습 당시 사용된 데이터의 지식을 바탕으로 학습**
- **변화하는 지식을 대처하기 위해서는 새로 사전학습을 진행해야 함**

#### 구체적 문제 사례

**1. 새로운 지식 처리 불가**
```
예시: 2018년까지 데이터로 학습된 사전학습 모델
→ 2019년에 발병한 COVID-19에 대한 지식이 없음
```

**2. 변화하는 지식 처리 불가**
```
예시: 2018년까지 학습된 사전학습 모델
→ Brexit가 EU 탈퇴 논의를 거치는 것으로 학습
→ 2020년에 EU 탈퇴가 완료된 현재 시점에서는 잘못된 지식으로 처리
```

---

### 4) 계산 비용과 환경 문제

#### 문제점
- **사전학습 모델 학습 및 사용은 기술적 혁신을 가져오는 반면, 상당한 탄소를 배출하여 심각한 환경 문제 야기**
- 모델을 훈련하고 유지하는 데 필요한 방대한 자원

#### 구체적 수치
```
LLaMA2 모델 학습
- 539톤의 CO2 배출
- 163 가구가 1년 사용할 수 있는 전력량에 해당
```

---

### 5) 데이터 편향 및 윤리적 문제

#### 데이터 편향 문제
- 사전학습 모델은 특정 코퍼스로 학습되어 해당 코퍼스에서 자주 등장하는 특성으로 편향됨
- 성별, 인종, 종교 등의 편향 발생

#### 주요 편향 유형

**1. Gender Bias (성별 편향)**
- 성별에 따라 단어나 문장을 다르게 해석하는 편향
- 예시:
  - 의사를 남성으로 가정
  - 간호사를 여성으로 가정

**2. Racial Bias (인종 편향)**
- 특정 인종이나 민족에 대해 부정적인 연관성을 가지는 편향
- 예시:
  - 흑인이 입력되었을 때, 범죄와 관련된 단어 확률이 증가
  - 오바마의 사진을 백인 남성으로 예측하는 AI 모델

**3. Age Bias (연령 편향)**
- 특정 언어에 대해 불공정한 처리 등을 하는 편향

**4. Socioeconomic Bias (사회경제적 편향)**
- 경제적 지위에 따라 선입견을 가지는 편향
- 예시:
  - 저소득층은 범죄율이 높다는 등의 경제적 스테레오타입 반영

#### 중요 사항
```
⚠️ 모든 편향(bias)이 나쁜 것은 아니지만,
Social bias 등과 같은 사회적 이슈를 발생할 수 있는 편향은
모델이 독성 정보를 생성할 수 있음
```

### 6) 할루시네이션 (Hallucination)

#### 정의
- **모델이 사실과 무관하거나 존재하지 않는 정보를 생성하거나, 확인할 수 없는 정보를 생성하는 현상**

#### 할루시네이션 유형

**1. Intrinsic Hallucination (내재적 환각)**
- Source에 있는 정보들을 사용해서 합성된 잘못된 정보가 결과로 나온 경우
- 원본 정보는 있지만 잘못 조합된 경우

**2. Extrinsic Hallucination (외재적 환각)**
- Source에서 찾을 수 없는 정보가 등장한 경우
- 완전히 새로운 (존재하지 않는) 정보를 만들어낸 경우

#### 특징
- **할루시네이션은 대부분 생성모델에서 발생**

## 2. 미래 지향적 언어모델 개발 방향

### 주요 개발 방향
1. 지속가능한 모델 개발
2. 사람의 선호도 기반 모델 개발
3. 계산 비용 감소 연구 추진
4. 데이터 편향 완화 기술 개발
5. 모델 해석 가능성 및 투명성 강화

---

### 1) 지속가능한 모델 개발

#### Continual Learning (지속 학습)
- **데이터 수집, 정제, 모델 학습, 테스트까지 자동화하여 지속적인 LM 업데이트**
- **주요 목표**: 새로운 정보를 학습하면서, 이전에 학습한 지식을 잊지 않도록 학습

#### RAG (Retrieval-Augmented Generation) - 검색기반 생성모델
- 생성모델 하나가 아닌, **검색모델과 생성모델을 같이 사용**하여 작동
- 검색모델에서 사용되는 데이터베이스로 새로운 정보를 생성모델에게 전달
- **검색모델과 생성모델을 따로 학습하지 않고, 데이터베이스 업데이트만으로 정보 업데이트 가능**

**장점**:
```
기존 방식: 새로운 정보 → 모델 재학습 필요 (비용 ↑)
RAG 방식: 새로운 정보 → 데이터베이스만 업데이트 (비용 ↓)
```

#### Self-Improvement (자가 개선)
- **인간의 개입 없이 모델 추론 결과를 통해 잘 모르는 지식을 스스로 개선**하게 하는 학습 방법
- 라벨링되지 않은 데이터를 활용하여 잘 모르는 지식들을 일부의 데이터만 추출해 학습하는 것이 트렌드

---

### 2) 사람의 선호도 기반 모델 개발

#### In-context Learning
- **Task description 혹은 프롬프트를 통합하여 추론 중에 파라미터를 업데이트하지 않고 답변 생성**
- 모델은 주어진 예시를 통해 학습 없이 Few-shot inference 가능
- **Task description의 활용으로 사람의 선호도를 반영할 수 있음**

**예시**:
```
프롬프트: "다음 질문에 간단하게 한 문장으로 답변해주세요."
→ 모델이 간단한 답변 생성

프롬프트: "다음 질문에 자세하게 설명해주세요."
→ 모델이 자세한 답변 생성
```

#### Human Preference Tuning (인간 선호도 튜닝)
- **사람의 선호도 기반 데이터를 통해 LM을 사람의 선호도가 최상이 되도록 미세조정**하는 방법
- **대표적 방법**: RLHF, DPO 등

---

### 3) 계산 비용 감소 연구 추진

#### 학습에 적절한 Hyper-parameter 찾기
- **최적화를 통한 효율성 개선**

**예시**:
```
BERT-base 원래 학습:
- 16 TPU chips로 4일 동안 학습

최적화된 학습:
- 1개의 GPU로 하루 동안 학습
→ 동일한 성능 달성하는 연구 존재
```

#### 효율적인 모델 아키텍처 개발
- 작은 모델로도 높은 성능 달성 (DistilBERT, ALBERT 등)
- Quantization, Pruning 등의 기법 활용

---

### 4) 편향 완화 (Debias) 기술 개발

#### 개요
- **언어모델 혹은 데이터 내에 편향을 완화하는 연구 개발**

#### 주요 연구 방향
1. **데이터 전처리**: 편향된 데이터 제거 또는 균형 맞추기
2. **언어모델 개선**: 모델 구조 및 학습 방법 개선
3. **벤치마크 개발**: 편향 측정을 위한 평가 지표 개발

#### 최근 동향
- **LLMs 등장 이후로 더욱 화제가 됨**
- Human Preference Tuning이 편향 생성을 억제하는가에 대한 연구

---

### 5) 모델 해석 가능성 및 투명성 강화

#### 목표
- 모델이 어떻게 결정을 내리는지 이해 가능하도록 만들기
- 사용자에게 모델의 동작 원리를 설명할 수 있도록 개선

#### 중요성
```
블랙박스 모델의 문제:
- 왜 그런 답변을 했는지 알 수 없음
- 편향이나 오류를 발견하기 어려움
- 신뢰성 문제 발생

해석 가능한 모델의 장점:
- 모델의 결정 과정 이해 가능
- 문제점 발견 및 수정 용이
- 사용자 신뢰도 향상
```

## 전체 요약

### 현재 문제점과 해결 방향

| 문제점 | 해결 방향 |
|--------|----------|
| 일반화 능력 상실 | In-context Learning, Few-shot Learning |
| 선호도 반영 불가 | Human Preference Tuning (RLHF, DPO) |
| 지식 오래됨 | Continual Learning, RAG, Self-Improvement |

| 할루시네이션 | RAG, 사실 검증 메커니즘 |
| 해석 불가능성 | Explainable AI 기법 개발 |

## 핵심 트렌드

### 1세대 → 2세대 언어모델 진화
```
1세대 (기존):
사전학습 → 미세조정 → 특정 Task에 특화
문제: 일반화 능력 상실, 업데이트 어려움

2세대 (현재/미래):
사전학습 → Instruction Tuning / RLHF → 범용 모델
특징: 
- In-context Learning으로 다양한 Task 수행
- RAG로 최신 정보 활용
- Human Preference 반영
- 지속적 개선 가능
```

### 주요 패러다임 변화

**1. Fine-tuning → Prompt Engineering**
```
기존: Task마다 모델 미세조정 필요
현재: Prompt로 다양한 Task 수행
```

**2. Static Model → Dynamic Model**
```
기존: 고정된 지식, 업데이트 어려움
현재: RAG, Continual Learning으로 지속 업데이트
```

**3. Model-Centric → Data-Centric**
```
기존: 모델 크기만 키우기
현재: 고품질 데이터, 편향 제거에 집중
```

**4. Black Box → Explainable**
```
기존: 왜 그런 답변을 했는지 알 수 없음
현재: 모델의 결정 과정 설명 가능하도록 개선
```

## 참고: 주요 용어 정리

| 용어 | 설명 |
|------|------|
| **RLHF** | Reinforcement Learning from Human Feedback (인간 피드백 기반 강화학습) |
| **DPO** | Direct Preference Optimization (직접 선호도 최적화) |
| **RAG** | Retrieval-Augmented Generation (검색 증강 생성) |
| **Continual Learning** | 이전 지식을 잊지 않으면서 새로운 지식 학습 |
| **In-context Learning** | 프롬프트 내 예시로 학습 없이 추론 |
| **Few-shot Learning** | 소수의 예시만으로 학습 |
| **Zero-shot Learning** | 예시 없이 Task 수행 |
| **Hallucination** | 모델이 존재하지 않는 정보를 생성하는 현상 |

## 미래 전망

### 단기 목표 (1-2년)
- 더 효율적인 학습 방법 개발
- 편향 완화 기술 고도화
- RAG 시스템 성능 개선

### 중기 목표 (3-5년)
- 완전히 자동화된 Continual Learning 시스템
- 할루시네이션 대폭 감소
- 해석 가능한 대규모 언어모델

### 장기 목표 (5년+)
- 인간 수준의 언어 이해 및 생성
- 편향 없는 공정한 AI
- 지속 가능하고 환경 친화적인 AI 시스템
