# 배열과 구조체 그리고 포인터

## 배열

- 같은 형의 변수를 여러 개 만드는 경우에 사용, 0부터 시작
- 연속적인 메모리 공간
- 1차원 배열
- 2차원 배열 : 1차원이 두 개, 행과 열, 요소들이 2차원 형태로 나열

### 배열 추상 데이터

- 객체 : 인덱스와 값의 쌍으로 이루어진 집합
- 연산
```text
create(size) : size 개의 요소를 저장할 수 있는 배열
get(A, i) : 배열의 A의 i번째 요소 반환
set(A, i, v) : 배열 A의 i번째 위치에 값 v 저장
```

### 배열의 응용(다항식)

- 다항식 : 프로그램에서 다항식을 처리하려면 다항식을 위한 자료구조가 필요
- 어떤 자료구조를 사용해야 다항식의 덧셈, 뺄셈, 곱셈, 나눗셈 연산을 할 때 편리하고 효율적인지
- 2가지 방법
1. 다항식의 모든 항을 배열에 저장 -> 쉽고 직관적
2. 다항식의 0이 아닌 항만을 배열에 저장 -> 공간 절약

### 배열의 응용(희소행렬)

- 희소행렬 : 대부분의 항들이 0인 배열
- 2가지 방법
1. 2차원 배열을 이용하여 배열의 전체 요소를 저장 -> 간단, 메모리 공간 낭비
2. 0이 아닌 요소들만 저장 -> 희소행렬의 경우 메모리 공간 절약, 구현이 복잡

## 포인터

- 다른 변수의 주소를 가지고 있는 변수
- 모든 변수는 주소를 가지고 있음

### 연산자

- & 연산자 : 변수의 주소를 추출
- * 연산자 : 포인터가 가리키는 곳의 내용을 추출

### 종류

- int \*p; p는 int형 변수를 가리키는 포인터
- float \*pf; pf는 doublel형 변수를 가리키는 포인터
- char \*pc; pc는 char형 변수를 가리키는 포인터

### 배열과 포인터

- 배열의 이름은 사실상 포인터와 같은 역할

### 동적 메모리 할당

- 프로그램의 실행 도중에 메모리를 할당 받는 것, 필요한 만큼만 할당을 받고 또 필요한 때에 사용하고 반납, 메모리 이용 효율적
- 고정 메모리는 메모리 공간이 너무 부족하거나 너무 많아 질 수 있어 비효율적
- 전형적인 동적 메모리 할당 코드

```C
main()
{
  int *pi;
  pi = (int *)malloc(sizeof(int));	// 동적 메모리 할당
  ...
  ...
  ...					// 동적 메모리 사용
  free(pi);				// 동적 메모리 반납
}
```
