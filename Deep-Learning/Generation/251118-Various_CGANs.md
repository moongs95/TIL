# 🎨 조건부 생성 모델 기반 다양한 영상 조작 정리

본 문서는 **이미지 대 이미지(Image-to-Image)** 변환과  
**텍스트 대 이미지(Text-to-Image)** 생성 모델의 흐름을  
조건부 생성 모델(CGANs) 관점에서 정리한 학습용 문서입니다.

---

# 1. 이미지 대 이미지(Image-to-Image)

## 1.1 조건부 생성 기반 영상 조작 개념

### ● 이미지 대 이미지 변환이란?
- 입력 이미지 → 원하는 스타일/형태/도메인으로 변환하는 작업
- 예:  
  - 낮 ↔ 밤 변환  
  - 스케치 ↔ 채색  
  - 말 ↔ 얼룩말  
  - 계절 변화  

### ● 기존(전통적) 방식의 한계
- 회귀 기반(Pixel-wise L1/L2 loss)  
- **평균값 예측 → 흐릿한 이미지 생성**
- 태스크마다 모델·손실함수를 새로 설계해야 함

→ **조건부 GAN(Conditional GAN)을 도입하여 '이미지를 직접 생성'하도록 개선**

---

## 1.2 Pix2Pix (2017)

**핵심: 쌍(pair)이 있는 이미지 변환을 위한 조건부 GAN**

### ● 주요 개념
- 입력 이미지와 목표(target) 이미지가 **1:1 쌍으로 존재해야 학습 가능**
- GAN을 활용하여 “회귀”가 아닌 “생성” 기반 변환 수행  
- 더 날카롭고 디테일한 이미지 생성 가능

### ● 생성 모델 (Generator)
- U-Net 구조 (Encoder + Decoder + Skip Connections)
- Skip connection 덕분에 **세부 디테일 보존**이 뛰어남

### ● 판별 모델 (Discriminator)
- PatchGAN 사용  
- 전체 이미지를 보는 것이 아니라 작은 패치 단위로 Real/Fake 판단  
→ 고해상도 이미지에서도 안정적으로 학습

### ● 손실 함수
- 조건부 GAN Loss  
- + L1 Reconstruction Loss (원본·생성 이미지 유사성 유지)

### ● 장점
- 매우 안정적이며 자연스럽고 디테일한 결과물 생성
- 다양한 스타일 변환 태스크에서 강력한 성능

### ● 한계
- **이미지가 반드시 쌍으로 존재해야 함**  
  (말 ↔ 얼룩말, 여름 ↔ 겨울 같은 쌍 데이터를 모으기 매우 어려움)

---

## 1.3 CycleGAN (2017)

**핵심: 쌍이 없는(Unpaired) 이미지 변환 가능**

### ● 해결하려는 문제
- 대부분의 현실 데이터는 “쌍” 형태가 아님  
  → Pix2Pix는 적용 불가

### ● 주요 아이디어: Cycle Consistency
- 한국어 → 영어 번역이 가능하면  
  영어 → 한국어도 가능해야 함
- 즉,  
  x → G(x) → F(G(x)) ≈ x  
  y → F(y) → G(F(y)) ≈ y  

### ● 구성 요소
- G: X → Y 변환  
- F: Y → X 변환  
- Dx: X가 Real인지 판단  
- Dy: Y가 Real인지 판단  
총 **4개의 네트워크** 사용

### ● 손실 함수
- GAN Loss (도메인 간 분포 맞추기)
- Cycle Consistency Loss (L1 loss)
- Identity Loss (선택적)

### ● 장점
- 쌍이 없는 데이터에서도 매우 자연스러운 변환 가능
- 스타일 변환, 도메인 변환에 활용 폭 넓음

---

## 1.4 BiCycleGAN (2017)

**하나의 입력 → 다양한 가능한 출력 생성**

- 단일 입력 이미지가 도메인 B에서 여러 양상으로 표현될 수 있음을 반영  
- 다중 모드(multi-modal) 이미지 생성 가능  
- VAE + GAN 구조 결합  
- 다양성(Diversity) 개선에 초점

---

## 1.5 StarGAN (2017)

**여러 도메인을 하나의 모델로 변환 가능**

- A ↔ B ↔ C 등 여러 도메인을 **하나의 Generator**로 처리  
- 다중 도메인 이미지 변환의 대표적 모델  
- 예: 얼굴 이미지 전체 조정(나이/성별/표정 등)

---

## 1.6 InstaGAN (2019)

**형태가 크게 다른 도메인 간 변환 가능**

- 객체의 “형태(shape)”가 크게 변해도 안정적으로 변환  
- 객체의 마스크 정보를 활용해 구조적 정보를 보존  
- 예: 개 ↔ 고양이처럼 구조가 크게 다른 도메인 간 변환

---

## 1.7 LostGAN

**레이아웃(Layout) 기반 이미지 생성**

- “무엇이 어디에 있는가”라는 **공간 구조(layout)** 를 입력으로 받음  
- 레이아웃 정보에 따라 이미지를 재구성할 수 있어  
  객체 위치 변경·구성 변경 등에 활용 가능

---

## 1.8 SPADE (GauGAN, 2019)

**의미 분할(Semantic Map) 기반 고품질 이미지 생성**

- semantic segmentation map을 조건으로 사용  
- 생성 과정에서 조건 정보를 계속 주입 (SPADE normalization)
- 동일한 의미 영역(예: 하늘, 잔디)에서도 다양한 스타일 생성 가능

---

## 1.9 HyperStyle (2022)

**Pretrained GAN(STYLEGAN 등)을 빠르게 조작가능한 방식**

- 기존에 학습된 GAN의 잠재 공간(latent space)을 분석  
- HyperNetwork로 파라미터를 빠르게 업데이트  
- 이미지를 GAN latent 공간에 빠르게 맞추고 다양한 편집 적용 가능

---

# 2. 텍스트 대 이미지(Text-to-Image)

텍스트를 입력받아 조건에 맞는 이미지를 생성하는 모델

---

## 2.1 GAN-CLS (2016)

### ● 목적
- “문장 설명”을 보고 그에 맞는 이미지를 생성

### ● 텍스트 → 이미지 생성이 어려운 이유
- 텍스트는 순차 구조 (RNN 기반)  
- 이미지는 한 번에 생성  
→ 텍스트 정보를 시각 정보로 잘 인코딩해야 함

### ● 손실 함수 개선
기존 GAN 손실에 다음을 포함:

1. 실제 이미지 + 정확한 텍스트 → Real  
2. 실제 이미지 + 잘못된 텍스트 → Fake  
3. 생성 이미지 + 정확한 텍스트 → Fake  

### ● GAN-INT-CLS 개선
- 텍스트 임베딩(interpolation) 적용  
- 훈련 텍스트 사이의 중간 의미도 반영 → 일반화 성능 향상

---

## 2.2 GigaGAN (2023)

현존 GAN 기반 텍스트-이미지 생성 모델 중 **최고 성능**

### ● 특징
- 매우 큰 모델 규모(Model scaling)
- CLIP 기반 텍스트 임베딩 사용
- GAN 구조 기반이지만 diffusion 수준의 고품질 이미지 생성

### ● Multi-stage Generation
1. 저해상도 이미지 생성  
2. 고해상도 업샘플링 네트워크로 품질 향상  

### ● 생성 모델 구조
- 텍스트 → CLIP Encoder → Text Embedding  
- Style Network → Style vector w 생성  
- Generator → 이미지 생성  
- 이미지-이미지 self-attention  
- 이미지-텍스트 cross-attention  
- Adaptive convolution kernel 선택(텍스트 반영 강화)

### ● 판별 모델 구조
- 단계별로 텍스트 조건을 삽입  
- 피라미드 구조로 Real/Fake 판별

### ● 특징적 장점
- 글로벌 텍스트 의미 보존  
- 로컬 스타일 보존  
- 텍스트 변화에 따른 자연스러운 이미지 보간 가능

---

# 📌 전체 요약

## 이미지 대 이미지 (Image-to-Image)
- Pix2Pix: 쌍이 있는 데이터  
- CycleGAN: 쌍 없이 가능, 가장 널리 사용  
- StarGAN: 다중 도메인  
- SPADE: 의미 분할 기반 고품질 생성  
- InstaGAN / LostGAN: 구조·레이아웃 조작  
- HyperStyle: pre-trained GAN 빠른 편집

## 텍스트 대 이미지 (Text-to-Image)
- GAN-CLS → 최초 GAN 기반 텍스트-이미지  
- GigaGAN → 최신 GAN 기반 초고품질 생성
