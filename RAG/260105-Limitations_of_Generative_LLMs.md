# Limitations of Generative LLMs

## Hallucination

- LLM이 알지 못하는 내용을 그럴듯하게 답변 생성

## Outdated knowledge

- 지식 시간차가 존재
- 업데이트를 매번 할 수 없음
- 일정 기간까지의 내용만 알고 있음

## Untraceable reasoning process

- 모델의 추론과정의 불투명성
- 어디서부터 잘못됬는지 알 수 없음
- 디버깅 불가

## Bias

- 모델의 편향은 서비스에서 치명적인 문제
- ex. 흑인 사진을 고릴라로 라벨링, 성별에 따른 직업이나 형용사

## etc

- API 내부정보 유출 가능성
- 개인정보 데이터 관리
