# 삼각함수

## 각

- 도(degree) : 한 바퀴 360°
- 호도(radian) : 한 바퀴 2π

### 주요 각도

- 30° = π/6
- 45° = π/4
- 60° = π/3
- 90° = π/2
- 180° = π 
- 360° = 2π

### 각도의 변환

- 단위도 연산이 가능
- 도(°)가 약분이 가능
- 도를 호도로 : 도 X (π/180°)
- 호도를 도로 : 호도 X (180°/π)

## 삼각비

- 직각삼각형에서 변들 사이의 비율
- sinθ = b/c
- cosθ = a/c
- tanθ = b/a = sinθ/cosθ
- 특정한 각도일 때 항상 비율이 같음
- θ가 45도라면 이등변 삼각형
- 특수각의 삼각비 알아두기!(30° π/6, 45° π/4, 60° π/3)
- 피타고라스 정의 이용

## 삼각비와 삼각함수

- 삼각비에서 a, b(상수)였던게 삼각함수에서는 x, y(음수도 가능)

### 삼각함수 cos

- x/r
- x축이 세타일때
- 패턴이 계속 반복 -> 주기함수
- 시계방향은 양수, 반시계방향은 음수
- domain은 각도, range는 [-1, 1], 주기가 2π, 우함수

### 삼각함수 sin

- y/r
- 기함수
- cos과 sin은 평행이동(π/2)하면 겹침

### 삼각함수 tan

- sin/cos, y/x
- 점근선 = π/2
- 기함수

### 삼각함수의 특징

- tan만 주기가 π, cos, sin은 2π
- cos는 even, sin, tan은 odd
- cos, sin은 range가 [-1, 1], tan은 실수 전체
- sin(x+-π) = -sin(x)
- cos(x+-π) = -cos(x)

### 삼각함수 공식

- cos(−x)=cos(x)
- sin(−x)=−sin(x)
- tan(−x)=−tan(x)
- sin(x+π)=−sin(x)
- cos(x+π)=−cos(x)
- cos(x+2nπ)=cos(x)
- sin(x+2nπ)=sin(x)
- tan(x+nπ)=tan(x)
- sin(π/2−x)=cos(x)
- cos(π/2−x)=sin(x)

## 역삼각함수

- 삼각함수 sin, cos, tan은 기본적으로 1:1 대응이 아니기 때문에 역함수가 존재할 수 없음
- 역함수를 위해 정의역 제한하기
- domain을 제한하여 강제로 1:1대응이 되도록 만들어 줌
- sin의 domain = [-π/2, π/2], range = [-1, 1]
- cos의 domain = [0, π], range = [-1, 1]
- tan의 domain = (-π/2, π/2), range = (-∞, ∞)
- arcsin, arccos, arctan 모두 domain과 range가 서로 변경이 됨
- arcsin, arccos, arctan은 각각 y/r, x/r, y/x 입력하면 각도를 출력
