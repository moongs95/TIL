# 성능 고도화 방법 IV_데이터 증강 및 그 외 방법

## 데이터 증강 기법 및 그 외 방법들
Data Augmentations and Various Model Training Methods

### 1.1 데이터 증강 기법

**학습 데이터가 부족하다면?**  
일반적으로 데이터가 충분하지 않다면 과적합이 발생. 그렇기 때문에, 충분한 양의 학습 데이터를 확보하는 것은 중요.  
다만, 데이터를 더 이상 구할 수 없는 상황이라면 데이터 증강 기법(Data Augmentation)을 고려해볼 수 있음.  
→ 데이터를 임의로 늘림

**기본적인 이미지 데이터 증강 기법**  
이미지 데이터에서 가장 많이 활용하는 방법으로는 이미지 사이즈 조절(Resize), 회전(Rotation), 뒤집기(Flipping) 그리고 자르기(Crop)가 있음.  
파이썬에서는 OpenCV 라이브러리를 이용하면 간단하게 구현할 수 있음.  
TensorFlow나 PyTorch와 같은 딥러닝 프레임워크에서도 기본적인 데이터 증강 기법을 지원.

여러 오픈 소스 라이브러리인 Albumentations은 색상 변화 등 다양한 기법을 지원.  
ImgAug는 객체 인식(Object Detection) 등에서 정답 레이블(Ground Truth)까지 함께 수정할 수 있음.  
→ 라벨링 정보도 유지해서 같이 증강

**주의해야 할 점**  
함부로 데이터를 변형하여 증폭시키면 안 됨. 데이터의 도메인을 고려해서 처리해야 함.  
문맥이나 의미를 왜곡하지 않도록 주의해야 함.  
예를 들어, 나침반을 학습할 때 이미지를 회전시키면 방향 정보가 훼손될 수 있고, 글자 인식 모델에서 문자를 뒤집으면 의미가 바뀔 수 있음.  
→ 원래 가지고 있는 정보가 훼손되지 않는지 유의

**그 외 다양한 방법들**
- **Cutout** : 이미지의 일부 영역을 가림
- **Mixup** : 두 이미지의 픽셀 값을 선형 조합하여 새로운 이미지 생성
- **CutMix** : 한 이미지의 일부분을 다른 이미지에 붙여넣는 방식  
→ 이미지 분류에 있어서 성능이 좋음

**텍스트 데이터도 증강이 가능할까?**

**기본적인 텍스트 증강 기법**
1. **동의어 대체(Synonym Replacement, SR)** : 문장에서 불용어가 아닌 단어를 무작위로 선택해 동의어로 교체  
2. **무작위 삽입(Random Insertion, RI)** : 불용어가 아닌 단어의 동의어를 찾아 문장의 무작위 위치에 삽입  
3. **무작위 교체(Random Swap, RS)** : 문장에서 두 단어를 무작위로 선택하고 위치를 교환  
4. **무작위 삭제(Random Deletion, RD)** : 각 단어를 확률 p로 무작위 제거  
→ 문맥이나 문법에 따라 의미가 달라질 수 있으므로 주의 필요

**의미 유지 변환 방법**  
문장의 의미를 유지하면서 구조적 변화나 문법적 변화를 줌.  
예: 능동태 ↔ 수동태 변환, 직접화 ↔ 간접화 변환

**역번역(Back Translation)**  
문장을 한 언어로 번역했다가 다시 원래 언어로 번역하여 자연스러운 다양성을 확보.  
원래 의미를 크게 훼손하지 않으면서 다양한 문장 생성 가능.

**사전학습된 언어모델(Pretrained LM)**  
BERT, GPT2, BART 등의 언어모델을 이용해 문맥 기반으로 새로운 문장을 생성.  
GPT 모델에서는 Temperature 값이 낮으면 주제에 충실, 높으면 다양하고 창의적인 문장 생성.  
또한 Top-k, Top-p 설정으로 단어 선택의 확률 분포를 제어하여 다양성을 높일 수 있음.

### 1.2 전이 학습 (Transfer Learning)

**항상 처음부터 다시 학습해야 할까?**  
전이 학습은 이미 학습된 모델의 지식을 새로운 작업에 활용하는 방법.  
즉, 하나의 문제에서 얻은 지식을 다른 문제에 ‘전이(Transfer)’하는 것.

**전이 학습은 어떻게 사용될까?**  
대표적으로 의료 이미지 분석 분야에서 소량의 데이터로도 높은 성능을 달성.  
→ 라벨링된 데이터가 부족하거나 개인정보 이슈로 데이터가 부족할 때 특히 유용.  
텍스트 데이터의 감정 분석 등에서도 BERT를 통한 전이 학습이 효과적임.

**전이 학습의 한계**  
소스 데이터와 타겟 데이터의 도메인 간 차이가 크면 효과가 떨어짐.  
또한 많은 레이어를 학습시킬 경우 과적합 위험이 존재.  
→ 도메인 간 간극, Fine-tuning 시 파라미터 설정을 신중히 고려해야 함.

### 1.3 자기 지도 학습 (Self-Supervised Learning)

**항상 모델을 학습할 때 레이블을 써야 할까?**  
지도 학습은 레이블에 크게 의존하지만, 레이블링은 시간과 비용이 많이 듦.  
자기 지도 학습은 명시적인 레이블 없이 데이터 내부의 구조를 이용하여 ‘가상의’ 레이블을 만들어 학습.  
예: 이미지의 일부를 가리고 가려진 부분을 예측하거나, 이미지를 회전시켜 각도를 예측하는 방식.

**생성 학습 (Generative Learning)**  
동일한 이미지를 변형하여 원본과 변형된 이미지의 관계를 학습.  
오토인코더(autoencoder) 구조를 이용해 입력과 출력을 동일하게 만들어 학습.  
압축된 표현을 통해 주요 특징을 학습하고 원본 이미지를 복원.

**대체 작업 학습 (Proxy Task Learning)**  
주요 작업 대신 대리 작업을 학습하여 특징을 얻는 방법.  
예를 들어, 한 이미지를 여러 방식으로 변형하여 원본을 식별하도록 학습.  
→ 어떤 클래스인지는 중요하지 않고, 변형된 이미지들이 같은 클래스임을 인식하도록 학습.

**대조 학습 (Contrastive Learning)**  
서로 다른 데이터 포인트 간의 유사도와 차이를 학습하여 특징을 추출.  
데이터 증강 기법을 다양하게 적용해 ‘비슷한 샘플은 가깝게, 다른 샘플은 멀게’ 학습.  
→ 데이터 증강은 모델이 학습해야 할 핵심 정보를 변경하지 않도록 주의해야 함.
