# RNN

## 순환 신경망 Recurrent Neural Networks

순환 레이어와 같이 순환 신경망을 구성하는 기본적인 요소에 대해서 어떻게 동작하는지 알아보는 시간

---

### 1.1 순환 신경망의 등장

**기존 신경망의 한계**
- DNN, CNN은 **고정된 크기(Fixed size)** 의 입력과 출력만 처리 가능.
- 텍스트, 음성, 주식 가격처럼 **길이가 가변적인 시퀀스 데이터(Sequential data)** 는 처리 어려움.

→ 과거 정보를 기억하면서 현재 입력을 처리할 수 있는 구조 필요  
→ **순환 신경망 (Recurrent Neural Network, RNN)** 등장

**핵심 개념**
- 시간 흐름에 따라 입력을 처리하면서 **이전 상태 정보를 유지**
- 은닉 상태(Hidden State)가 “기억” 역할 수행
- 루프 구조를 통해 정보가 다음 시점으로 전달됨

---

### 1.2 순환 신경망의 구성 요소

#### ▪ 순환 신경망의 구조
- RNN은 **이전 시점의 정보를 현재 시점의 입력과 함께 처리**  
- 은닉 상태(Hidden State): 과거 정보를 저장 및 업데이트
- 출력은 현재 은닉 상태에 기반하여 계산됨

**입출력 형태 확장**
- **One-to-One** : 전통적인 신경망 (예: 이미지 분류)
- **One-to-Many** : 이미지 캡셔닝 (하나의 입력 → 여러 단어 출력)
- **Many-to-One** : 감정 분석 (여러 단어 입력 → 하나의 출력)
- **Many-to-Many** : 번역, 비디오 프레임 분류 등

→ RNN은 입력과 출력의 개수가 달라도 처리 가능  
→ **이전 상태를 기억**하는 구조

**활성화 함수**
- 일반적으로 **tanh** 를 사용 (은닉 상태의 안정적인 갱신에 유리)

#### ▪ 은닉 상태 계산
현재 은닉 상태(h_t)는 이전 은닉 상태(h_{t-1})와 현재 입력(x_t)에 기반해 계산  
활성화 함수로 tanh 사용  
출력은 은닉 상태에 기반해 계산됨

---

### 1.3 순환 신경망의 한계

**장기 의존성(Long-Term Dependency) 문제**
- 시퀀스가 길어질수록 앞부분 정보를 잊어버림
- 역전파 과정에서 **기울기 소실(Vanishing Gradient)** 문제 발생

→ 이를 해결하기 위해 **LSTM** 과 **GRU** 구조가 등장

---

### 1.4 LSTM (Long Short-Term Memory)

**핵심 개념**
- 장기 의존성 문제를 완화하기 위해 설계된 구조
- 세 개의 게이트(Gate)를 통해 정보 흐름 제어

**게이트 구성**
1. **Forget Gate** : 어떤 정보를 버릴지 결정  
2. **Input Gate** : 어떤 정보를 저장할지 결정  
3. **Output Gate** : 어떤 정보를 다음으로 전달할지 결정  

→ 세 개의 게이트를 통해 “기억 유지”와 “정보 선택”을 동시에 수행

---

### 1.5 GRU (Gated Recurrent Unit)

**핵심 개념**
- LSTM의 간소화 버전  
- 두 개의 게이트만 사용하면서 유사한 성능 유지  
- 계산량이 적고 효율적

**게이트 구성**
1. **Reset Gate** : 이전 상태 정보를 얼마나 반영할지 결정  
2. **Update Gate** : 이전 상태를 얼마나 유지할지 결정  
   - LSTM의 Forget Gate + Input Gate 역할을 합침

→ GRU는 2개의 게이트 구조로 LSTM보다 단순하지만 비슷한 성능을 냄

---

### 1.6 RNN, LSTM, GRU 비교 요약

| 모델 | 주요 특징 | 게이트 수 | 장점 | 단점 |
|------|-----------|-----------|------|------|
| RNN | 기본 순환 구조, 단기 기억 | - | 구조 단순, 빠름 | 장기 의존성 문제 |
| LSTM | Long-Term Memory 가능 | 3개 | 장기 기억 가능 | 구조 복잡, 연산 많음 |
| GRU | 간소화된 LSTM | 2개 | 계산 효율적, 성능 유사 | 세밀한 제어는 부족 |

---

### 1.7 요약 및 읽을거리

**핵심 요약**
- RNN은 시계열 및 순차 데이터 처리에 적합  
- 은닉 상태를 통해 과거 정보 기억  
- LSTM, GRU는 RNN의 장기 의존성 문제 해결
