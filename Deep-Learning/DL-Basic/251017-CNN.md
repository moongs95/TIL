# CNN

## 1. 합성곱 신경망 (Convolutional Neural Networks)

이미지의 **형상 정보(spatial information)** 를 보존하면서 학습하기 위해 등장한 신경망 구조.  
완전연결층(FC layer)은 1차원 평탄화 과정에서 위치 정보를 잃기 때문에 이미지 분석에 부적합함.

---

## 1.1 합성곱 연산 (Convolution)

**핵심 개념**  
- 입력 데이터에 **필터(커널)** 를 슬라이딩하며 곱셈-합산 수행  
- 각 필터는 학습 가능한 파라미터  
- 연산 결과: **특징맵(Feature Map)**

**필터 수에 따른 구조**  
- 입력 채널 수와 같은 채널을 가진 필터: 출력 1개  
- 필터가 여러 개(FN개): 출력 채널 수도 FN개  
→ 가중치는 4차원 구조 `(출력채널, 입력채널, 높이, 너비)`

---

### ▪ 스트라이드 (Stride)

- 필터가 이동하는 간격  
- 클수록 출력 크기(Feature Map) 감소

---

### ▪ 패딩 (Padding)

- 입력 가장자리를 0 등으로 채워 크기 감소 방지  
- **zero padding** 이 일반적

**출력 크기 계산 공식**

```text
OH = (H + 2P - FH) / S + 1
OW = (W + 2P - FW) / S + 1
```


---

## 1.2 풀링 연산 (Pooling)

피처맵의 공간 크기를 줄이고 중요한 정보만 남기는 다운샘플링 연산.  
학습 파라미터가 없고, 연산 효율성과 잡음 강인성을 높임.

---

### ▪ 최대 풀링 (Max Pooling)

- 윈도우 내 **최대값 선택**  
- 두드러진 특징 강조, 노이즈에 강함  
- 하지만 평균적 정보 손실 가능

---

### ▪ 평균 풀링 (Average Pooling)

- 윈도우 내 **평균값 계산**  
- 전체적 구조/배경 정보 보존  
- 뚜렷한 특징은 덜 강조됨

---

**풀링의 특징 요약**

- 학습 파라미터 없음  
- 계산 효율적  
- 노이즈에 강인함

---

## 1.3 CNN 블록 구성 예시

### 블록 1

```python
layer_defs.push({type:'conv', sx:5, filters:8, stride:1, pad:2, activation:'relu'});
layer_defs.push({type:'pool', sx:2, stride:2});
```

→ 필터 8개, 출력 8개
→ MaxPooling으로 크기 감소

### 블록 2

```python
layer_defs.push({type:'conv', sx:5, filters:16, stride:1, pad:2, activation:'relu'});
layer_defs.push({type:'pool', sx:3, stride:3});
```
→ 필터 16개, 피처맵 더 깊어짐

### 블록 3

```python
layer_defs.push({type:'softmax', num_classes:10});
```

→ 10개 클래스에 대한 확률 출력

## 1.4 요약

| 구성요소                   | 역할       | 특징              |
| ---------------------- | -------- | --------------- |
| **Conv Layer**         | 지역 패턴 추출 | 필터(가중치) 학습      |
| **Pooling Layer**      | 공간 크기 축소 | 파라미터 없음, 노이즈 강인 |
| **FC Layer / Softmax** | 최종 분류    | 확률 기반 예측        |

## 📘 핵심 정리

- CNN은 이미지의 공간적 구조를 유지하면서 특징을 학습함
- 합성곱(Convolution) → 특징 추출
- 풀링(Pooling) → 크기 축소 및 정보 요약
