# 📘 언어학 & 전산언어학 완전 정리 (NLP 기초 이론)

본 문서는 **자연어처리(NLP)의 이론적 기반**이 되는 언어학·전산언어학 개념을 학습용으로 정리

---

# 1. 언어학과 전산언어학

## 1.1 언어학(Linguistics)이란?
- 인간의 언어를 **과학적으로 분석하는 학문**  
- 인간 고유의 인지 능력인 ‘언어’의 구조 · 의미 · 사용 방식을 연구

## 1.2 전산언어학(Computational Linguistics)
- 컴퓨터를 이용해 언어를 자동 분석하는 학문  
- 언어 자료를 자동 처리할 때 발생하는 언어학적 문제를 연구  
- **컴퓨터과학 관점에서는 자연어처리(NLP)** 로 불림

---

# 2. 언어학의 접근 방법

## 2.1 규칙 기반 접근 (Rule-based)
- 언어학에서 정의한 형태·구문 규칙을 토대로 분석
- EX) 형태소 사전, 문법 규칙 기반 분석기

## 2.2 통계 기반 접근 (Statistical NLP)
- 실제 코퍼스(전자화 텍스트)의 **빈도·분포 기반**
- EX) 언어모델(ngram), PMI 기반 연어 분석

## 2.3 딥러닝 기반 접근 (Neural NLP)
- 대규모 데이터로 학습한 **신경망 표현** 사용  
- 규칙을 명시적으로 만들지 않아도 자동 학습됨  
- EX) BERT, GPT, Transformer 기반 모델

---

# 3. 전통적인 NLP 처리 파이프라인

문서 입력 → 전처리 → 토큰화 → 품사 태깅 → 구문 분석 → 의미 분석 → 화용/담화 분석 → 응용 태스크 수행

| 단계 | 설명 |
|------|------|
| Tokenization | 형태소 기준으로 단위 분절 |
| POS Tagging | 단어의 품사 판별 |
| Parsing | 문장 구조(트리) 분석 |
| Semantics | 의미 해석 |
| Pragmatics | 화자의 의도·문맥 추론 |
| Discourse | 여러 문장 단위 연결 |

---

# 4. 기본 언어 단위

## 4.1 음절 (syllable)
- 발화에서 하나의 소리 덩어리  
- 한국어: 한 글자 = 한 음절  
- 영어: 최소 하나의 모음 포함

## 4.2 형태소 (morpheme)
- **의미를 가지는 최소 단위 (NLP 기본 토큰)**
- 분류
  - **자립/의존** 형태소  
  - **실질/형식** 형태소  
- EX) “먹었습니다” = 먹(어간) + 었(과거) + 습(존칭) + 니다(종결)

## 4.3 어절 (eojeol)
- 한 개 이상의 형태소가 붙은 단위  
- 한국어에서는 띄어쓰기 기준

## 4.4 품사 (Part of Speech)
- 단어를 문법적 기능/형태에 따라 구분  
- NLP에서는 **POS Tagging**으로 자동 분석  
- 분류 예시  
  - 명사, 조사, 동사, 형용사, 관형사, 부사, 감탄사 …

# 5. 언어학의 하위 분야

언어는 **형태 / 내용 / 사용**의 세 축으로 구성된다.

---

# 5.1 형태론 (Morphology)
> 형태소 분석의 근간

- 단어가 어떻게 구성되는지를 연구  
- 형태소 = 의미를 가진 최소 단위  
- 자립 vs 의존, 실질 vs 형식 형태소

### 이형태(Allomorph)
- 하나의 형태소가 여러 형태로 실현됨  
- EX) 복수표지 s/es, 과거표지 ed/d

---

# 5.2 통사론 (Syntax)
> 문장의 구조 연구 (Parsing과 연결)

- 단어들이 어떻게 결합해서 구와 문장을 이루는지 연구  
- 통사 구조는 자연어처리에서 **구문 분석 모델**의 기반

### 심층 구조 vs 표층 구조
- 심층 구조: 추상적 의미 구조  
- 표층 구조: 실제 발화 형태  
- 하나의 심층 구조가 여러 표층 구조로 표현 가능

### 구조적 모호성
- 같은 문장이 여러 해석을 가질 수 있는 현상  
- NLP에서 난제

### 반복 (Recursion)
- 문장 속 문장 삽입—언어 무한성의 원천  
- NLP가 어려운 핵심 이유 중 하나

### 구 구조 규칙 (Phrase Structure Rules)
- NP, VP, PP 등을 구성하는 규칙  
- → 트리 기반 Parsing

### 변형규칙 (Transformational Rules)
- 하나의 문장을 다른 구조로 변환  
- 예: 평서문 → 의문문  
- 규칙이 매우 많아 규칙 기반 NLP의 난점

---

# 5.3 의미론 (Semantics)
> 단어·문장의 ‘의미’를 연구

### 의미자질(semantic features)
- 단어 의미를 성분(feature)로 표현  
- EX) 인간은 [+사람], [+생물], [+지능] …

### 의미역(semantic roles)
- 문장에서 단어가 수행하는 의미적 역할  
  - Agent (행위자)  
  - Theme (대상자)  
- NLP 응용: **Semantic Role Labeling**

### 의미 관계
- 동의어(synonym)  
- 반의어(antonym)  
- 상하관계(hyponymy)  
- 다의어(polysemy)  
- 동음이의어(homonym) ← NLP 매우 난제  
- 연어(collocation) ← 의미 기반 단어 연관

---

# 5.4 화용론 (Pragmatics)
> “말하지 않은 의미”를 해석하는 학문

### 문맥(Context)
- 물리적 문맥 (시간·장소)  
- 언어적 문맥 (전후 문장)

### 직시 표현 (deixis)
- 이곳, 저기, 나, 너, 지금 …  
- 화자의 관점 없이는 해석 불가

### 지시(reference)
- 특정 대상을 가리키는 행위

### 추론(inference)
- 발화 내용과 진짜 의미를 연결하는 과정  
- NLP가 해결하기 어려운 핵심 요소

### 대용어(Anaphora)
- 앞 문장의 요소를 지시하는 표현  
- NLP 응용: **Coreference Resolution**

### 전제(presupposition)
- 말하지 않았지만 참이라고 가정되는 것

### 화행(speech acts)
- 말 = 행동  
- 부탁, 명령, 위협, 약속…  
- 직접/간접 화행 구분 필요

---

# 5.5 담화론 (Discourse)
> 문장 너머의 언어 분석

### 결속(Cohesion)
- 텍스트 내부의 의미적 연결

### 일관성(Coherence)
- 실제 의미의 흐름이 자연스러운지

### 협조의 원칙 (Grice’s Maxims)
- 양(quantity)  
- 질(quality)  
- 관련성(relation)  
- 방식(manner)

→ 대화형 AI가 반드시 고려해야 하는 영역

# 6. 언어학의 NLP 적용 사례

## 6.1 주요 NLP 태스크
- 토큰화
- 품사 태깅
- 구문 분석(Parsing)
- 의미/담화 분석
- NER (개체명 인식)
- 문법 교정(GEC)
- 의존 구문 분석 (Dependency Parsing)
  - Transition-based  
  - Graph-based

## 6.2 BERT와 언어학
BERT는 다음 특징을 보유해 언어 정보를 잘 학습함:

- 하층: 표면적 정보(단어 형태, 문법)
- 중간층: 구문 정보(문장 구조)
- 상층: 의미 정보(문장 의미)

연구 예시:
- LIMIT-BERT
- GiBERT
- “Does BERT Learn as Humans Perceive?”
- Linguistic Knowledge Injection 연구들

# 7. 결론

### 📌 자연어처리에서 언어학은 필수다.
- NLP는 언어학 없이 성립할 수 없음  
- 최신 딥러닝 모델(GPT, BERT 등)도 언어학적 개념을 내부에서 학습  
- 규칙·구문·의미·화용·담화 이론이  
  **모두 NLP 모델 설계·해석·개선에 직접적으로 기여**

### 📌 언어학 기반 NLP는 계속 진화 중
- 통계 기반 → 신경망 기반으로 발전했지만  
- 여전히 언어학적 정보는 모델의 성능 향상에 핵심 역할  
- 언어적 통찰을 활용한 최신 연구(LoRA, BERT variants 등)도 활발
