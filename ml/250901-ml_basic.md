# ML Basic

## 머신러닝이란 무엇인가

- 인공지능 : 인간의 학습능력, 추론능력, 지각능력을 인공적으로 구현하려는 컴퓨터 과학의 분야 중 하나
- 약인공지능(ANI) : 정해져있는 과제들을 잘 수행하는 인공지능
- 강인공지능(AGI) : 사람처럼 복합적인 사고를 통해 어떤 일이든 수행하는 AI
- 함수 : 일련의 과정을 통해 인풋으로 들어오는 무언가를 특정한 아웃풋으로 변환해 주는 것
- 머신러닝을 통해 고수준의 추상화 해결 : 파라미터를 활용해 함수들의 공간을 정의, 데이터를 사용해 얼마나 틀렸는가를 측정, 틀린 정도를 최소화하는 파라미터 찾아내기
- 딥러닝 : 함수가 가진 파라미터의 수, 형태에 따라 매우 복잡한 기능도 구현이 가능, 딥러닝이란 심층신경망 구조의 모델을 사용하는 머신러닝의 일종

## 모델과 데이터

- 머신러닝에서 학습 : 모델에서의 데이터 인풋값에 대한 예측값과 라벨의 차이로 계산되는 손실함수를 최소화하는 파라미터를 찾아내는 것
- Universal Approcimation Theorem : 특정 구조의 모델을 적절히 학습하면 그 어떤 함수라도 근사할 수 있다.
- 머신러닝을 위한 문제 정의 : 주어진 데이터를 전부 벡터나 행렬 같은 숫자의 형태로 표현해야 함.
- 정형 데이터 : 수치형 변수(연속형, 이산형), 범주형 변수(명목형, 순위형)
- 비정형 데이터 : 텍스트, 이미지, 동영상, 음악, 녹음파일 등
- 데이터의 수치적 표현 방법 : 범주형 데이터의 인덱싱 / 텍스트 데이터 인덱싱 -> 자연어 처리 / 비트맵 -> 컴퓨터 비전 / Raw Wave, 스펙트로그램 -> 음성처리 / 추천시스템
- EDA(탐색적 데이터 분석) : 데이터를 탐색함으로써 각 변수의 의미와 특성, 분포를 이해하는 과정
- 데이터 전처리 : 노이즈 제거, 모델이 잘 학습할 수 있는 형태로 데이터를 변환, 이상치 및 결측치 처리, 피쳐 스케일의 조정

## 지도학습 방법

- 지도학습 : 입력데이터 x에서 함수의 출력값이 라벨 y에 가까워지도록 학습하는 방식
- 비지도학습 : 레이블 y를 활용하지 않고 입력 데이터 x로만 모델을 학습하는 방법론
- 회귀모델 : y가 연속형 -> 선형회귀모델, 상관관계 분석
- 분류모델 : y가 범주형 또는 이산형 -> 로지스틱 회귀모델
- 상관관계 : 두 변수가 함께 변화하는 경향성
- 인과관계 : 한 변수가 원인이 되어 결과로 다른 변화를 변화
- 인과관계가 있는 변수는 상관관계도 있으나 역은 성립되지 않음.
- 상관관계 분석 : 두 변수 사이의 상관관계를 판단하기 위한 분석 과정(선형성, 등분산성, 정규분포성, 독립성 만족)
- 공선성 : 두 변수간 상관관계가 1 또는 -1일 때
- 다중 공선성 : 한 변수가 여러 번수들의 선형결합일 때
- 이진분류 : 출력값이 참 혹은 거짓 두 가지로만 나오는 형태의 분류모델
- 다중분류 : 원 핫 인코딩, 소프트맥스, 크로스엔트로피
- 다양한 분류문제 모델링 : k-최근접 이웃 알고리즘, 의사결정나무, 랜덤포레스트, 서포트 벡터 머신
