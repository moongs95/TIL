# Strage와 Computing

## Storage

- Storage는 MLOps에서 데이터를 저장, 관리, 검색하는 중요한 구성 요소
- 데이터의 안전성, 접근성 및 확장성을 보장하는 것이 핵심

### 유형

- 클라우드 스토리지 : 확장성, 내구성과 가용성, 안전성, 비용 효율성
- 분산 파일 시스템 : 대규모 데이터 처리, 고가용성, 확장 가능한 아키텍처, 비용 효율적
- 데이터 웨어하우스 : 고속 쿼리 실행, 대규모 데이터 분석, 사용 편의성, 보안과 규제 준수
- 데이터 레이크 : 다양한 데이터 형식 지원, 유연한 데이터 처리, 대규모 데이터 관리, 비용 효율성, 데이터 통합

## Computing

- Computing Resource는 데이터 처리, 모델 트레이닝 및 추론에 필요한 컴퓨팅 파워를 제공
- 높은 성능과 확장 가능한 리소스로 빠른 처리 속도 및 효율성을 보장하는 것이 중요

### 유형

- 클라우드 기반 컴퓨팅 : 인스턴스 유형과 환경, 자동 스케일링, 종합적인 보안, 전역 네트워크
- GPU/TPU : 딥러닝 최적화, 고속 메모리 접근, 에너지 효율적 설계, 확장 가능한 인프라
- 서버리스 컴퓨팅 : 코드 중심 실행, 다양한 트리거 옵션, 빠른 배포 및 업데이트, 에코시스템
- 컨테이너화된 컴퓨팅 : 개발 및 배포 일관성, 자톧 오케스트레이션, 마이크로서비스 아키텍처 지원, 리소스 효율성
