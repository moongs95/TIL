# 다항함수

## 거듭제곱(Power)

- x가 변수, 지수값 고정
- 0제곱은 1, 1제곱은 자기 자신, 지수의 분배법칙 가능

## 멱함수(Power Function)

- 지수는 자연수로 fix
- 많은 부분이 멱함수에 포함, 멱함수의 조합으로 더 복잡한 함수를 만들 수 있음
- 0제곱 까지 멱함수
- identity function도 멱함수

### 멱함수의 특징

- 짝수 차수는 even function, x<0에서는 감소함수, x>0에서는 증가함수
- 홀수 차수는 odd function, 증가함수
- 계수를 가지는 거듭제곱 합수
- y축의 수축과 팽창, c가 음수(-)일 경우에는 x축의 대칭이동도 포함

## 다항함수(Polynomial Functions)

- 멱함수 기반, polynomial 리그래션, 인터포레이션과 관련, 특히 2차함수를 다룸
- 멱함수들의 합 -> 나중에 벡터로 변형 가능
- 최고차항의 차수를 다항함수의 차수로 표현
- Even Polynomial Functions : 짝수 차수의 power function들의 합으로 이루어진 다항함수
- Odd Polynomial Functions : 홀수 차수의 power function들의 합으로 이루어진 다항함수

## 이차함수(Quadratic Functions)

- 최고차항의 차수가 2차인 다항함수
- 일반형 : y절편 보기 쉬움(x=0일 때)
- 표준형 : 평행이동, 대칭이동을 잘 볼 수 있음 꼭지점(vertex)이 잘 보임(p, q)
- 일반형에서 표준형 변형 공식

1. a로 묶어줌
2. b/a 절반의 제곱을 더하고 빼줌(0이라 식에 영향 없음) -> point!
3. a를 곱해주고 괄호 밖으로 보내줌
4. 곱셈공식을 활용하여 묶어줌 -> 표준형으로 변형(b/2a는 -p, 뒤는 모두 q)
