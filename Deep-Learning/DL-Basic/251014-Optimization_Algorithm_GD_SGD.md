# 경사 하강법

- 최적화 알고리즘 : 경사 하강법, 확률적 경사 하강법

## 미분과 기울기

### 미분(differentiation)

- 변수의 움직임에 따른 함수값의 변화를 측정하는 도구
- 최적화에서 제일 많이 사용하는 기법
- 극한을 통해 정의되며 직접 구하기 위해서는 ℎ→0 극한을 계산해야 함
- 변수 x에 대한 미분값은 변수 값이 바뀔 때 결과값(f(x))이 얼마나 많이 바뀌는 지에 대한 값
- 특정 검은색 점에서 어떻게 a, b에 대한 변화를 줘야 L이 줄어드는지 추정하여 파라미터 값을 변화시킴
- 파라미터를 변화시킬 때 L값이 어떻게 변화하는지 => 미분

### 2차원 평면에서의 미분

- x에서의 미분값은 함수 f의 주어진 점(x, f(x))에서의 접선의 기울기와 동일
- 어떤 점에서의 함수의 기울기를 알면 어느 방향으로 점을 움직여야 함수값이 증가 or 감소하는지 알 수 있음
- 미분의 반대 방향으로 가야지 감소

### 편미분(partial differentiation)

- 벡터를 입력값으로 받는 다변수 함수의 경우, 각 변수에 대해 미분한 편미분을 사용
- 각 변수에 대한 편미분을 나타낸 그래디언트(gradient) 벡터를 이용하면 마찬가지로 다변수 함수의 기울기를 알 수 있음
- 그래디언트 : 각 변수 별로 미분한 것을 벡터 형태로 모아 놓은 것

## 경사 하강법(Gradient Descent, GD)

- 기울기가 감소하는 방향으로 x를 움직여서 f(x)의 최소값을 찾는 알고리즘
- 딥러닝에선 손실 함수의 그래디언트가 감소하는 방향으로 파라미터를 움직여 손실함수L의 최소값을 찾음
- 학습률(learning rate, lr) : 특정 방향으로 얼마나 움직일지에 대한 상수값
- 미분은 방향, 학습률은 그 방향으로 한 번에 얼마나 갈지
- 경사 하강법의 학습 과정
```text
(1) 모델 파라미터 초기화
(2) 전체 학습데이터셋에서의 손실 함수 값을 구하고 미분을 통해 이를 최소화하는 모델 파라미터 W, b를 찾음
(3) (2)를 반복하다가 종료 조건이 충족되면 학습 끝!
-> 종료 조건 : 함수 값이 최소인 지점에서는 L의 변화가 작거나 미분값이 작거나
```

- 경사 하강법의 알고리즘
```python
Input: gradient, init, lr, eps
Output: var
———————————————————————————————————————————
# gradient: 그래디언트 벡터를 계산하는 함수
# init: 시작점, lr: 학습률, eps: 알고리즘 종료조건
var = init
grad = gradient(var)
while norm(grad) > eps :
		var = var - lr * grad
    grad = gradient(var)
```

### 경사 하강법의 한계 및 해결방안

- 지역 최소에 빠지던지 미분값이 거의 0에 수렴하는 곳에 멈춤
- 해결 방안
```text
① 파라미터 초기화를 굉장히 잘한다. (여러 초기화 기법, pretraining)
② 모델 구조를 바꿔서 그래프 모양을 바꾼다. → 학습데이터가 바뀌어도 함수 모양이 바뀜
③ Learning Step을 바꾼다.
```

### 경사 하강법의 파이프라인

- 모든 샘플에 대해서 로스를 구해 다 더해야 함
- 샘플수가 많으면 연산량 문제
- 딥러닝은 데이터가 많아서 연산량도 많아짐
- 계산 효율을 위해 손실값을 샘플별 합이 아닌 평균값으로
- 전체 샘플이 아닌 일부 샘플에 대한 평균값으로 대체
- 그래디언트 계산도 훨씬 간단해짐 -> 확률적 경사 하강법

## 확률적 경사 하강법(Stochastic Gradient Descent, SGD)

- 모든 데이터를 사용해서 구한 경사를 통해 파라미터를 한 번 업데이트 하는 대신, 데이터 한 개 또는 일부를 활용하여 구한 경사로 여러번 업데이트 진행
- SGD를 통해 한 번의 학습을 하는 데에 사용되는 데이터 샘플의 집합을 ‘미니 배치(mini-batch)’ 혹은 간단히 ‘배치(batch)’
- 손실 함수의 크기를 1/m로 스케일하는 과정은 학습 데이터의 크기가 실시간으로 바뀌는 환경에서 특히나 잘 작동
- m=1인 환경을 ‘온라인 학습(online/incremental learning)’이라고 부름
- m이 M의 1/10개 라면 10step, 10epoch

### 확률적 경사 하강법의 파이프라인

- epoch 마다 반복 하면서 손실함수의 미분 구함
- 전체 손실함수는 개별 샘플별 손실함수의 평균과 비슷할 것
- 학습을 위해서 손실함수의 그래디언트를 계산하는 과정이 불가피 -> sigmoid function이 자주 사용되는 이유(미분 가능)

## SGD vs GD

- 볼록하지 않은 목적식을 가진 경우, SGD가 GD보다 실증적으로 더 낫다고 검증됨
- SGD는 학습에 활용하는 데이터 샘플이 매번 달라짐에 따라 손실 함수의 형태가 약간씩 바뀐다고 볼 수 있으며(모델 구조를 간접적으로 바꿔보는 효과 - 경사하강법의 한계 해결방안②), 이를 통해 local minima에 빠지는 것을 방지하여 최적해에 도달할 가능성을 높이는 방법으로 이해할 수 있음
- 데이터의 일부를 가지고 그래디언트 벡터를 계산하고 파라미터를 업데이트하므로 컴퓨터의 메모리 및 연산 자원을 좀 더 효율적으로 활용할 수 있음
