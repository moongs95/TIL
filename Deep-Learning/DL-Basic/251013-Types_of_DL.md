# 딥러닝 기술 종류들

- 전체적인 구분 방법
- 데이터/학습/태스크 관점으로 구분 가능
- Data : 정형 데이터(Classic Machine Learning), 이미지/동영상(Computer Vision), 텍스트(Natural Language Processing), 음성(Speech Recongnition/Generation)
- Learning : 교사학습(Supervised Learning), 비교사학습(Un-supervised Learning), 강화학습(Reinforcement Learning)
- Task : 인식(Recognition), 생성(Generation)

- AI = 모델 = 연산의 집합 = 프로그램
- 프로그램은 특정 입력을 특정 출력이 나오도록 하는 연산의 집합
- 컴퓨터는 숫자만 이해하므로, 입력/출력 모두 숫자

## 학습 방식에 의한 구분

- 정답 사용 여부, 피드백 제공 여부, 보상 신호 제공 여부에 의해 구분
- 각 학습 방법별로 특징들이 뚜렷해 그에 맞는 AI 태스크들이 존재

### 교사학습(Supervised Learning)

- 라벨링 데이터, 직접 피드백
- 특정 입력에 대한 정답을 알려주는 방식으로 학습
- 교사 학습으로 학습된 모델은 분류(Classification) 태스크 혹은 회귀(Regression) 태스크를 수행
- 데이터 : 교사 학습에서 데이터 구성은 입력데이터 및 정답데이터로 구성되고, 정답데이터를 확보하는 작업을 라벨링(Labeling) 혹은 어노테이션이라고 (Annotation) 함
- 학습/평가 데이터로 분류 : 데이터는 모델 학습을 위한 데이터와 모델 평가를 위한 데이터로 구분해서 사용(학습 데이터의 일부로 평가하는 것은 마치 수능 문제로 공부햇 수능 치는 것과 유사)
- 분류(Classification) : 기정의된 클래스들 중 입력이 어느 클래스에 해당하는지 맞추는 태스크
- 회귀(Regression) : 회귀는 입력 데이터에 대한 실수 혹은 실수의 집합을 (벡터) 출력으로 맵핑해주는 (Mapping) 태스크
- 분류(Classification) + 회귀(Regression) : 분류와 회귀를 동시에 진행하는 경우도 존재 ex. 객체 검출
- 라벨링 노이즈 : 교사학습에서 중요한 것은 데이터의 품질이고 라벨링 노이즈에 따라 교사 학습의 성능이 좌지우지 됨, 데이터 밸런스가 좋아야 함.

### 비교사학습(Un-supervised Learning)

- 라벨링 데이터 X, 피드백 X, 숨은 구조 찾기
- 특정 입력에 대한 정답을 알리지 않고 학습시키는 방법
- 비교사 학습으로 학습된 모델은 차원 축소(Dimension Reduction) 혹은 클러스터링(Clustering) 태스크를 수행
- 클러스터링 : 데이터의 군집화
- 차원 축소 : N차원 입력을 N > n차원으로 출력으로 변경하는 태스크

```text
(1)정보 압축 : 이미지/비디오/오디오 압축 → 정보를 압축하여 저장 공간을 아끼고, 통신 속도를 올린다!
(2)정보 시각화 : 사람이 눈으로 확인할 수 있는 것은 3차원 까지 ex. SNS 관계망 시각화
(3)정보 특징 : 중요한 특징을 추출하여 분석에 사용 → 10개 클래스가 잘 구분되는 2차원의 특징 벡터를 찾는다면 훨씬 분류 성능이 뛰어난 모델을 만들 수 있음! ex. 트리 형태의 부스트 모델(LGBM)은 구간화를 하면 성능이 좋아짐
```

### 강화학습(Reinforcement Learning)

- 라벨링 데이터 X, 지연 피드백, 보상 신호
- 주어진 환경에서 더 높은 보상을 위해서 최적의 행동을 취하는 정책을 학습
- 4가지 구성요소 : 에이전트(Agent)=AI, 보상(Reward), 행동(Action), 환경(Environment)
- Reward가 최대화 되도록 학습
- Model-Free 강화학습에서는 정책/가치 함수에 해당하는 두 가지 AI가 필요

## 데이터 형식, 태스크 종류에 의한 구분

### 데이터 형식에 의한 구분(Data Type)

- AI의 입력에서 다루는 데이터가 어떤 형식이냐에 따라서 구분 짓는 방법
- 크게는 정형 데이터와 비정형 데이터로 나뉘고, 비정형 데이터 중 이미지/동영상 데이터/텍스트 데이터, 음성 데이터로 나뉨

#### 정형 데이터(Tabular Data)

- 구조화된 정보로 저장되어 있는 것이 정형 데이터
- 정형 데이터 외의 데이터는 모두 다 비정형 데이터
- 딥러닝을 통해 비정형 데이터를 구조화된 정보로 바꿀 수 있음
- 정형 데이터는 쉽게 생각해서 표의 형태로 표현이 가능한 데이터
- 주로 회귀/분류 태스크 수행

#### 컴퓨터 비전(Computer Vision, CV)

- 입력으로 이미지나 동영상 데이터를 받는 AI
- ChatGPT 이전에는 가장 많이 상품화된 AI 기술, 딥러닝 기술을 선도
- 얼굴 인식(분류), 얼굴 검출(회귀), 성별 인식(분류), 나이 인식(회귀), 이미지 복원(Super Resolution)
- 지문 인식, 번호판 인식, 자율 주행, 명함 인식(리멤버), 영수증 인식(네이버 영수증 리뷰), 동영상 요약(타임랩스), 배경 제거(누끼 따기), 스타일 변환(스노우 ai 프로필) 등

#### 자연어 처리(Natural Language Processing, NLP)

- 입력으로 텍스트 데이터를 받는 AI
- ChatGPT 이후 자연어 처리 관련 서비스/제품들이 기하급수적으로 증가
- 현재, 딥러닝 기술 선도
- 문장 작성(생성), 혐오글 분류, 번역(생성), 감정 분류
- Large Language Model

#### 음성 인식/생성(Speech Recognition/Generation)

- 입/출력으로 음성 데이터가 활용되는 AI
- 음성 인식은 출력이 텍스트이므로 자연어 처리와 함꼐 사용되는 경우가 많음
- 음성 인식, 감정 분류, 나이 인식(회귀), 화자 분류, 음성 생성
- 음성 인식 예시 : 회의록 작성(클로바 노트), 동영상 편집(Vrew), 네비게이션, 인공지능 스피커 등
- 음성 생성 예시 : 뉴스 읽기, 목소리 생성(클로바 보이스)
- 음성 인식 + 생성 : AICC(인공지능 상담원), 버츄얼 휴먼

### 태스크 종류에 의한 구분(Task Type)

- 인식 및 생성(Recognition & Generation)
- 비정형 데이터와 정보의 입출력 관계에 따라 인식 혹은 생성으로 구분
- 인식은 비정형 데이터 입력에 정보가 출력, 생성은 출력이 비정형 데이터
- 생성은 의도된 정보를 입력, 비정형 데이터를 입력으로 주면서 간접적으로 의도를 줄 수도 있음
- 인식 기술보다 생성 기술이 더 어려움(인식 -> 생성)
- 생성을 해낸다면 인식도 잘 하고 있다는 뜻

```text
[이미지 생성]
1. 거의 불가능할 것 같은 이 태스크의 가능성을 보여준 건 2014년의 GAN (Generative Adversarial Network)
→ 서비스는 아쉬웠음, 이미지 생성이 가능하다는 것에 놀라했지만, 통제력은 (‘이런 이런 이미지를 생성해줘’) 다소 부족해서 상업적으로는 사용이 어려운 상황
2. 통제력 달성은 결국 입력을 텍스트로 받아서 해결. OpenAI에서 ‘21년도에 공개한 DALL-E가 대표적 ex. 아보카도 모양 안락의자
3. ‘23년도에 StabilityAI의 Stable Diffusion이 상업적으로도 이용가능하면서 오픈소스여서 관련 산업이 급격히 성장. 구체적으로 묘사해야함(Prompt Engineering)

[텍스트 생성]
1. 2018년부터 ChatGPT의 근간이 되는 LLM 기술이 개발되기 시작했고, 5년 후 일반 사용자가 느꼈을 때 성능이 좋은 (상품화된) 기술이 등장
2. ‘23년도에 OpenAI에서 내놓은 ChatGPT가 모든 것을 다 변화시킴. 마치 AGI처럼 사람들이 느끼기 시작. 입력된 텍스트에서 스스로 태스크를 파악하여 그에 맞는 결과를 텍스트 출력
```
