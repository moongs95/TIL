# 기본 머신러닝 모델

- 목적 : 분류, 회귀
- 모델의 분류 : 선형모델(Linear Regression), 비선형모델(KNN, Tree)

## Linear Regression

- 데이터를 잘 대변하는 최적의 선 찾는 과정
- 최소자승법(OLS) : 잔차제곱의 합을 최소화하는 회귀계수들을 구하는 법
- 장점 : 학습 및 예측 속도 빠름, 해석이 명확
- 단점 : 선형관계 가정하기 때문에 현실에서는 잘 적용되지 않을 가능성, 이상치에 민감

### 선평회귀 분석의 가정

1. 선형성
2. 잔차 관련 가정
3. 독립성

### 사용시 주의할 점

- 이상치 처리

### 모델 평가와 결과 해석

- R-square(결정계수)
- 회귀 계수에 대한 표준편차, 신뢰구간, p-value 등으로 회귀 모형 해석 가능

### 실전 사례

- 최신 LLM 데이터의 평가모델로 활용
- 평가지표를 variable로 두고 quality를 예측하는 모델을 학습해서 새로운 데이터가 들어왔을 때 quality를 예측하는 방법
- 각 데이터 평가지표가 얼마나 유의미하고 중요한지도 확인 가능

## KNN(K-최근접 이웃)

- 가까운 이웃에 위치한 k개의 데이터를 보고 데이터가 속할 그룹을 판단
- 거리 측정 방법 : 유클리드 거리(L2), 맨해튼 거리(L1) -> 성능차이 존재
- 장점 : 단순, 빠름, 데이터에 특별한 가정 없음
- 단점 : 적절한 k선택 필요, 데이터가 많아지면 분류 느려짐, 스케일링이 필수적(거리기반)

### 실전 사례

- 유사한 데이터(인접한 이웃)을 구하기 위한 방법론으로도 사용 가능 -> 추천시스템 모델
- 결측치 보간

## Decision Tree

- 데이터 내 규칙을 찾아 Tree 구조로 데이터를 분류/회귀하는 과정, 특정 기준(질문)에 따라 데이터 구분
- 리프 노드의 불순도를 최소화 하는것
- 불순도가 높다는 것은 여러가지 샘플이 섞여있다는 뜻
- 불순도 함수 : 지니계수, 엔트로피가 줄어드는 방향으로
- 장점 : 직관적 이해가 쉽고, 데이터 스케일에 민감하지 않음, 범주형 연속형 데이터 모두 처리 가능
- 단점 : 트리 깊이 가 깊어지면 과적합 위험 존재 -> 적절한 Pruning, 트리의 Depth 조절이 필요
- Feature Improtance(변수 중요도) : 트리 분기 과정에서 불순도를 많이 낮출 수 있는 feature -> feature selection 기준

## Random Forset

- ensemble(앙상블) : 주어진 데이터로 여러개의 서로 다른 예측모형을 생성, 결과를 종합 -> 더 정확한 예측결과 기대 가능
- Tree ensemble : 배깅, 부스팅
- 부트스트랩 : 복원추출을 사용해 표본을 추출, 모집단의 통계량을 추론하는 통계적 방법
- 배깅(Bagging, Bootstrap aggregation) : 부트스트랩의 복원추출 과정을 머신러닝 앙상블에 사용
- 랜덤 포레스트 : 배깅의 일종으로 학습데이터뿐 아니라 독립변수들도 무작위로 선택해 트리를 생성
- 장점 : 예측 성능 향상 기대, 과적합 완화 기대
- 단점 : 대용량 데이터 오랜 시간, 해석가능성은 떨어짐
