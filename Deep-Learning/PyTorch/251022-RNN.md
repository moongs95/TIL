# RNN 구현

## Vanilla RNN

- RNN 모델은 recurrent neural network로 입력과 출력을 sequence 단위로 처리하는 모델
    - sequence는 순서대로 배열된 데이터들의 집합으로 순차적으로 연결되어 있고, 각 항목은 특정 순서에 따라 나열되어 있음
    - ex) "Hello, how are you?"라는 문장은 "Hello", ",", "how", "are", "you", "?"라는 단어들이 순서대로 나열되어 있는 sequence
- DNN과 달리 RNN은 시간의 흐름에 따라 정보를 공유할 수 있으며, 이로 인해 이전 단계에서 얻은 정보가 현재 단계에서 영향을 미침
- RNN은 이전 단계의 은닉 상태(hidden states)와 현재 입력을 사용하여 다음 단계의 은닉 상태를 계산하는 방식으로 구성이 되어, 과거의 정보와 현재의 정보를 모두 이용하는 방식으로 구현
    - 처음에는 zero-vector로 초기화 되거나 random으로 초기화

### PyTorch에서의 RNN 구현

- RNN은 `torch.nn.RNN`을 통해 쉽게 구현할 수 있음
- torch.nn.RNN은 t시점의 hidden state를 계산해주는 역할
- torch.nn.RNN은 기본적으로 `input_size`와 `hidden_size`를 지정
    - `input_size`: embedding dimension
    - `hidden_size`: hidden state dimension

### Next word prediction를 위한 RNN 모델 구현

- Next word prediction 작업에서는 주어진 입력 시퀀스로부터 다음 단어를 예측하는 것이 목표
- 이때, 일반적으로 주어진 시퀀스 내에서 **마지막 time step의 hidden state**를 사용
    - RNN은 이전 time step의 정보를 현재 time step으로 전달하는 방식이기 때문에, 모든 이전 time step의 정보를 담고 있는 마지막 time step의 hidden state를 사용하면 문맥 정보를 잘 반영할 수 있음
- torch.RNN의 output은 모든 time step의 정보를 담고 있는 hidden state와 마지막 time_step의 정보만 담고 있는 hidden state 두개를 반환
    - 코딩의 편리성을 위해, 모든 정보를 담고 있는 hidden state를 사용하여 마지막 time_step의 정보만 따로 추출
    - 마지막 time_step의 정보만 담고 있는 hidden state의 shape은 RNN의 layer 개수와 나중에 학습하는 bidirectional 인자에 의해 영향을 받기 때문

## LSTM

- LSTM (Long Short-Term Memory)의 약자로 RNN의 단점인 장기 의존성 문제를 해결하기 위해 고안된 모델
- 앞의 정보가 뒤로 갈 수록 사라짐. 어떤것을 까먹고 어떤 것을 기억할 지 선택하면서 나아감
    - RNN의 장기 의존성 문제: 시퀀스가 길어질수록 앞부분의 정보가 뒷부분의 예측에 영향을 미치기 어려운 문제

### PyTorch에서의 LSTM 구현은 어떻게 할까?

- LSTM은 `torch.nn.LSTM`을 통해 쉽게 구현할 수 있음
- torch.nn.LSTM RNN과 동일하게 기본적으로 `input_size`와 `hidden_size`를 지정
    - `input_size`: embedding dimension
    - `hidden_size`: hidden state dimension
- 일반적으로 RNN과 동일하게 마지막 time step의 hidden state 정보만 추출하여 사용
- torch.LSTM의 output은 모든 time step의 정보를 담고 있는 hidden state와 마지막 time_step의 정보만 담고 있는 hidden state, 그리고 마지막 time_step의 정보만 담고 있는 cell state까지 3개를 반환

## GRU

- GRU (Gated Recurrent Unit)는 LSTM과 마찬가지로 장기 의존성 문제를 해결하고 RNN의 성능을 향상시키기 위해 고안된 모델
- GRU는 LSTM에 비하여 파라미터수가 적기 때문에 연산 비용이 적게 들고, 구조도 더 간단하지만, 성능에서도 LSTM과 비슷한 결과

### PyTorch에서의 GRU 구현

- GRU는 PyTorch에 `torch.nn.GRU`을 통해 쉽게 구현
- torch.nn.GRU RNN, LSTM과 동일하게 기본적으로 `input_size`와 `hidden_size`를 지정
    - `input_size`: embedding dimension
    - `hidden_size`: hidden state dimension
- torch.LSTM의 output은 모든 time step의 정보를 담고 있는 hidden state와 마지막 time_step의 정보만 담고 있는 hidden state 2개를 반환

⇒ 순차적이 아닌 양방향으로 진행할 수도 있음

uni-directional → bi-directional RNN/LSTM/GRU

나는 → 밥을 → 먹었다(순차적, 한쪽 방향으로만 진행)

## Bi-directional RNN

- RNN/LSTM/GRU은 **과거**의 정보만 이용하여 다음을 예측하는 방식으로 구성. 그러나 Bi-directional RNN/LSTM/GRU은 **과거 뿐만 아니라 미래**의 정보를 이용하여 다음을 예측하는 방식
- 다음과 같은 3가지 문장
    1. I'm ____.
    - sad, happy, hungry와 같은 다양한 단어들이 들어갈 수 있음
    2. I'm ____ hungry.
    - very 또는 not과 같은 단어들이 들어갈 수 있음. 1번보단 들어갈 수 있는 단어가 적음.
    3. I'm \____ hungry, so I can eat more.
    - not 이라는 단어가 매우 적절
- 이와 같은 예시처럼, 앞의 단어들 뿐만 아니라 뒤의 단어들을 고려하여 문맥을 이해할 수 있고, 더욱 적절한 단어를 예측할 수 있음

## PyTorch에서의 양방향 RNN/GRU/LSTM 모델 구현

- 양방향 모델을 구현하기 위해선, `torch.nn.RNN/LSTM/GRU`의 `bidirectional` 인자를 True로 설정해주면 됨
- 이 때, **양방향** RNN/GRU/LSTM이므로 hidden state의 크기가 bidirectional=False 일 때 보다 2배 더 커짐
