# 벡터의 독립성

## 벡터의 선형결합과 스팬

### 벡터의 선형결합

- a1**u1** + a2**u2** + ⋯ + an**un**

### 벡터의 스팬

- 집합인데 V라는 벡터 = 선형 결합
- 만들어 질 수 있는 모든 선형결합의 집합이 스팬
- the set of **all linear combinations** of the vectors in V

## 한 벡터의 스팬

- 하나의 벡터가 주어졌을 때 만드는 스팬
- the set of **all linear combinations** of **u** = the set of all scalar multiplications of **u**
- 주어진 벡터의 선형결합 꼴로 나타낼 수 있으면 속함
- span{**u**}은 **u**로 만들어진 직선
- 직선은 벡터들의 집합, 스팬 = 직선(L)

## 두 벡터의 스팬

- 두 개의 벡터가 주어졌을 때 만드는 스팬
- the set of all linear combinations of u1,u2
- 제로 벡터는 모든 스팬의 원소
- 일반적인 상황에서 두 벡터의 스팬 = 평면(P)

## 대체 가능한 벡터

- u2 = 2u1
- 평면 -> 직선
- 같은 방향의 벡터라면 스칼라의 곱으로 변환이 가능
- 직선 위의 모든 벡터들로 스팬을 나타낼 수 있음
- u1, u2는 span의 입장에서 서로 대체 가능 = 두 벡터가 각각 차원을 높이는 데 사용되지 않음 = 두 벡터가 만드는 span이 동일

## 두 벡터의 독립성

- 대체가 불가능한 두 벡터
- 독립적인지 알아보기 위해서 방정식을 세움
- independent(독립적) → 방정식을 만들어서 0, 0만이 유일한 해
- dependent(종속적) → 방정식을 만들어서 0, 0을 제외한 수많은 해가 나옴

## 벡터의 독립성

- n개의 벡터의 독립성(일반화)
- 대체 가능한 벡터가 존재한다면 불필요한 벡터가 존재한다는 뜻
- 세 벡터가 서로 independent -> 3차원 공간
- 두 벡터가 서로 independent -> 평면
- 모두 dependent -> 직선
- 대체 가능한 벡터가 존재하지 않음 = 나머지 벡터들의 linear combination으로 만들 수 없음 -> 독립적
