# 역전파 (Backpropagation)

## 1. 역전파의 개념

### 등장 배경
- **목적:** 손실 함수(Loss Function)를 최소화하기 위한 **효율적인 기울기 계산 방법**
- **필요성:** 딥러닝 모델(MLP 등)의 파라미터가 많아질수록 직접 미분 계산이 매우 복잡해짐
- → **계산 그래프(Computational Graph)** 와 **연쇄 법칙(Chain Rule)** 을 활용

---

## 2. 계산 그래프 (Computational Graph)
- 연산 과정을 **노드(연산)** 와 **엣지(입출력값)** 으로 표현한 방향 그래프
- 장점:
  1. 편미분 계산의 단순화
  2. 중간 연산 결과를 재활용 가능 → 연산 효율 ↑

---

## 3. 연쇄 법칙 (Chain Rule)
- 합성함수의 미분은 각 함수의 미분의 곱으로 표현 가능  
  예:  
f(g(x)) → df/dx = (df/dg) * (dg/dx)

- 뉴럴넷에서는 각 레이어 간의 관계를 이 법칙으로 연결하여 편미분 계산

---

## 4. 역전파 알고리즘 (Backpropagation Algorithm)
- **순전파 (Forward Pass):** 입력 → 출력 계산
- **역전파 (Backward Pass):** 손실함수로부터 거꾸로 미분값 전파

### 핵심 개념
- **∂L/∂f:** 손실함수를 출력에 대해 미분  
- **∂L/∂x, ∂L/∂y, ∂L/∂z:** 이전 레이어 파라미터에 대한 미분  
∂L/∂x = ∂L/∂f * ∂f/∂x

- **Parameter Update:**
w = w - η * ∂L/∂w
(η: 학습률)
---

## 5. MLP에서의 역전파 (수학적 표현)

### 기본 방정식
1. **출력층의 에러**
δL = ∂C/∂aL ⊙ σ'(zL)

2. **이전 레이어로의 에러 전파**
δl = (W(l+1)^T * δ(l+1)) ⊙ σ'(zl)

3. **가중치와 편향의 변화량**
∂C/∂Wl = δl * (a(l-1))^T
∂C/∂bl = δl


### 해석
- **가중치 미분(∂C/∂W):** 이전 레이어 출력값과 에러의 곱
- **편향 미분(∂C/∂b):** 에러 자체
- **학습이 느릴 수 있는 경우:**
1. 이전 레이어 출력값 ≈ 0
2. 활성화함수 미분값 ≈ 0 (예: sigmoid의 극단 영역)

---

## 6. 손실 함수 (Loss Function)

| 종류 | 정의 | 특징 |
|------|------|------|
| **MAE (L1)** | 평균 절대 오차 | 직선형, 미분 일정 |
| **MSE (L2)** | 평균 제곱 오차 | 큰 오차에 민감 |
| **Huber Loss** | MSE + MAE 혼합형 | 이상치에 덜 민감 |
| **Cross Entropy (CE)** | 확률 분포 차이 | 분류 문제에 적합 |
| **Hinge Loss** | 마진 최대화 | SVM에 사용 |

---

## 7. 손실 함수 해석

### 🔹 Backpropagation 관점
- **Vanishing Gradient Problem**
- Sigmoid/Tanh의 미분값이 0~1 사이이므로, 레이어 깊을수록 gradient → 0
- **MSE vs. CE**
- CE는 활성화 미분값이 곱해지지 않아 **학습이 더 빠름**
- 하지만 히든레이어에서는 여전히 gradient vanishing 존재
- → ReLU 사용 시 완화 가능

### 🔹 Maximum Likelihood 관점
- 손실함수를 **확률 분포의 음의 로그우도(Negative Log-Likelihood)** 로 해석
- 데이터 분포에 따라 손실함수 선택

| 데이터 분포 | 적합한 손실함수 |
|--------------|----------------|
| 가우시안 분포 | MSE |
| 베르누이 분포 | Cross Entropy |

## 8. 핵심 요약

| 개념 | 요약 |
|------|------|
| **역전파의 본질** | 손실함수의 기울기를 효율적으로 계산하기 위한 알고리즘 |
| **필수 도구** | 계산 그래프 + 연쇄 법칙 |
| **핵심 수식** | δl = (W(l+1)^T * δ(l+1)) ⊙ σ'(zl) |
| **문제점** | Vanishing Gradient |
| **대응 방법** | ReLU 사용, Batch Normalization, 적절한 초기화 |
| **손실 함수 선택 기준** | 회귀 → MSE / 분류 → CE |
