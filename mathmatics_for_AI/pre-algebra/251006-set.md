# 집합

- 집합이라는 수학적 객체

## 집합의 정의

- set = a collection of distinct and well-defined things(or elements)
- collection : 자료구조의 형태
- distinct : 구분되는, 서로 같지 않은
- well-defined : 객관적인
- things : 서로 같은 종류의 object들
- 집합의 원소는 수 말고도 문자, 도형, 이미지, 사람일 수도 있음

## 집합의 표현

- 원소 나열법 : ,를 기준으로 나열함, 어떤 원소가 있는지 명확
- 조건 제시법 : | 뒤에 조건을 명시, 원소의 의미적 접근

## 집합과 집합의 연산

- 수학적 객체 : 집합
- 연산 : 포함관계, 합집합, 교집합, 곱집합

### 포함관계

- a가 집합 A에 포함됨
- a가 집합 A에 포함되지 않음
- 서로 같은 집합 : 집합 A의 모든 원소가 집합 B에도 포함되고 반대도 성립할 때, A, B는 서로 같은 집합(A=B)
- Subset(부분집합) : 집합 A의 모든 원소가 집합 B에 포함될 때, A는 B의 subset이라 함
- Superset : 집합 B의 모든 원소가 집합 A에 포함될 때, A는 B의 superset이라 함
- Proper Subsets(진부분집합) : 집합 A, B에 대해 A가 B의 subset이지만 완전히 같지는 않을때, A는 B의 proper subset이라 함, 적어도 B의 원소 중 하나는 A에 포함되지 않아야 함
- Proper Supersets : 집합 A, B에 대해 A가 B의 superset이지만 완전히 같지는 않을때, A는 B의 proper superset이라 함, 적어도 A의 원소 중 하나는 B에 포함되지 않아야 함

## 집합의 연산

### 여집합

- A에 포함되지 않은 원소들을 모은 집합을 A의 complement, A^c

### 교집합과 합집합

- 집합 A, B에 모두 포함되는 원소들의 모든 집합을 A와 B의 intersection이라 부름
- 집합 A 또는 B에 포함되는 원소들의 모든 집합을 A와 B의 union이라 부름
- 대수학적 특징 : 교환, 분배, 결합법칙 성립
- 항등식 : 공집합, 합집합, 여집합과의 관계
- 드모르간의 법칙 : 여집합의 분배법칙 성립

### 곱집합

- 집합 A, B에서 원소 a, b들을 각각 뽑아 순서쌍(a, b)를 만들 때, 모든 (a, b)들의 집합을 A X B라 함
- 원소의 개수는 m(집합 A의 개수) x n(집합 B의 개수)
- R^2는 좌표평면, R^3은 좌표공간, R^n은 n차원 공간을 나타냄 -> 집합으로 표현

## 서로소 집합과 파티션

### 서로소 집합

- 집합 A, B에 대해 A와 B의 교집합이 공집합일 때 A, B는 disjoint set
- 상호 배타적 mutually exclusive

### 파티션

- Universal set(U)안에 n개의 집합 A1, A2, ..., An이 있고 U의 모든 원소들이 모두 단 하나의 A집합에만 포함될때 {A1, A2, ..., An}을 U의 파티션이라 부름
- mutually exclusive + collectively exhaustive

## 구간

- 구간도 집합의 한 종류
- 수직선은 실수를 나타내는 집합
- [닫힌 구간]-포함 / (열린 구간)-미포함
- 반 반 ( ], [ )
- 무한대 고려, 상태를 말하는 거라서 열린구간으로 표현, [,∞), (,∞), (−∞,], (−∞,)
- 구간의 합집합
- 구간의 교집합, 새로운 구간으로 표현
