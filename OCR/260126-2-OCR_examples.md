# OCR 활용 예시

# 01. 실생활에서의 활용 사례

## 1.1 실생활에서의 활용 사례

### Real-time Translation (실시간 번역)
- 실시간 번역 서비스는 **OCR 기술이 선행적으로 뒷받침**되어야 함
- 이미지를 정확하게 읽어야 → **정확한 번역 가능**
- 예시:
  - 외국어 메뉴판 번역
  - 표지판, 안내문 실시간 번역 앱

---

### Scanning Card
- 카드 정보를 스캔하여 **자동으로 입력**
- 수작업 입력 오류 감소
- 사용자 편의성 향상

---

### Self Check-In Kiosk (무인 발권기)
- 공항, 호텔 등의 **무인 키오스크**
- 여권 스캔을 통한 정보 자동 인식
- 체크인 및 발권 과정의 자동화

---

# 02. 기업에서의 활용 사례

## 2.1 보험사

### 보험료 지급 프로세스
- 보험료 지급 시 다량의 문서 작업 필요
  - 진료비 영수증
  - 처방전 등
- 보험료 산정을 위해
  - 각 항목의 값을 **직원이 직접 입력**

---

### 보험료 지급 자동화
- OCR을 활용하여
  - 사람이 하던 문서 입력 작업을 **기계로 대체**
- 문서 인식 → 데이터 추출 → 보험료 산정 자동화

**기대 효과**
- 더 빠르고 더 정확한 처리
- 24시간, 연중무휴 보험료 확인 및 지급 가능

---

## 2.2 국제 무역

### 국제무역 프로세스
- 최종 고객에게 물자가 도달하기까지
  - 수많은 물류 프로세스 존재
- 각 프로세스마다
  - **독립적인 문서 작업**이 수반됨

---

### 국제무역의 특징
1. 단순한 일대일 거래가 아닌 **다대다 거래**
2. 수많은 공급자, 파트너, 거래처가 얽힌 **복잡한 공급망**
3. 표준화되지 않은 문서와 프로세스
4. 낮은 정보 투명성

---

### OCR 도입 시 장점

#### 1) 프로세스 자동화
- 사람이 처리하던 문서 작업을 **기계로 대체**
- 업무 처리 속도 및 정확도 향상

#### 2) 문서 표준화
- 기존 문서 표준화가 어려웠던 이유:
  - 서로 다른 기관에서 사람이 직접 작성
- 기계 기반 처리 시:
  - 표준 변경에 대한 **저항 감소**
  - 일관된 문서 구조 유지 가능

#### 3) 정보 투명화
- 표준화 부족으로 공개 정보 선별이 어려웠음
- 기계 처리 시:
  - 공개 가능한 정보 자동 분류
  - 정보 접근성과 투명성 향상

---

## 2.3 비정형 데이터 자산화

### 비정형 데이터란 (Unstructured Data)
- 지속적으로 생성되는 데이터 중 가장 큰 비중
- 예시:
  - 동영상 파일
  - 오디오 파일
  - 사진
  - 보고서(문서)
  - 이메일 본문 등
- 변칙성과 모호성으로 인해
  - 알고리즘을 활용한 처리 어려움
  - 정리되지 않은 정보 형태

---

### 사업적 예시
- 문서 및 음성 데이터 자산화를 통해
  - 고객 상담 서비스의 **Digital Transformation** 진행
- 활용 기술:
  - OCR
  - Speech-To-Text (STT)

---

### 학술적 예시
- 인공지능을 활용한 **Alt Text (대체 텍스트) 생성**
- 시각 장애인을 위한 접근성 향상
- 이미지 콘텐츠의 의미를 텍스트로 설명
