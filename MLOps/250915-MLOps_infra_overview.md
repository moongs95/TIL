# MLOps의 인프라 요소들

- MLOps는 ML Life cycle을 체계적으로 관리하여 더 빠르고 신뢰할 수 있는 결과를 달성하는데 중점

## 인프라의 역할

- MLOps의 성공은 강력한 인프라에 크게 의존(MLOps는 인프라 요소들의 집합체)
- 적절한 인프라 구성은 데이터 처리, 모델 트레이닝, 배포 및 모니터링과 같은 핵심 작업을 지원
- 이러한 작업들을 원활하고 안정적으로 수행할 수 있게 하는 것이 인프라

## 주요 인프라 요소

- Storage : 데이터의 저장, 백업, 복구 기능을 제공
- Computing Resources(컴퓨팅 리소스) : 데이터 처리, 분석, 모델 트레이닝에 필요한 컴퓨팅 파워를 제공
- 환경 관리 툴 : 프로젝트별 독립적인 환경을 제공하는 패키지 및 환경 관리 시스템
- Container(컨테이너) : 애플리케이션과 그 의존성을 패키지화하여 일관된 환경에서 실행할 수 있도록 지원
- Orchestrator(오케스트레이터) : 여러 컨테이너의 배포, 확장, 네트워킹을 관리
- Workflow Management : 작업을 효율적으로 컴퓨팅 리소스에 할당하고 실행
- CI/CD : 상품화하기 위한 중요한 요소, 모델 개발 및 테스트 주기를 단축시켜 빠른 반복을 가능하게 하는 도구
- 버전 관리 : 소프트웨어 프로젝트의 다양한 요소를 버전 관리로 진행
- HTTP & REST API : 다른 시스템과의 통신을 위한 표준 프로토콜 및 인터페이스
