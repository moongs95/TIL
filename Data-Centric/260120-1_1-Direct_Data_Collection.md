# 1-1. 데이터 수집 ① 직접 수집 (Direct Data Collection)

## 01. 데이터 수집 개요

### 1.1 새로운 데이터의 수집

머신러닝 / 딥러닝 프로젝트에서는 **문제 정의에 맞는 원시 데이터(raw data)**를 어떻게 확보하느냐가 핵심이다.  
데이터의 특성과 환경에 따라 하나 또는 여러 방법을 조합해 데이터를 수집한다.

#### 주요 데이터 수집 방법

- **직접 수집 (Direct Collection)**
- **웹사이트 크롤링 (Web Crawling)**
- **오픈 소스 데이터 활용 (Open Dataset)**
- **크라우드 소싱 (Crowdsourcing)**

> 하나의 방식만 고집할 필요는 없으며,  
> **여러 수집 방식을 조합**해 데이터셋을 구성하는 것이 일반적이다.

---

### 1.2 기수집된 데이터의 활용

이미 확보한 데이터의 **양과 다양성**을 늘리기 위해 다음과 같은 방법을 사용할 수 있다.

#### 데이터 확장 방법

- **데이터 혼합 (Data Blending)**
- **데이터 증강 (Data Augmentation)**
- **데이터 합성 (Data Synthesis)**

---

#### 1) 데이터 혼합 (Data Blending)

둘 이상의 데이터 소스를 결합하여 하나의 데이터셋으로 사용하는 방법이다.

**① 유사한 데이터 결합**
- 목적: 데이터 규모 확장
- 예시  
  - 영화 평점 예측  
    - Netflix Prize ⊕ MovieLens Dataset

**② 이종 데이터 결합**
- 목적: 새로운 문제 정의
- 예시  
  - 주가 예측  
    - 주식 가격 데이터 ⊕ 뉴스 텍스트 데이터

---

#### 2) 데이터 증강 (Data Augmentation)

기존 데이터를 **변형(transform)**하여 학습 데이터를 늘리는 방법이다.

- 완전히 새로운 데이터는 아님
- 도메인별로 사용 가능한 기법이 다름

⚠️ **주의사항**
- Bias(편향) 확대 가능
- 노이즈 증가 가능
- 실제 분포와 멀어질 위험 존재

---

## 02. 직접 수집 개요

### 2.1 직접 수집 방법

**직접 수집**이란,  
본인 또는 주변인으로부터 **간단한 도구를 사용해 데이터를 수집**하는 방식이다.

#### 수집 가능한 데이터 유형

- **이미지 / 영상 데이터**
  - 스마트폰, 카메라로 촬영한 사진
  - 스캐너로 스캔한 문서

- **텍스트 / 음성 데이터**
  - 워드 문서, 메모
  - 녹음기를 통한 음성 파일

- **센서 데이터**
  - 스마트폰, 스마트워치 센서
  - 가속도, GPS, 심박수 등

---

### 2.2 직접 수집 방식의 한계

직접 수집은 빠르고 간단하지만, 다음과 같은 구조적인 한계가 존재한다.

#### 1) 수량의 한계
- 딥러닝 학습에 필요한 **대규모 데이터 확보가 어려움**

#### 2) 품질의 한계
- 복잡하거나 정밀한 데이터 수집이 어려움
- 수집 기기 및 환경이 제한적

#### 3) 편향(Bias)
- 주변인은 모집단을 대표하지 못함
- 지역, 나이, 접근성 등에 따른 편향 발생 가능

#### 4) 전문성 부족
- 전문 라벨러 또는 숙련 작업자가 아님
- 기준 일관성 부족

➡️ **결론**  
직접 수집은 **사이드 프로젝트, 토이 프로젝트, 프로토타입(MVP)** 단계에 적합

---

### 2.3 도메인별 직접 수집 예시

#### 이미지 / 영상 데이터
- 예시: 선박 도장 품질 데이터
- 방법: 스마트폰 카메라로 촬영된 이미지 수집

#### 텍스트 / 음성 데이터
- 예시: 감성 대화 말뭉치
- 방법:
  - 감정 라벨 정의
  - 문장 또는 시나리오 작성
  - 음성 녹음 후 데이터화

#### 센서 데이터
- 예시: 다이어리 앱 기반 라이프로그 수집
- 방법:
  - 직접 애플리케이션 제작
  - 스마트폰 / 웨어러블 센서 데이터 수집
    - 이동 경로
    - 심박수
    - 활동 로그 등
