# 버전 관리

- 소프트웨어의 모든 구성 요소(코드, 데이터, 환경설정 등)에 대한 변경 사항을 추적하고 관리하는 프로세스
- 프로젝트의 재현성, 안정정 및 협업 효율성을 높이는데 매우 중요

## 코드 버전 관리

- 소스코드의 변경 사항을 추적
- git과 같은 도구를 사용하여 브랜치, 병합, 커밋 등을 관리

### Git

- 분산 버전 관리 시스템으로 소프트웨어 개발에서 소스 코드의 변경 사항을 추적하는데 널리 사용
- 기능 : Branching & Merging, Change Tracking, Collaboration
- MLOps 적용 : 모델 개발 및 실험 단계에서의 코드 변경 관리, 다양한 실험의 버전을 관리하고 최적의 모델을 선택하는 데 도움

### GitHub/GitLab

- Git repository 호스팅 서비스로 코드 공유, 협업 및 버전 관리 기능을 제공
- 기능 : Issue Tracking, Pull Requests/Merge Requests, CI/CD Integraion
- MLOps 적용 : 코드 리뷰를 통한 품질 관리, CI/CD 파이프라인을 통한 자동화된 모델 훈련 및 배포

## 데이터 버전 관리

- 데이터 세트의 버전을 관리
- 데이터 변경 사항, 업데이트, 변형 과정을 추적

### DVC

- 오픈 소스 버전 관리 시스템, Git과 유사한 인터페이스 제공, 대용량 파일/데이터 세트/머신러닝 모델 등을 효율적으로 관리하는데 특화
- 기능 : 대용량 데이터 관리, 데이터 세트 버전 관리, 데이터 파이프라인 관리, 실험 관리 및 추적, 원격 저장소 지원
- 특징 : Git과의 통합, 확장성, 플랫폼 독립성, 커뮤니티 및 문서

### Git LFS(Large File System)

- Git의 확장 도구러서 대용량 파일을 효율적으로 관리
- 기능 : 댜용량 파일 관리, 버전 관리, 효율적인 데이터 전송, 통합 및 호환성
- 특징 : 확장성, 성능 최적화, 유연한 작업 흐름, 쉬운 설정 및 사용

### Delta Lake

- Apache Spark 위에 구축된 오픈 소스 저장소 레이어
- 대규모 Data Lake 환경에서 데이터의 신뢰성과 성능을 향상시키기 위해 설계
- ACID 트랜잭션 지원, 데이터 무결성과 복잡한 데이터 파이프라인 관리를 용이
- 기능 : ACID 트랜잭션, 스케일러블 메타데이터 처리, Time Travel, 통합 스트리밍 및 배치 처리, 스키마 검증
- 특징 : 데이터 무결성 및 신뢰성, 성능 최적화, 유연한 데이터 처리, Spark 통합

## 모델 버전 관리

- 모델의 각 버전을 추적
- 훈련된 모델, 파라미터, 하이퍼 파라미터 등의 버전을 관리

## 환경 및 구성 버전 관리

- 머신 러닝 모델을 훈련하고 실행하는 데 사용되는 환경의 버전을 관리
- Docker와 같은 컨테이너화 도구를 사용하여 환경을 일관되게 유지

### MLOps에서의 중요성

- 재현성 : 버전관리를 통해 언제든지 특정 시점의 실험을 정확하게 재현할 수 있어야함
- 협업 : 변경 사항을 추적, 충돌을 방지, 팀 간의 효율적인 협업 지원
- 품질 관리 : 코드 리뷰, 테스트, CI/CD 파이프라인을 통해 높은 품질의 모델을 보장
- 규정 준수 및 감사 : 머신러닝 프로젝트의 각 단계를 문서화하고 기록을 유지
