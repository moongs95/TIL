# 신경망(Neural Network) 구조 개요

- 딥러닝을 위한 신경망은 데이터 연산을 수행해 출력단에서의 예측 값을 바탕으로 손실 함수를 계산하기 위한 다양한 계층(layer)으로 구성됨
- 이러한 다양한 계층(layer)은 파이토치의 직관적인 API를 이용하면 몇 줄의 간단한 코드만으로 쉽고 빠르게 구축
- 파이토치에서는 신경망을 구축하기 위한 다양한 데이터 구조나 layer 등이 torch.nn 패키지에 정의
- torch.nn 패키지를 이용하면 신경망층/손실함수층/활성화 함수층/최적화 알고리즘을 서로 조합해서 쉽고 빠르게 딥러닝 모델을 만들어 학습시키는 것이 가능
