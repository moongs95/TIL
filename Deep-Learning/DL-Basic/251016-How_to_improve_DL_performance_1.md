# 성능 고도화 방법 I — 과적합, 편향과 분산, 지역-전역 최소값, 네트워크 안정화

## 좋은 모델 학습을 위한 기초 (Fundamentals for Training a Good Model)

**과적합(Overfitting)**: 모델이 학습 데이터에 너무 맞춰져 일반화하지 못하는 현상  
**편향(Bias)**: 모델의 예측이 실제 값에서 일관되게 벗어나는 정도  
**분산(Variance)**: 예측이 학습 데이터의 작은 변화에 얼마나 민감한지를 표현

---

### 과적합

과적합은 학습 데이터 오차가 일반화 오차에 비해 현격하게 낮아지는 현상이다.

과소적합(Underfitting)이나 과적합(Overfitting)이 아닌 상태를 **적합한 상태(Good fitting)** 이라 하며,  
모델이 **강건하다(Robust)** 고 표현한다.

---

### 편향과 분산 (Bias and Variance)

**편향과 분산의 관계**
- 둘 다 낮은 것이 이상적.
- 모델 복잡성이 증가하면 분산은 증가하고 편향은 감소한다.
- 모델 복잡성이 감소하면 편향은 증가하고 분산은 감소한다.

따라서 모델 설계 시 **편향과 분산의 트레이드오프를 최적화**하여  
평가 데이터 성능을 최대화해야 한다.

**일반화 오차 = 편향 + 분산**

---

### 지역 최소값과 전역 최소값

- **지역 최소값(Local Minimum)**: 손실 함수의 특정 영역에서 가장 낮은 점  
- **전역 최소값(Global Minimum)**: 손실 함수 전체 영역에서 가장 낮은 점

지역 최소값에 빠지면 학습이 진행되지 않으므로,  
**학습률(Learning Rate)** 조정을 통해 전역 최소값에 도달하도록 해야 한다.

---

## 네트워크 안정화 기법 (Network Stabilization Techniques)

학습 도중 활성화 출력을 조절하여 과적합과 불안정한 그래디언트 문제를 완화한다.

---

### 드롭아웃 (Dropout)

**드롭아웃(Dropout)**: 학습 시 임의의 가중치 노드를 일정 확률로 비활성화시키는 방법.  
일부 노드가 꺼져도 모델이 잘 작동하도록 하여 과적합을 방지한다.

- 비활성화된 노드에서는 역전파(Backpropagation)가 진행되지 않음.
- 학습 중엔 일부 뉴런을 랜덤하게 꺼서 여러 모델을 앙상블한 효과를 냄.
- 테스트 시엔 모든 뉴런을 사용하므로 출력값의 크기가 커질 수 있음.

---

### 정규화 (Normalization)

#### 피처 스케일링 (Feature Scaling)

입력 데이터를 일정한 범위(보통 0~1)로 맞추는 과정.  
이를 통해 각 피처가 편향 없이 학습되도록 한다.

피처 간 스케일이 다르면 큰 스케일을 가진 피처의 영향력이 커질 수 있다.

---

#### 여러 정규화 방법

1. **배치 정규화 (Batch Normalization)**  
2. **레이어 정규화 (Layer Normalization)**  
3. **인스턴스 정규화 (Instance Normalization)**  
4. **그룹 정규화 (Group Normalization)**

---

### 배치 정규화 (Batch Normalization)

가장 널리 쓰이는 정규화 방식으로,  
**배치 단위의 평균과 분산**을 이용해 활성화 출력을 정규화한다.

→ 표준 정규분포를 따르도록 함  
→ 학습 안정화 및 기울기 폭발/소실 문제 완화


**내부 공변량 변화(Internal Covariate Shift)**를 줄여  
각 층의 입력 분포를 일정하게 유지시킨다.

#### 적용 위치
`Fully Connected (또는 Conv) → BatchNorm → Activation`

#### 이유
- 활성화 전에 정규화를 해야 입력 분포가 건강하게 유지된다.  
- 시그모이드 등 활성화 함수가 포화되지 않도록 돕는다.

#### 요약 표

| 구분 | 내용 |
|------|------|
| **BN의 목적** | 각 층 입력 분포를 안정화 |
| **적용 위치** | `FC (또는 Conv) → BN → Activation` |
| **이유** | 활성화 전 정규화를 통해 포화 방지 |
| **시그모이드 관계** | 입력 스케일 조정으로 포화 방지 |
| **다음 층에서도 필요** | 각 층마다 입력 분포가 달라지기 때문 |

---

### 배치 정규화의 한계

- 시계열 데이터에는 잘 맞지 않음 (배치 내 의미가 바뀜)
- 작은 배치 크기에서는 통계량이 불안정함

---

### 레이어 정규화 (Layer Normalization)

**배치 정규화의 한계**를 보완.  
배치 크기에 의존하지 않고, **각 데이터 샘플 내 피처들의 평균과 분산**을 이용.

→ RNN, LSTM 등 시계열 데이터에 적합


---

### 인스턴스 정규화 (Instance Normalization)

각 데이터 샘플의 **각 채널별 평균과 분산**을 계산.  
**이미지 스타일 변환(Image Style Transfer)** 등에서 사용.


참고: [TensorFlow Style Transfer 예제](https://www.tensorflow.org/lite/examples/style_transfer/overview?hl=ko)

---

### 그룹 정규화 (Group Normalization)

채널을 여러 그룹으로 나누고, 각 그룹 내 평균과 분산을 정규화.  
**배치 크기에 덜 민감**하며 **인스턴스 정규화의 확장판**이라 할 수 있음.

→ 객체 인식(Object Detection), 영역 분할(Segmentation) 등 소규모 배치 학습에 적합

---

## 요약

| 구분 | 설명 |
|------|------|
| **배치 정규화** | 배치 단위로 정규화하여 학습 안정화 |
| **레이어 정규화** | 시계열 데이터 등 가변 입력에 적합 |
| **인스턴스 정규화** | 각 데이터 고유 특성 유지 (예: 스타일 변환) |
| **그룹 정규화** | 작은 배치에서도 잘 작동, 인스턴스 정규화 확장 |
