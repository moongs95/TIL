# 그래프

어플리케이션에서 의미가 있음

간단한 개념

새로운 자료 구조

non-linear한 자료표현

## Node와 Edge

점과 선으로 이루어진 자료구조

점 : node, vertex

선 : edge, link

→ graph, network

cf. deep learning의 neural network도 그래프로 표현 노드와 엣지

### 그래프 예시 - 친구 그래프

SNS - social network service

팔로워끼리의 팔로우 관계 표현

친구 관계의 network
node = 사람
edge = 친구

### 그래프 예시 - 배달

배달 장소를 연결해서 최단 거리 구하기

node =  배달 지역
edge = 배달 경로

## 그래프의 표현

- Diagram

node와 edge 형태의 그림으로 나타낸 것, 시각적으로 이해하기 쉽지만 컴퓨터가 처리하기 어려움

- set

V ={A, B, C, D, E, F} → 어떤 객체가 있는지
E ={(A, B), (A, C), (B, E), (C, E), (C, D), (D, F)} → 객체끼리 어떤 연결을 이루고 있는지
G=(V, E) → graph는 vertec와 edge의 집합

- 인접행렬(Adjacency Matrix)

연결된 건 1, 아닌건 0으로 행렬을 표현 → 대칭 행렬로 나옴

→ 컴퓨터가 이해하기 쉬움

- 연결 리스트(Adjacency List) → 참고

## 그래프의 종류

Undirected Graph : 방향성이 없는 것 ex. 친구추가

Directed Graph : 방향성이 있는 것 ex. 팔로우, 에스컬레이터

Unweighted Graph : 가중치가 없는 것

Weighted Graph : 가중치가 있는 것, 물리량, 시간, 돈, 거리 등

### 특수한 형태의 그래프

Complete Graph : 노드들이 모두 연결

Cycle Graph : 루프가 만들어짐, 내부 연결은 없음 ex. 손을 잡고있음

## 그래프의 정보

Order: the number of nodes 그래프 노드의 갯수
Size: the number of edges 엣지의 갯수

degree of a node: the number of connected nodes 각 노드에 연결된 엣지의 수

Density =2|E| / |V|(|V|−1) 집합의 크기 ||, 분자, 분모 2로 나눠주면 현재 edge 수 / 최대 edge 수 ⇒ 밀도

그래프 활용 예시

사회 문제, 사람 관계, 인프라 나타냄

네트워크 분석을 통해 전략 의사결정할 수 있음

### 지하철 노선도와 그래프

지하철 역: Node
구간: Edge

subgraph 환승 고려

출발점부터 도착점까지의 최적의 이동경로
배차 간격 조정
신구간 개설

지하철 노선도의 인접행렬

행렬 곱셈으로 표현, 제곱, 세제곱 … 으로 이동 할 수 있는 경로를 늘림

제곱은 두 번가서 이동하는 것까지 고려해서 경우의 수

세제곱은 세 번가서 이동하는 것까지 고려해서 경우의 수

역들 사이의 가중치도 고려해서 역들 사이의 시간도 생각할 수 있음

## 그래프와 Walk

엣지들의 수열

 A walk is a finite or infinite sequence of edges which joins a sequence of vertices.

walk의 가짓수를 인접행렬로 나타냄

## Directed Graph와 Path

방향성을 추가한다면? → 연결이 아니라 대칭성이 깨짐, 삼각행렬로 변경

path : 노드들이 한 번만 선택되는 walk들

A path is a trail in which all vertices (and therefore also all edges) are distinct.

## Weighted Graph와 최단경로

가중치 그래프에서의 분석

최단경로를 선택, 가중치가 가장 적은 것, 비용이 가장 적은 것

또는 최대화일 때 선택도 고려할 수 있음
