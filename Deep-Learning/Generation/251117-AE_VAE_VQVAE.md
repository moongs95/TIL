# 📘 오토인코더(AE) · 변분 오토인코더(VAE) · VQ-VAE & VQ-VAE-2 정리

---

# 1. 오토인코더(Autoencoder)

## 1.1 개념
- **비지도 학습 기반 특징추출 모델 (1987)**
- 입력 데이터를 압축한 후 다시 복원하는 구조
- 목표: 입력 데이터의 **패턴을 압축된 잠재 공간(latent space)에 학습**

### 구조
- **Encoder**: 입력 → 저차원 잠재 벡터 z로 변환  
- **Decoder**: z → 입력을 복원  
- **Loss**: 입력과 복원된 데이터의 MSE(재구성 오차)

### 특징
- 차원 축소(비선형 PCA 형태)
- 중요한 정보만 잠재공간에 남게 됨
- 단점: 생성 모델이 아님 → **새로운 데이터 생성 불가**

---

# 2. 디노이징 오토인코더(Denoising AE)

## 개념
노이즈가 섞인 입력을 받아 **노이즈 없는 원본을 복원**하도록 학습한다.

### 효과
- 노이즈가 있어도 특징을 잘 잡아내는 **강건한(latent robustness)** 표현 학습
- 미세한 입력 변화에도 안정적인 잠재벡터를 생성

---

# 3. 오토인코더의 활용

## 3.1 특징 추출(Representation Learning)
- 학습된 Encoder를 **특징 벡터 추출기**로 활용
- 이 latent vector로 분류/클러스터링 수행 가능
- 장점: 라벨 없이도 내부 구조를 학습  
- 단점: 사람이 해석하기 어려운 latent 공간이 생성될 수 있음

## 3.2 이상치 탐지(Anomaly Detection)
- 정상 데이터만 학습 → 정상 데이터는 잘 복원됨
- 이상 데이터는 잘 복원되지 않아 **재구성 오차가 크게 증가**
- 재구성 오차 기준으로 이상치 판별

---

# 4. 변분 오토인코더(VAE)

## 4.1 개념
- AE와 구조는 동일하지만, **새로운 데이터 생성이 가능한 생성 모델**
- 잠재 변수가 **확률분포(z ~ N(0, I))**를 따른다고 가정
- 확률적 디코더 p(x|z) 를 통해 데이터 생성

## 4.2 핵심 아이디어
오토인코더의 latent vector를 **정규분포에 따르도록 규제(KL Divergence)** 하여  
샘플링이 가능하도록 만듦 → 생성모델이 됨.

## 4.3 ELBO (Evidence Lower Bound)
VAE는 log p(x)를 직접 최적화할 수 없으므로  
계산 가능한 **ELBO를 최대화**하여 학습한다.

ELBO =  
1) **재구성 오차(Decoder가 x를 얼마나 잘 복원하는가)**  
2) **잠재 분포 정규화 항(KL Divergence)**  
두 항의 합으로 구성됨.

## 4.4 재매개변수화 Trick (Reparameterization Trick)
- 샘플링은 미분 불가 → 학습 불가능
- z = μ + σ * ε (ε ~ N(0,1)) 로 변환하면 **미분 가능**
- VAE 학습을 가능하게 만드는 핵심 기법

## 4.5 장단점

### 장점
- 잠재 벡터가 유용한 특징을 가짐  
- 생성 모델이므로 새로운 데이터 생성 가능

### 단점
- Likelihood의 **하한만 최적화**하여 실제 분포를 완전히 학습하기 어려움  
- 생성 이미지가 비교적 **흐릿함(blur)**

---

# 5. 벡터 양자화 변분 오토인코더 (VQ-VAE)

## 5.1 등장 배경
VAE의 단점(연속 잠재 → 흐릿한 이미지)을 해결하기 위해  
**잠재공간을 “이산(discrete)” 코드북(codebook)** 으로 표현.

## 5.2 핵심 아이디어
- Encoder 출력 → 가장 가까운 codeword로 **양자화(Vector Quantization)**
- latent vector z가 연속값이 아니라 **K개의 discrete code 중 하나**가 됨.
- 이미지/텍스트는 실제로 유한한 패턴들의 조합 → 이산 표현이 더 자연스러움

## 5.3 ELBO 구성
VAE와 유사하지만, **잠재 분포가 discrete이므로 정규화 항이 상수**
→ 사실상 재구성오차만 최적화

## 5.4 학습의 어려움과 해결
양자화(discrete choice)는 미분 불가능 → 역전파 불가  
→ **Straight-through estimator**(sg: stop-gradient) 사용  
잠재 변수에 대한 gradient를 Encoder 입력으로 전달하여 학습 가능해짐.

## 5.5 생성 과정
- 단순 정규분포 샘플링이 불가능 → 코드북의 분포를 따르는 제너레이터 필요
- PixelCNN 등 오토리그레시브 모델로 **코드북 분포 p(z)** 를 학습  
→ VQ-VAE는 실제로 “디코더 + PixelCNN” 구조로 생성모델 완성됨

# 6. VQ-VAE-2

## 6.1 고해상도 이미지를 위한 계층 구조
- 고해상도 이미지는 단일 코드북으로 표현하기 어려움  
→ **Top–Bottom 2계층 구조**로 분리
  - Top Level: 전역(Global) 구조  
  - Bottom Level: 지역(Local) 디테일

## 6.2 사전 분포 p(z) 학습
- Top: PixelSNAIL(자기어텐션 기반)로 전역 정보 모델링  
- Bottom: Top 계층의 잠재 벡터를 condition으로 활용

## 6.3 생성 품질 향상
- 필요시 **Rejection Sampling** 사용  
  - 사전학습된 분류기가 예측 확률 낮은 샘플 제거 → 품질 향상  
- VAE와 비교 시 훨씬 선명하고 고품질 이미지 생성 가능

---

# 7. 요약

## 오토인코더(AE)
- 입력 복원 모델  
- 특징추출·이상치 탐지에 활용  
- 생성 모델 아님

## 변분 오토인코더(VAE)
- AE+확률적 잠재변수  
- ELBO 최적화  
- 생성 가능하지만 이미지가 흐림

## VQ-VAE
- 잠재 공간을 이산 코드북으로 표현  
- 보다 선명한 생성 가능  
- PixelCNN 등과 조합해야 완전한 생성 모델이 됨

## VQ-VAE-2
- 계층화 구조 적용 → 고해상도 이미지 생성  
- Top/Bottom Level의 잠재벡터로 Global/Local 정보 분리  
- Rejection Sampling으로 품질 향상

# ✔ 핵심 흐름 한눈에 정리

AE → 특징 추출 / 복원  
↓  
Denoising AE → 노이즈에 강한 특징  
↓  
VAE → 확률적 잠재공간, 생성 모델  
↓  
VQ-VAE → 이산 잠재, 더 선명한 생성  
↓  
VQ-VAE-2 → 고해상도 / 계층 구조 / 고품질 생성
