# 🎨 적대적 생성 신경망(GANs) & 조건부 생성 모델 정리

---

# 1. GANs 소개

생성 모델의 한 종류로, **두 개의 신경망이 적대적으로 경쟁하며 학습되는 구조**를 가진다.

## 1.1 GANs란?

**GANs (Generative Adversarial Networks)**  
- **Generative**: 데이터를 생성  
- **Adversarial**: 두 네트워크가 서로 적대적으로 경쟁  
- **Network**: 신경망 기반 모델  
- 생성 모델의 대표적인 형태로 매우 선명한 이미지를 생성하는 것이 특징

## 1.2 VAE vs GANs

| 구분 | VAE | GANs |
|------|------|-------|
| 생성 방식 | 입력 분포를 정규화하며 근사 | 진짜/가짜 판별을 속이며 생성 모델 개선 |
| 학습 목표 | ELBO 최대화 | Generator vs Discriminator 대립 |
| 장점 | 안정적 학습 | 매우 선명한 이미지 생성 |
| 단점 | 흐릿한 이미지 | 학습 불안정, 모드 붕괴 |

VAE는 **데이터 분포를 부드럽게 근사**, GAN은 **판별 모델을 속이며 더 정교하게 생성**한다.

---

# 2. GANs 구조와 학습

GAN은 **Generator(G)** + **Discriminator(D)** 두 모델로 구성된다.

## 2.1 GAN 구조

### Generator (G)
- 입력: 잠재 벡터 z (노이즈)
- 출력: 가짜 데이터
- 목표: 판별자를 속여 실제(real)로 판별받기

### Discriminator (D)
- 입력: 실제 데이터 or 생성된 데이터
- 출력: Real(1) / Fake(0)
- 목표: 진짜/가짜를 정확히 구별

---

## 2.2 GAN 목적 함수

GAN의 학습은 **두 모델 간 경쟁 게임(Zero-Sum Game)**

### Discriminator의 목표 (maximize)
- 실제는 1, 가짜는 0으로 맞히기

### Generator의 목표 (minimize)
- 생성된 데이터를 판별 모델이 실제라고 믿게 하기

### 최적 상태
- 생성 분포 pg = 실제 데이터 분포 pdata  
- 이때 GAN 목적 함수는 **–log 4** 로 수렴

---

## 2.3 GAN 학습 방식

GAN 학습은 다음 2단계를 반복한다:

### 1) Discriminator 업데이트  
- 실제 데이터 = Real  
- Generator가 만든 Fake = Fake  
- 이진 분류를 학습  

### 2) Generator 업데이트  
- D를 속이도록 Fake를 생성  
- D의 파라미터는 고정한 채 G만 업데이트  

---

## 2.4 실전에서의 문제와 개선

### (1) 기울기 소실 문제(Gradient Vanishing)
- 판별자가 너무 잘하면 Generator가 학습할 신호가 약해짐

→ 해결: **판별 모델이 틀릴 확률을 최대화하는 방식으로 손실 변경**

### (2) 모드 붕괴 (Mode Collapse)
- Generator가 몇 종류의 데이터만 반복해서 생성하는 문제

### (3) 불안정한 학습
- 두 모델이 경쟁하므로 hyperparameter, balance tuning 필요

---

## 2.5 GAN 학습 의사 코드

### Discriminator 업데이트
- 진짜 데이터 batch 하나  
- 노이즈로 생성된 fake batch 하나  
- 두 데이터를 분류하도록 학습

### Generator 업데이트
- Fake 이미지를 생성  
- D가 Real로 판단하도록 만들기 (역전파 신호로 학습)

---

## 2.6 생성 결과

### VAE vs GAN 생성 이미지 비교
- VAE: 흐릿함  
- GAN: 매우 선명함  
- 최신 GAN (StyleGAN, StyleGAN2/3): 고해상도 얼굴, 사물 생성 가능

**GAN의 핵심 요약**
- 두 신경망의 적대적 학습 구조  
- 매우 선명한 이미지 생성 가능  
- 그러나 학습이 어렵고 모드 붕괴 위험 존재  

---

# 3. 조건부 생성 모델

GAN을 더 실용적으로 만들기 위해 **조건(condition)** 을 추가한 생성 모델.

## 3.1 조건부 생성 모델의 필요성

일반 GAN의 한계:
- "무엇을 생성할지" 제어 불가능

예)
- 강아지 이미지를 생성하고 싶은데 고양이가 생성될 수도 있음

→ **조건부 생성 모델(Conditional Generative Model)** 필요

### 조건의 예
- 클래스(label)
- 이미지
- 텍스트
- 오디오  
등 다양한 modality

---

# 4. 조건부 GAN (CGAN)

## 4.1 CGAN 개념

- 생성자 G: (z + 조건 y) → 이미지 생성  
- 판별자 D: (이미지 + 조건 y) → Real or Fake  

조건이 일치하지 않으면 Fake로 판별되므로  
**조건을 만족하는 이미지 생성이 가능**하다.

---

## 4.2 다양한 조건 부여 방식

### 1) 단순 Concatenation
- 입력 벡터에 조건 y를 그냥 이어붙임  
- MNIST 같은 단순 데이터에서는 잘 됨  
- 복잡한 이미지에서는 한계

### 2) ACGAN
- Discriminator가  
  - 진짜/가짜  
  - 클래스  
  두 가지를 함께 학습  
→ 판별자가 클래스의 특징을 학습하여 생성 품질 향상

### 3) Projection GAN
- 조건을 embedding 공간에서 내적  
→ 더 정교한 조건 반영 가능

---

## 4.3 다중 모드 조건부 생성

조건은 라벨뿐 아니라 다양한 표현이 될 수 있다:

### 예시 모델
- **Pix2Pix**: 이미지 → 이미지 변환  
- **LostGANs**: 레이아웃 → 이미지  
- **Speech2Image**: 음성 → 이미지  
- **GigaGAN**: 텍스트 → 초고화질 이미지  

---

## 4.4 요약: 조건부 생성 모델이란?

- 조건(condition)을 입력 → 원하는 형태로 데이터 생성  
- 클래스, 텍스트, 이미지, 레이아웃 등 다양한 조건 사용  
- 더 높은 품질·다양성을 얻을 수 있으나  
  **조건 데이터 수집 비용이 크다**

# 📌 전체 요약

## GANs
- Generator & Discriminator의 경쟁 구조  
- 매우 선명한 이미지 생성  
- 학습이 어렵고 불안정, 모드 붕괴 등 문제 존재

## Conditional GANs
- 조건(y)을 추가하여 의미 제어 가능  
- 단순한 MNIST부터 텍스트→이미지(GigaGAN)까지 다양한 형태  
- 실용적인 생성 모델로 발전 중
