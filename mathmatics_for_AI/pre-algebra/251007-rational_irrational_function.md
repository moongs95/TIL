# 유리함수와 무리함수

## 유리식과 유리함수

- 유리식 : 분모에 x에 관한 다항식이 있는 식
- 다항식은 유리식에 포함
- 유리함수에서 가장 중요한 함수는 y=1/x -> 감소함수, 원점 대칭, 기함수, 역함수와 자기자신이 같음
- y=1/x^2 -> 좌우 대칭, 우함수, 역함수가 존재할 수 없음
- y=1/x^3 -> 기함수, 역함수가 자기자신과 다름
- y=1/x^4 -> 우함수

## 무리식과 무리함수

- 제곱근 : n제곱해서 x가 나오는 수
- 양수, 음수가 모두 가능한 상황에서 양수를 선택
- 2제곱근, 3제곱근을 많이 사용
- 홀수의 거듭제곱근의 경우 음수에 대한 거듭제곱근 연산이 가능
- power function처럼 변경 : 지수가 분수가 됨
- 제곱근 함수 : domain, range = [0, 무한대) → 증가함수, even, odd 다룰 수 없음
- 세제곱근 함수 : domain, range = 실수 → 음수도 가능, odd, 증가함수, 역함수도 가능 y = x^3
