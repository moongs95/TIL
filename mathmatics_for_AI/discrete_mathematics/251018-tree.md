## 문자열 전송하기

다음과 같은 문자열을 효율적으로 전송하려고 한다.

AAAAFAAAABBBAAACAAAABBBBCCBBBBDDBBBBCCCAAAAACCCCDDDDEEEF

→ 압축을 잘 할 수록 효율적

핸드폰끼리, 통신사 기지국이랑 사용자끼리 전송

문자열 압축, 전송 중요한 문제, 비용 최소화

solution 1. ASCII Code로 보내기

아스키코드로 변경해서 문자를 숫자로 대응하여 보내기

Hex code는 모두 8bit

보내려는 문자는 모두 56개

총 448bit가 필요

solution 2. 3비트로 압축하기

6개의 문자열만 사용하고 있음

Bin code는 모두 3bit

보내려는 문자는 모두 56개

총 168bit가 필요
→ 38% 감소! 대략 3배에 해당하는 내용을 더 보낼 수 있음

### Huffman Coding의 과정

Step.1 빈도 구하기

자주 등장하는 건 낮은 비트 조금 등장하는 건 더 많은 비트를 할당

Step.2 내림차순으로 Node 정렬하기

Step.3 작은 빈도의 Node 합치기

parent node 생성해서 연결 해줌(child node)

전체 트리 구조 만들기

roof, leaf로 생성

Step.4 코드 할당하기

분기가 될 때마다 1, 0나눠짐

leaf 노드에서 지나온 거리를 붙여서 코드를 할당해 줌

자연스럽게 노드가 깊숙하게 있을 수록 비트가 늘어남

앞부분부터 코드가 나오면 문자열을 매칭할 수 있음, 중복이 나오지 않음

총 128bit, 비트수가 많이 감소함
