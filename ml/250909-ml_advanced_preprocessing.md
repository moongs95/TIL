# 전처리 기법

## 데이터 전처리

- 데이터 전처리는 데이터의 특성을 이해하고 수정하여 품질을 향상시키는 과정
- 편향 제거, 신뢰성 높은 모델 제작
- 알고리즘 모델 성능에 영향을 끼치는 중요 변수나 패턴을 찾기 용이
- 시각화 용이

### 데이터의 종류

- 정형 데이터와 비정형 데이터
- 변수의 종류 : 수치형 변수(연속, 이산), 범주형 변수(명목, 순위)

### 결측치 다루기

- 데이터 손실과 더불어 분포를 왜곡시켜 편향을 야기시키는 원인
- 매커니즘 : 완전 무작위 결측, 무작위 결측, 비무작위 결측
- 패턴 : 일변량 결측 패턴, 단조 결측 패턴, 일반 결측 패턴, 규칙 결측 패턴
- 처리 : 삭제(목록 삭제, 열 삭제), 대체(통계값 대체, 회귀 대체)

### 이상치 처리

- 변수의 분포상 비정상적으로 극단적이며 일반적인 데이터 패턴을 벗어나는 관측치
- 이상치 탐지 : Z-Score, IQR

## 카테고리와 기타 변수 다루기

### 연속형 변수 다루기

- 함수변환 : 로그변환, 제곱변환, Box-Cox변환
- 스케일링 : min-max, 표준화, 로버스트
- 구간화 : 등빈도, 등간격

### 범주형 변수 다루기

- 원-핫 인코딩
- 레이블 인코딩
- 빈도 인코딩
- 타겟 인코딩
