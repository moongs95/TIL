# Tensor

- 텐서는 파이토치 기본 데이터 타입이며 배열(array)이나 행렬(matrix)과 유사한 자료 구조임
- 일반적으로 1차원 데이터를 벡터(vector), 2차원 데이터를 행렬(matrix), 3차원 이상의 데이터를 텐서라고 말하지만
- 파이토치에서는 이런 차원에 관계없이 입력과 출력 그리고 학습에 필요한 모든 데이터를 텐서(Tensor) 데이터 타입 정의

## 벡터

- 쌍을 이루는 대괄호가 1개면 1차원
```python
[1, 2]
```

## 행렬

- 쌍을 이루는 대괄호 2개면 2차원
```python
[[1, 2], [3, 4]]
```

### 텐서
- 쌍을 이루는 대괄호 3개면 3차원
```python
[[[1, 2]],[[3, 4]]]
```

## 딥러닝 기본 모델

- 딥러닝에서는 학습 파라미터인 가중치 W와 바이어스 b에 대한 미분(Differentiation) 계산이 필요한데,
- 파이토치에서는 모든 텐서 데이터에 자동미분(Automatic Differenctiation) 기능이 최적화 되어있어,
- 딥러닝 모델을 구축하고 적용하는데 있어 매우 편리함

1. 입력데이터 X, 출력 값 Y, 정답 T, 가중치 W 그리고 바이어스 b 모두 텐서 데이터
2. 손실함수 E(W, b) = Y - T 계산식은 개념적으로 나타낸 것
3. 딥러닝 모델에 맞게 최적화된 손실함수가 존재(MSE, Binary/Categorical/Sparse Cross-Entropy 등)
