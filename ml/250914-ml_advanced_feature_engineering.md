# 파생변수

- 기존의 변수를 기반으로 새로운 변수를 생성

## 파생변수 생성1 - 변수 자체를 변환하는 방식

- 함수변환 : 로그변환, 제곱근변환, Box-Cox 변환
- 스케일링 : Min-Max 스케일링, 표준화, 로버스트 스케일링
- 구간화 : 도메인 지식을 바탕
- 기타 변수 : 분할, 시간변수

## 파생변수 생성2 - 변수 간의 관계를 활용

- 변수 결합 : 서로 다른 의미를 담고 있는 변수를 통해 새로운 의미 파생 -> 도메인 지식과 연관
- 통계 기반 변수 : 집계 후 평균, 중앙, 최대, 최소 등 통계치를 파생 변수로 적용
