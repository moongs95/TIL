# 벡터와 도형

- 직선, 평면, 초평면(Hyperplane)을 의미

## 스팬의 차원

- 스팬의 차원은 V의 벡터 중 선형 독립적인 벡터의 개수
- 유의미한 벡터들의 차원

### 벡터와 직선

- dim(S) = 1
- 직선은 dim(span(V)) = 1인 V의 span

### 벡터와 평면

- dim(S) = 2
- 직선은 dim(span(V)) = 2인 V의 span

## 직선의 방정식

### 2차원 공간

- 2차원 공간에 존재하고 원점을 지나는 직선
- 벡터는 방향을 가지고 있어서 direction(d)로 표현
- 직선의 방정식(y=ax) → 벡터 방정식(**r**=t**d**)

- 2차원 공간에 존재하고 원점을 지나지 않는 직선
- 스팬만으로 나타낼 수 없고 벡터의 덧셈 필요
- y=ax+b → **r**=t**d**+**s**

### 3차원 공간

- y=ax+b 형태로 만들어 줄 수 없음(두 개의 방정식의 결합이라서)
- **r**=a**d**+**s**
- 방향이 **d**이고 **s**를 지나는 직선의 방정식
- NOTE: 임의의 차원에 존재할 수 있음 -> 고차원이어도 형태가 똑같기 때문

## 평면의 방정식

- 직선은 direction vector **d**로 방향을 나타낼 수 있음
- 평면은 같은 방식으로 방향을 나타내기 힘듦
- 평면은 평면에 수직인 벡터(normal vector)로 방향을 나타냄
- norm(길이)보다 방향이 중요

- 3차원 공간에 존재하고 원점을 지나는 평면의 방정식
- 평면에 존재하는 모든 벡터와 평면에 수직인 normal vector는 수직 관계 → 내적이 0
- ax + by + xz = 0(수직이면서 원점을 지남)

- 3차원 공간에 존재하고 원점을 지나지 않는 평면의 방정식
- 평면위의 모든 점들을 -s만큼 평행이동, normal vector는 그대로 → 여전히 수직 = 내적이 0
- ax + by + xz =d

- **n**·(**r**-**s**) = 0
- **n**에 수직이고 **s**를 지나는 직선의 방정식
- NOTE: 임의의 차원에 존재할 수 있음

## 초평면(Hyperplane)

- ML, DL 알고리즘에서 많이 사용
- 직선을 나타낼 때도 direction vector 말고 normal vector를 사용 할 수 있음
- **n**에 수직이고 **s**를 지나는 직선
- **n**에 수직이고 **s**를 지나는 평면
- **n**에 수직이고 **s**를 지나는 초평면
- 2, 3차원은 시각적으로 이해 가능(초평면의 특이 케이스)
- Hyperplane은 4차원 이상부터 부르는 말

- 2차원 공간에 존재하는 초평면(직선) | 2차원 공간을 양분 | dimension=1
- 3차원 공간에 존재하는 초평면(평면) | 3차원 공간을 양분 | dimension=2
- 4차원 공간에 존재하는 초평면 | 3차원 공간을 양분 | dimension=3
- m차원 공간에 존재하는 초평면 | m차원 공간을 양분 | dimension=m-1

- 초평면 → 평평한 존재라 공간을 2개로 나눌 수 있음
- 머신러닝에서 linear separator, classifier가 hyperplane의 특징을 가지고 있음
