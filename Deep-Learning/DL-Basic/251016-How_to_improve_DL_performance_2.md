# 성능 고도화 방법 II — 가중치 초기화, 규제화, 학습률
## Weight Initialization, Regularization, and Learning Rate Adjustment

---

## 1. 가중치 초기화 (Weight Initialization)

### 🔹 왜 가중치 초기화가 필요한가?

- 가중치 초기 세팅은 모델의 학습 속도와 성능에 직접적인 영향을 미침.  
- 초기화가 제대로 되지 않으면, 층이 깊어질수록 활성화 함수 출력 분포가 한쪽으로 치우치며 학습이 불안정해짐.  
- 학습이 **plateau(평탄면)** 나 **local minimum(지역 최소값)** 에서 시작되면 학습 효율이 급격히 떨어짐.

---

### ✅ 1. 용어 정리

| 개념 | 설명 |
|------|------|
| **가중치 초기화 (Weight Initialization)** | 각 층의 가중치(weight)를 학습 전에 어떤 분포로 설정할지 결정하는 과정 |
| **초기값 세팅 (Initialization Setting)** | 모델 전체의 가중치, 편향, 구조적 파라미터 등을 포함한 초기 상태 설정. 가중치 초기화보다 더 넓은 개념 |

> 즉, “초기값 세팅이 중요하다” = “가중치 초기화가 중요하다” 와 같은 의미다.

---

### ✅ 2. 가중치 초기화의 중요성

가중치 초기화는 신경망이 **손실 함수의 비선형 공간**에서  
전역 최소값(Global Minimum)을 향해 효율적으로 이동하도록 돕는 핵심 단계이다.

잘못된 초기화는 다음과 같은 문제를 유발한다:

| 문제 | 설명 |
|------|------|
| **포화(Saturation)** | 초기 가중치가 너무 크면 활성화 함수가 포화되어 기울기가 0이 됨 |
| **기울기 소실(Vanishing Gradient)** | 가중치가 너무 작으면 역전파 시 기울기가 사라짐 |
| **대칭 문제(Symmetry Problem)** | 모든 뉴런이 동일한 초기값을 가지면 동일하게 학습되어 의미가 사라짐 |

---

### ✅ 3. 대표적인 초기화 기법

| 초기화 방법 | 특징 | 적합한 활성화 함수 |
|--------------|--------|--------------------|
| **Xavier Initialization (Glorot)** | 입력/출력 뉴런 수에 따라 분산 조정. Sigmoid, Tanh에 적합 | Sigmoid / Tanh |
| **He Initialization (Kaiming)** | ReLU 계열 함수에서 기울기 소실 방지. Xavier보다 분산이 큼 | ReLU / Leaky ReLU |
| **LeCun Initialization** | SELU(자가 정규화 활성화 함수)용 | SELU |

→ 학습 초반의 활성화 분포가 한쪽으로 치우치지 않게 만드는 것이 목적이다.

---

### ✅ 4. 잘못된 초기화 예시

| 방식 | 결과 |
|------|------|
| **모두 0으로 초기화** | 기울기가 0이 되어 학습 불가능 |
| **너무 큰 정규분포 사용** | 활성화 값이 과도하게 커져 포화 발생 |
| **너무 작은 값 사용** | 기울기 소실로 학습 정체 |

---

### ✅ 5. Xavier vs He 초기화

| 구분 | Xavier 초기화 | He 초기화 |
|------|---------------|-----------|
| **적용 대상** | Sigmoid / Tanh | ReLU 계열 |
| **수식 (분산)** | 1 / n | 2 / n |
| **특징** | 활성화 포화 방지 | ReLU의 0 출력 보완 |
| **효과** | 안정적 학습 | 기울기 소실 완화 |

---

### ✅ 6. 배치 정규화와 비교

| 구분 | 가중치 초기화 | 배치 정규화 |
|------|----------------|--------------|
| **적용 시점** | 학습 시작 전 | 각 학습 단계 중 |
| **목적** | 활성화 분포 균형 유지 | 내부 공변량 변화 감소 |
| **효과** | 초기 학습 안정화 | 학습 과정 안정화 |
| **보완 관계** | 상호보완적으로 사용 가능 | - |

---

### 💡 결론

- “초기값 세팅이 중요하다” = “가중치 초기화가 중요하다”  
- Xavier, He 초기화는 활성화 함수의 특성에 따라 선택  
- 잘못된 초기화는 기울기 폭발/소실을 유발해 학습 효율 저하  
- 초기화 + 정규화(BN 등) + 최적화(Optimizer)는 함께 고려해야 함

## 2. 규제화 및 학습률 조정 (Regularization and Learning Rate Adjustment)

---

### 🔹 가중치 감쇠 (Weight Decay)

**정의:**  
손실 함수에 가중치 크기에 대한 제약을 추가하여 큰 가중치에 패널티를 부여하는 방식.

→ 모델이 훈련 데이터에 과도하게 적합하는 **과적합(Overfitting)** 을 방지한다.  
→ 손실 함수가 동일하다면 **가중치가 더 작은 모델**을 선호하도록 유도한다.

| 규제화 방식 | 수식 형태 | 특징 |
|--------------|------------|------|
| **L1 Regularization** | ∑ |W| | 가중치 희소성(0에 가까운 값) 유도 |
| **L2 Regularization** | ∑ W² | 큰 가중치 억제, 부드러운 학습 유도 |

> L2 규제화는 “Weight Decay”라고도 불린다.

---

### 🔹 학습 조기 종료 (Early Stopping)

**정의:**  
모델 학습 시 검증 데이터의 오차가 더 이상 줄어들지 않고 증가하기 시작할 때  
학습을 조기 종료하여 과적합을 방지하는 방법.

- 훈련 오차는 계속 감소하지만,  
  검증 오차가 일정 시점 이후 증가하면 학습을 중단한다.  
- 단순하지만 매우 효과적인 정규화 기법.

---

### 🔹 학습률 스케줄러 (Learning Rate Scheduler)

**정의:**  
학습률(learning rate)을 학습 과정 중 동적으로 조정하여  
수렴 속도와 안정성을 높이는 기법.

적절한 스케줄링은  
- 학습 초기엔 빠른 수렴  
- 후반엔 안정적 최소값 수렴  
을 가능하게 한다.

---

#### 대표적인 학습률 스케줄링 기법

| 스케줄러 | 설명 |
|-----------|------|
| **Constant** | 학습 내내 고정된 학습률 사용 |
| **Step Decay** | 일정 주기마다 학습률을 일정 비율로 감소 |
| **Exponential Decay** | 학습률을 지수적으로 감소 |
| **Cosine Annealing** | 코사인 함수 형태로 학습률을 감소시킴 |
| **One-cycle Policy** | 학습 초반엔 증가, 후반엔 감소하여 빠르고 안정적인 수렴 유도 |

> 실제 딥러닝 프레임워크에서는 `Step Decay`, `Exponential Decay` 가 기본(default)으로 많이 사용된다.

## 💬 요약

| 구분 | 핵심 내용 |
|------|------------|
| **가중치 초기화** | 학습 효율과 안정성의 출발점. Xavier/He 방식이 대표적 |
| **규제화 (Regularization)** | 모델 복잡도를 제어하여 과적합 방지 (L1/L2, Weight Decay) |
| **학습 조기 종료 (Early Stopping)** | 검증 오차가 증가하는 시점에서 학습 중단 |
| **학습률 스케줄링** | 학습률을 동적으로 조정해 효율적 수렴 유도 |
